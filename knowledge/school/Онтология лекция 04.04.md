Дескрипцио́нная логика — язык представления знаний, позволяющий описывать понятия предметной области в недвусмысленном, формализованном виде, организованный по типу языков математической логики.

Концепт - одноместный предикат (класс, экземпляр класса) - используются для описания классов;
Роль - двуместный предикат (отношение между экземплярами класса) - для описания взаимоотношений
abox (assertions) - набор утверждений частного вида, tbox - абстрактные отношения

abox + tbox = база знаний (онтология)

конкретная логика характеризуется набором конструкторов и индуктивых правил, c помощью которого основные концепты строятся из атомарных концептов

Набор концептов = 

пересечение (С П D) (конъюнкция).
объединение (дизъюнкция) (C _ D)
дополнение (отрицание) (-С)
ограничение на создание роли (VR.C)
экзистенциальное ограничение (E R.C)
численное ограничение для создания роли (<=nC)

всякий атомарный концепт является концептом, отрицание концепта - есть концепт

роль трансформирует один концепт к другому 
интерпретация I состоит из непустого множества delta(I) и интерпретирующей функции, которая сопоставляет каждому атомарному концепту А некоторое подмножество, пренадлежащее этому домену, а каждой атомарной роли R - другое некоторое подмножество 
квантор (Т ) - интерпретируется весь домен
квантор (перевернутое Т) - интерпретируется как пустое множнство

Условие - (антицидент) - некоторое предложение, под котором идет поиск в базе знаний
Действие (Консенквет) - действие при успешном исходе поиска (может быть промежуточным, выступающим как условие или целевым, завершающим результат работы) 

Ввод условий - система ищет в базе правила, в соответсвтии с действием добавляется новый факт, система обрабатывает следующее годное правило, если нет правил -> алгоритм заканчивается.
