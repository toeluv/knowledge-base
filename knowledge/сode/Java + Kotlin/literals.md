В Java **литералы** (literals) — это фиксированные значения, которые напрямую записываются в исходном коде. Они представляют собой константы различных типов данных.  

### Основные типы литералов в Java:

#### 1. **Целочисленные литералы**  
Представляют целые числа. Могут быть записаны в десятичной, двоичной, восьмеричной или шестнадцатеричной системах счисления.  

```java
int decimal = 42;        // Десятичный (по умолчанию)
int binary = 0b101010;   // Двоичный (начинается с 0b или 0B)
int octal = 052;         // Восьмеричный (начинается с 0)
int hex = 0x2A;          // Шестнадцатеричный (начинается с 0x или 0X)
long bigNumber = 100L;   // Длинное целое (суффикс L или l)
```

#### 2. **Литералы с плавающей точкой**  
Представляют вещественные числа.  

```java
double d1 = 3.14;        // double (по умолчанию)
double d2 = 3.14d;       // Явное указание double (суффикс D или d)
float f1 = 3.14f;        // float (суффикс F или f)
double sci = 1.23e4;     // Научная нотация (1.23 * 10^4)
```

#### 3. **Символьные литералы**  
Записываются в одинарных кавычках.  

```java
char c1 = 'A';           // Простой символ
char c2 = '\u0041';      // Unicode-символ (латинская 'A')
char c3 = '\n';          // Управляющий символ (перевод строки)
```

#### 4. **Строковые литералы**  
Записываются в двойных кавычках.  

```java
String s1 = "Hello, Java!";
String s2 = "Многострочный текст \
не поддерживается напрямую, но можно использовать конкатенацию: " +
             "часть 2";
```

#### 5. **Логические литералы**  
Только `true` и `false`.  

```java
boolean b1 = true;
boolean b2 = false;
```

#### 6. **Литерал `null`**  
Обозначает отсутствие ссылки на объект.  

```java
String s3 = null;
Object obj = null;
```

### Особые случаи:
- **Подчеркивания в числовых литералах** (для удобства чтения):  
  ```java
  int million = 1_000_000;
  double pi = 3.141_592_653;
  ```
  
- **Экранирование символов в строках и char**:  
  ```java
  String path = "C:\\Program Files\\Java";
  char quote = '\"';
  ```

Литералы в Java строго типизированы, и их использование зависит от контекста. Например, число `5` по умолчанию имеет тип `int`, а `5.0` — `double`.
