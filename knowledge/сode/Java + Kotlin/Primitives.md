### **Примитивные типы данных в Java**  

В Java **примитивные типы (primitive types)** — это базовые типы данных, которые хранят **непосредственно значения** (а не ссылки, как объекты). Они работают быстрее, чем ссылочные типы, но не поддерживают методы и не могут быть `null`.  

---

## **Список примитивных типов**  

| Тип         | Размер (бит) | Диапазон значений                         | Значение по умолчанию | Пример литерала       |
|------------|-------------|------------------------------------------|----------------------|-----------------------|
| `byte`     | 8           | -128 .. 127                              | `0`                  | `byte b = 100;`       |
| `short`    | 16          | -32_768 .. 32_767                        | `0`                  | `short s = 10_000;`   |
| `int`      | 32          | -2³¹ .. 2³¹-1 (~ ±2.1 млрд)             | `0`                  | `int i = 1_000_000;`  |
| `long`     | 64          | -2⁶³ .. 2⁶³-1                           | `0L`                 | `long l = 100L;`      |
| `float`    | 32          | ~ ±3.4e⁻³⁸ .. 3.4e³⁸                    | `0.0f`               | `float f = 3.14f;`    |
| `double`   | 64          | ~ ±1.7e⁻³⁰⁸ .. 1.7e³⁰⁸                  | `0.0d`               | `double d = 3.14;`    |
| `char`     | 16          | 0 .. 65_535 (Unicode)                    | `'\u0000'` (NUL)     | `char c = 'A';`       |
| `boolean`  | ~1 (JVM)    | `true` или `false`                       | `false`              | `boolean flag = true;`|

> **Примечание:**  
> - `boolean` в JVM может занимать разный размер (обычно 1 байт, но оптимизируется).  
> - `char` хранит символы Unicode (например, `'A'`, `'Я'`, `'😊'`).  

---

## **Особенности примитивных типов**  

### **1. Хранение в стеке (Stack)**  
Примитивы хранятся **непосредственно в стеке вызовов** (для локальных переменных) или внутри объектов (для полей класса). Это делает их быстрее, чем объекты.  

### **2. Нет методов и `null`**  
```java
int x = 10;
x.toString(); // Ошибка! У примитивов нет методов.
Integer y = null; // OK, но int z = null; // Ошибка!
```

### **3. Значения по умолчанию**  
- В **полях класса** примитивы инициализируются автоматически (например, `0`, `0.0`, `false`).  
- В **локальных переменных** — **не инициализируются** (ошибка компиляции).  

```java
class Test {
    int num;           // 0 (автоинициализация)
    boolean flag;      // false

    void method() {
        int x;         // Ошибка: must be initialized!
        System.out.println(x);
    }
}
```

### **4. Литералы примитивных типов**  
- **Целочисленные** (`42`, `100L`)  
- **Дробные** (`3.14f`, `2.71828`)  
- **Символьные** (`'A'`, `'\n'`)  
- **Логические** (`true`, `false`)  

```java
long big = 1_000_000_000L; // Суффикс L
float pi = 3.14f;          // Суффикс f
```

## **Сравнение с ссылочными типами**  

| Характеристика      | Примитивы (`int`, `double`)       | Ссылочные типы (`Integer`, `String`) |
|---------------------|----------------------------------|--------------------------------------|
| **Хранение**        | В стеке (значение)               | В куче (ссылка)                      |
| **Скорость**        | Быстрее                         | Медленнее (из-за ссылок)             |
| **`null`**          | Не поддерживается               | Поддерживается                       |
| **Методы**         | Нет                             | Есть (`toString()`, `equals()`)      |
| **Инициализация**   | `0` / `false` (в полях класса)   | `null` (если не задано)              |

---

## **Когда использовать примитивы?**  
1. **Высокая производительность** (циклы, математические операции).  
2. **Локальные переменные** (чтобы избежать накладных расходов).  
3. **Когда `null` не нужен** (например, счётчики, флаги).  

## **Когда использовать обёртки (`Integer`, `Double`)?**  
1. **В коллекциях** (`List<Integer>`, `Map<Double>`).  
2. **Работа с `null`** (например, отсутствие значения).  
3. **Использование методов** (`parseInt()`, `compare()`).  

---

## **Примеры**  

### **1. Автоупаковка и распаковка**  
```java
int a = 10;
Integer b = a;       // Автоупаковка (int → Integer)
int c = b;           // Распаковка (Integer → int)
```

### **2. Сравнение**  
```java
int x = 100;
int y = 100;
System.out.println(x == y); // true (сравнение значений)

Integer a = 200;
Integer b = 200;
System.out.println(a == b); // false (сравнение ссылок!)
System.out.println(a.equals(b)); // true (сравнение значений)
```

### **3. Работа с коллекциями**  
```java
List<Integer> numbers = new ArrayList<>();
numbers.add(10); // Автоупаковка int → Integer
int num = numbers.get(0); // Распаковка Integer → int
```

---

## **Вывод**  
- Примитивы **быстрые**, но **не имеют методов** и не могут быть `null`.  
- Обёртки (`Integer`, `Double`) **замедляют код**, но полезны в коллекциях и API.  
- **Автоупаковка/распаковка** делает переход между ними незаметным, но требует аккуратности.
