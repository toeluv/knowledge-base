### **Как хранятся примитивы и ссылочные типы в Java**

В Java хранение данных в памяти зависит от их типа: **примитивы** и **ссылочные типы** используют разные механизмы.  

---

## **1. Примитивные типы (Primitives)**  
**Хранят непосредственно значение** (не ссылку).  

### **Где хранятся?**  
- **Локальные переменные (в методах)** → **стек (Stack)**.  
- **Поля класса (не static)** → **куча (Heap) внутри объекта**.  
- **Статические переменные (`static`)** → **метаданные класса (Method Area)**.  

#### **Пример:**  
```java
void example() {
    int x = 10;       // Хранится в стеке
    double y = 3.14;  // Тоже в стеке
}

class MyClass {
    int num = 5;      // Хранится в куче (в составе объекта MyClass)
    static char c = 'A'; // В Method Area
}
```

### **Как выглядит в памяти?**  
```
[Стек]  
x → 10  
y → 3.14  

[Куча]  
MyClass объект → { num: 5 }  

[Method Area]  
MyClass.c → 'A'
```

**Особенности:**  
- Быстрый доступ (стек работает за O(1)).  
- Фиксированный размер (зависит от типа, например, `int` — 4 байта).  
- Не могут быть `null`.  

---

## **2. Ссылочные типы (Objects, Arrays, Strings)**  
**Хранят ссылку (адрес в памяти) на объект**, который лежит в куче.  

### **Где хранятся?**  
- **Ссылка (переменная)** → **стек (Stack)**.  
- **Объект (данные)** → **куча (Heap)**.  

#### **Пример:**  
```java
void example() {
    String s = "Hello"; // Ссылка в стеке, объект String в куче
    int[] arr = {1, 2, 3}; // Ссылка в стеке, массив в куче
}

class Person {
    String name; // Ссылка в куче (в составе объекта Person), сам String — тоже в куче
}
```

### **Как выглядит в памяти?**  
```
[Стек]  
s → 0x1000 (адрес)  
arr → 0x2000  

[Куча]  
0x1000 → String "Hello"  
0x2000 → [1, 2, 3] (массив)  
```

**Особенности:**  
- Доступ к объекту происходит через ссылку (двойное разыменование).  
- Объекты в куче управляются **Garbage Collector** (автоматическое освобождение памяти).  
- Могут быть `null` (ссылка никуда не указывает).  

---

## **Сравнение хранения**  

| Характеристика      | Примитивы                          | Ссылочные типы                     |
|---------------------|-----------------------------------|------------------------------------|
| **Хранение значения** | Непосредственно в переменной      | В куче, переменная хранит ссылку   |
| **Память**          | Фиксированный размер (4-8 байт)   | Зависит от объекта + ссылка (4-8 байт) |
| **Скорость доступа** | Быстрее (стек)                   | Медленнее (куча + ссылки)          |
| **`null`**          | Не поддерживается                 | Поддерживается                     |
| **Примеры**         | `int`, `double`, `char`          | `String`, `int[]`, `Person`        |

---

## **Пример с объектом внутри объекта**  
```java
class Engine {
    int power = 200;
}

class Car {
    Engine engine = new Engine(); // Ссылка на Engine
}

Car car = new Car(); // Всё хранится в куче!
```

**В памяти:**  
```
[Стек]  
car → 0x3000  

[Куча]  
0x3000 → Car { engine: 0x4000 }  
0x4000 → Engine { power: 200 }  
```

---

## **Ключевые выводы**  
1. **Примитивы** хранят значение прямо в переменной (стек/куча).  
2. **Ссылочные типы** хранят адрес объекта в куче (сам объект — в куче).  
3. **Стек** — для примитивов и ссылок, **куча** — для объектов.  
4. **`null`** — только для ссылок (означает "нет объекта").
