### **Ссылочные типы данных в Java**  
В Java все типы делятся на **примитивные** (primitive) и **ссылочные** (reference).  

**Ссылочные типы** — это объекты, которые хранятся в **куче (heap)**, а переменная содержит **ссылку** (адрес в памяти) на этот объект.  

#### **Особенности ссылочных типов:**
1. **Хранят ссылку на объект**, а не само значение.
2. **Могут быть `null`** (отсутствие ссылки).
3. **Поддерживают ООП** (наследование, полиморфизм, инкапсуляция).
4. **Имеют методы** (в отличие от примитивов).
5. **Работают через сборщик мусора (Garbage Collector)**.

---

### **Основные ссылочные типы в Java**
1. **Классы (`String`, пользовательские классы)**  
   ```java
   String name = "Java"; // Ссылка на объект String
   Person person = new Person(); // Ссылка на объект класса Person
   ```
2. **Массивы (`int[]`, `String[]` и др.)**  
   ```java
   int[] numbers = {1, 2, 3}; // Ссылка на массив
   String[] names = new String[5];
   ```
3. **Интерфейсы (`List`, `Map` и др.)**  
   ```java
   List<String> list = new ArrayList<>(); // Ссылка на объект, реализующий интерфейс List
   ```
4. **Классы-оболочки (`Integer`, `Double`, `Boolean` и др.)**  

---

## **Оболочки примитивных типов (Wrapper Classes)**
Примитивные типы (`int`, `double`, `boolean` и др.) не являются объектами, но иногда требуется работать с ними как с объектами (например, в коллекциях). Для этого в Java есть **классы-оболочки** (wrapper classes).  

### **Таблица соответствия примитивов и обёрток**
| Примитив  | Класс-оболочка (Wrapper) |
|-----------|--------------------------|
| `byte`    | `Byte`                   |
| `short`   | `Short`                  |
| `int`     | `Integer`                |
| `long`    | `Long`                   |
| `float`   | `Float`                  |
| `double`  | `Double`                 |
| `char`    | `Character`              |
| `boolean` | `Boolean`                |

---

### **Основные возможности классов-обёрток**
1. **Автоупаковка (Autoboxing) и распаковка (Unboxing)**  
   - **Автоупаковка** — автоматическое преобразование примитива в объект.  
   - **Распаковка** — автоматическое преобразование объекта в примитив.  

   ```java
   Integer num = 10;      // Автоупаковка (int → Integer)
   int n = num;           // Распаковка (Integer → int)
   ```

2. **Хранение в коллекциях** (т.к. коллекции работают только с объектами)  
   ```java
   List<Integer> numbers = new ArrayList<>();
   numbers.add(5);        // Автоупаковка int → Integer
   int x = numbers.get(0); // Распаковка Integer → int
   ```

3. **Полезные методы**  
   - `Integer.parseInt("123")` → преобразует строку в число.  
   - `Double.isNaN(value)` → проверяет, является ли число `NaN`.  
   - `Character.isLetter('A')` → проверяет, является ли символ буквой.  

   ```java
   int num = Integer.parseInt("42"); // String → int
   boolean isDigit = Character.isDigit('9'); // true
   ```

4. **Константы (`MIN_VALUE`, `MAX_VALUE`, `SIZE`)**  
   ```java
   System.out.println(Integer.MAX_VALUE); // 2147483647
   System.out.println(Double.MIN_VALUE); // 4.9E-324
   ```

---

### **Примеры использования**
#### 1. **Сравнение объектов (`==` vs `equals()`)**
```java
Integer a = 100;
Integer b = 100;
System.out.println(a == b); // true (кэширование для -128..127)

Integer c = 200;
Integer d = 200;
System.out.println(c == d); // false (разные объекты)
System.out.println(c.equals(d)); // true (сравнение значений)
```

#### 2. **Использование в коллекциях**
```java
List<Integer> numbers = new ArrayList<>();
numbers.add(10); // Автоупаковка int → Integer
int first = numbers.get(0); // Распаковка Integer → int
```

#### 3. **Работа с `null` (осторожно с распаковкой!)**
```java
Integer num = null;
int n = num; // NullPointerException!
```

---

### **Вывод**
- **Ссылочные типы** хранят объекты в куче и работают через ссылки.  
- **Классы-оболочки** позволяют использовать примитивы как объекты.  
- **Автоупаковка/распаковка** упрощает работу, но требует аккуратности (особенно с `null`).  
- **Обёртки полезны** в коллекциях, при работе с методами, требующими объекты.
