ArrayList в Java

#### 1. Основные характеристики ArrayList
- **Динамический массив**: ArrayList реализован на основе массива, который автоматически расширяется при добавлении элементов.
- **Быстрый доступ по индексу**: Время доступа O(1) благодаря прямой индексации.
- **Медленные вставка/удаление**: В среднем O(n) из-за необходимости сдвигать элементы.
- **Не синхронизирован**: В отличие от Vector, требует внешней синхронизации в многопоточной среде.

#### 2. Внутренняя структура
- **Массив элементов**: Хранит данные в массиве Object[].
- **Размер и емкость**: 
  - `size` - текущее количество элементов
  - `capacity` - длина внутреннего массива (емкость)
- **Начальный размер**: По умолчанию 10 элементов (в стандартной реализации).

#### 3. Ключевые методы и их особенности

**1. Добавление элементов**
- `add(E element)`: 
  - Проверяет достаточно ли места (вызывает расширение при необходимости)
  - Добавляет элемент в конец за O(1)
- `add(int index, E element)`:
  - Сдвигает все элементы справа от позиции вставки
  - Время работы O(n)

**2. Удаление элементов**
- `remove(int index)`:
  - Возвращает удаленный элемент
  - Сдвигает все элементы справа от удаляемого
- `remove(Object o)`:
  - Ищет элемент и удаляет первое вхождение
  - Использует equals() для сравнения

**3. Доступ к элементам**
- `get(int index)`: 
  - Проверяет границы индекса
  - Возвращает элемент за O(1)
- `set(int index, E element)`:
  - Заменяет элемент и возвращает старый

**4. Поиск элементов**
- `contains(Object o)`: 
  - Линейный поиск O(n)
  - Использует equals() для сравнения
- `indexOf()`/`lastIndexOf()`: 
  - Возвращают позицию первого/последнего вхождения

**5. Итерация**
- `iterator()`: 
  - Возвращает fail-fast итератор
  - Не поддерживает `remove()` без предварительного вызова `next()`
- `listIterator()`: 
  - Добавляет возможность движения в обе стороны
  - Поддерживает `add()` и `set()`

**6. Работа с коллекциями**
- `addAll(Collection)`: 
  - Добавляет все элементы коллекции
  - Может вызвать несколько расширений массива
- `removeAll()`/`retainAll()`: 
  - Используют contains() для проверки элементов
  - Время работы O(n*m)

#### 4. Механизм расширения
1. При заполнении массива создается новый массив (обычно в 1.5 раза больше)
2. Элементы копируются в новый массив
3. Старый массив освобождается для GC
4. Время операции O(n), но амортизированная стоимость добавления O(1)

#### 5. Особенности производительности
- **Плюсы**:
  - Быстрый доступ по индексу
  - Эффективное использование кэша процессора
  - Минимальные накладные расходы на хранение
- **Минусы**:
  - Дорогие вставки/удаления в середину
  - Требует непрерывного блока памяти
  - Лишние копирования при расширении

#### 6. Отличия от LinkedList
- **ArrayList**:
  - Лучше для частого доступа по индексу
  - Меньший расход памяти
- **LinkedList**:
  - Быстрее вставки/удаления в середине
  - Поддерживает эффективные операции с началом/концом списка

#### 7. Рекомендации по использованию
- Задавайте начальную емкость, если известен примерный размер
- Используйте для частого чтения и редкой модификации
- Избегайте частых вставок/удалений в середину списка
- Для многопоточного доступа используйте `Collections.synchronizedList()`

#### 8. Важные детали реализации
- Не поддерживает примитивные типы (используются wrapper-классы)
- Позволяет хранить null-значения
- Методы `subList()` возвращают view, а не новый список
- Итераторы fail-fast (выбрасывают исключение при изменении списка во время итерации)
