### Реализация ArrayList в Java

#### 1. Основные характеристики ArrayList
- **Динамический массив**: В основе лежит обычный массив, который автоматически расширяется
- **Быстрый доступ**: Прямая адресация по индексу за O(1)
- **Автоматическое расширение**: Увеличивает емкость при заполнении (обычно в 1.5 раза)

#### 2. Сложность операций

Операция | Сложность | Примечания
---|---|---
Доступ по индексу (get/set) | O(1) | Прямой доступ к элементу массива
Добавление в конец (add) | O(1) | Амортизированная сложность
Добавление по индексу (add(index)) | O(n) | Требует сдвига элементов
Удаление по индексу (remove) | O(n) | Требует сдвига элементов
Поиск элемента (contains/indexOf) | O(n) | Линейный поиск по массиву
Итерация | O(n) | Последовательный доступ

#### 3. Внутренняя структура
```java
transient Object[] elementData; // Хранилище элементов
private int size; // Текущее количество элементов
```

#### 4. Механизм расширения
1. При добавлении проверяется хватает ли места
2. Если нет - создается новый массив (newCapacity = oldCapacity + (oldCapacity >> 1))
3. Элементы копируются в новый массив (System.arraycopy)
4. Старый массив удаляется

#### 5. Ключевые особенности

**1. Добавление элементов**:
- `add(E e)`: 
  - Проверка емкости (возможно расширение O(n))
  - Добавление в конец O(1)
- `add(int index, E e)`:
  - Проверка границ
  - Сдвиг элементов вправо O(n)
  - Вставка элемента O(1)

**2. Удаление элементов**:
- `remove(int index)`:
  - Проверка границ
  - Сдвиг элементов влево O(n)
- `remove(Object o)`:
  - Поиск элемента O(n)
  - Сдвиг элементов O(n)

**3. Итераторы**:
- `iterator()`: Fail-fast итератор
- `listIterator()`: С дополнительными методами
- При изменении списка во время итерации - ConcurrentModificationException

#### 6. Оптимизации
1. **Выбор начальной емкости**: 
   ```java 
   new ArrayList<>(100) // Избегает первых расширений
   ```
2. **Быстрый доступ**: Прямая работа с массивом
3. **Эффективное копирование**: System.arraycopy (нативный метод)

#### 7. Сравнение с LinkedList

Операция | ArrayList | LinkedList
---|---|---
Добавление в конец | O(1)* | O(1)
Добавление в начало | O(n) | O(1)
Вставка в середину | O(n) | O(n)
Доступ по индексу | O(1) | O(n)
Удаление из начала | O(n) | O(1)
Исп. памяти | Меньше | Больше (ссылки)

* - амортизированная сложность

#### 8. Рекомендации по использованию
- **Используйте ArrayList когда**:
  - Частый доступ по индексу
  - Преобладает добавление в конец
  - Важна экономия памяти
- **Избегайте ArrayList когда**:
  - Частые вставки/удаления в начале/середине
  - Неизвестен конечный размер

#### 9. Примеры использования
```java
// Оптимальное создание
List<String> list = new ArrayList<>(1000); 

// Быстрый доступ
String item = list.get(500); // O(1)

// Медленная вставка
list.add(0, "new"); // O(n)
```

#### 10. Особенности производительности
- **Плюсы**:
  - Молниеносный доступ по индексу
  - Эффективное использование кэша CPU
  - Минимальные накладные расходы
- **Минусы**:
  - Дорогие вставки/удаления
  - Требует непрерывного блока памяти
  - Лишние копирования при расширении

ArrayList - оптимальный выбор для сценариев с частым чтением и редкой модификацией данных.
