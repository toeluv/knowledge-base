### Реализация LinkedList в Java

#### 1. Основные характеристики LinkedList
- **Двусвязный список**: Каждый элемент (узел) содержит ссылки на предыдущий и следующий элементы
- **Сложность основных операций**:

Операция | Сложность | Примечания
---|---|---
Добавление в начало/конец | O(1) | Не требует обхода списка
Вставка/удаление по индексу | O(n) | В худшем случае требует обхода половины списка
Доступ по индексу (get) | O(n) | Требует последовательного обхода
Поиск элемента | O(n) | Линейный поиск по всему списку
Итерация | O(n) | Последовательный доступ к элементам

#### 2. Внутренняя структура
- **Узел (Node)**:
  ```java
  class Node<E> {
      E data;
      Node<E> next;
      Node<E> prev;
  }
  ```
- **Ссылки**:
  - `first` - ссылка на первый элемент
  - `last` - ссылка на последний элемент
  - `size` - текущее количество элементов

#### 3. Ключевые особенности реализации

**1. Добавление элементов**:
- `addFirst()`/`addLast()`: O(1)
  - Простое обновление ссылок у соседних узлов
- `add(index, element)`: O(n)
  - Требует поиска позиции (в среднем n/2 операций)

**2. Удаление элементов**:
- `removeFirst()`/`removeLast()`: O(1)
- `remove(index)`/`remove(object)`: O(n)
  - Поиск элемента + обновление ссылок соседей

**3. Доступ к элементам**:
- `get(index)`: O(n)
  - Оптимизация: поиск с начала или конца в зависимости от позиции
  ```java
  if (index < size/2) { // Ищем с начала
      Node<E> x = first;
      for (int i = 0; i < index; i++)
          x = x.next;
  } else { // Ищем с конца
      Node<E> x = last;
      for (int i = size-1; i > index; i--)
          x = x.prev;
  }
  ```

**4. Итераторы**:
- `iterator()`: O(1) для `next()`
- `listIterator()`: Поддерживает движение в обе стороны
- **Fail-fast**: Бросает `ConcurrentModificationException` при изменении списка во время итерации

#### 4. Сравнение с ArrayList

Операция | LinkedList | ArrayList
---|---|---
Добавление в начало | O(1) | O(n)
Добавление в конец | O(1) | O(1) (амортизированно)
Вставка в середину | O(n) | O(n)
Доступ по индексу | O(n) | O(1)
Удаление из начала | O(1) | O(n)
Использование памяти | Выше (хранит ссылки) | Ниже (только данные)

#### 5. Оптимизации в реализации
1. **Двусвязность**: Позволяет эффективно удалять элементы и двигаться в обе стороны
2. **Раздельный поиск**: Для индексов в первой/второй половине списка
3. **Кэширование позиции**: В итераторах для ускорения последовательного доступа

#### 6. Рекомендации по использованию
- **Используйте LinkedList когда**:
  - Частые вставки/удаления в начале/середине списка
  - Нужна очередь (FIFO) или стек (LIFO)
  - Не требуется частый доступ по индексу
- **Избегайте LinkedList когда**:
  - Преобладает случайный доступ по индексу
  - Критична экономия памяти
  - Требуется максимальная производительность итераций

#### 7. Особенности производительности
- **Плюсы**:
  - Быстрые операции с началом/концом списка
  - Эффективные вставки/удаления
  - Не требует непрерывного блока памяти
- **Минусы**:
  - Плохая локализация данных (проигрыш в кэш-памяти)
  - Высокие накладные расходы на хранение ссылок
  - Медленный доступ по индексу

#### 8. Примеры использования
```java
// Использование как очереди
LinkedList<String> queue = new LinkedList<>();
queue.addLast("a"); // O(1)
queue.removeFirst(); // O(1)

// Использование как стека
LinkedList<String> stack = new LinkedList<>();
stack.addFirst("a"); // O(1)
stack.removeFirst(); // O(1)
```

Эта реализация обеспечивает эффективное выполнение операций с началом и концом списка, но менее эффективна для случайного доступа по сравнению с ArrayList.
