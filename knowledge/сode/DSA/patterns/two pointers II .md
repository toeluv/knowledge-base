📊 Категории паттернов

1️⃣ Встречное движение (Левый и Правый)
Когда использовать: Манипуляции с массивами/строками, задачи на разделение, проверка палиндромов

Шаблон:

```java
int left = 0, right = n - 1;
while (left < right) {
    // Обработка в зависимости от условия
    if (condition) {
        // Выполняем действие
    }
    left++;
    right--;
}
```

Задачи:
✅ Two Sum II (LC 167) - Легкая
✅ Container With Most Water (LC 11) - Средняя
✅ Valid Palindrome (LC 125) - Легкая
✅ 3Sum (LC 15) - Средняя
✅ Trapping Rain Water (LC 42) - Сложная
✅ Sort Colors (LC 75) - Средняя

2️⃣ Однонаправленное движение (Быстрый и Медленный)
Когда использовать: Удаление дубликатов, модификации на месте, циклы в связных списках

Шаблон:

```java
int slow = 0;
for (int fast = 0; fast < n; fast++) {
    if (condition) {
        arr[slow] = arr[fast];
        slow++;
    }
}
```

Задачи:
✅ Remove Duplicates (LC 26) - Легкая
✅ Move Zeroes (LC 283) - Легкая
✅ Remove Element (LC 27) - Легкая
✅ Linked List Cycle (LC 141) - Легкая
✅ Find Duplicate Number (LC 287) - Средняя

3️⃣ Скользящее окно (Динамический быстрый указатель)
Когда использовать: Задачи на подмассивы/подстроки с ограничениями

Шаблон:

```java
int left = 0;
for (int right = 0; right < n; right++) {
    // Расширяем окно
    while (window_invalid) {
        // Сужаем окно
        left++;
    }
    // Обновляем результат
}
```

Задачи:
✅ Longest Substring Without Repeating (LC 3) - Средняя
✅ Minimum Window Substring (LC 76) - Сложная
✅ Max Consecutive Ones III (LC 1004) - Средняя
✅ Fruits Into Baskets (LC 904) - Средняя
✅ Longest Repeating Character Replacement (LC 424) - Средняя

4️⃣ Паттерн слияния (Два массива)
Когда использовать: Слияние отсортированных массивов, задачи на пересечение

Шаблон:

```java
int i = 0, j = 0;
while (i < n && j < m) {
    if (arr1[i] < arr2[j]) i++;
    else if (arr1[i] > arr2[j]) j++;
    else { /* нашли совпадение */ i++; j++; }
}
```

Задачи:
✅ Merge Sorted Array (LC 88) - Легкая
✅ Intersection of Two Arrays (LC 349) - Легкая
✅ Merge Two Sorted Lists (LC 21) - Легкая
✅ Partition Labels (LC 763) - Средняя

5️⃣ Паттерн разделения (Быстрая сортировка)
Когда использовать: Разделение по условию, Голландский национальный флаг

Шаблон:

```java
int boundary = 0;
for (int i = 0; i < n; i++) {
    if (condition) {
        swap(arr[i], arr[boundary]);
        boundary++;
    }
}
```

Задачи:
✅ Sort Array By Parity (LC 905) - Легкая
✅ Sort Colors (LC 75) - Средняя
✅ Partition Array (LC 2161) - Средняя
✅ Kth Largest Element (LC 215) - Средняя

🎯 Дерево решений: Какой паттерн использовать?
Задача о подмассивах/подстроках с ограничениями размера/суммы?
├─ ДА → Скользящее окно (Категория 3)
└─ НЕТ ↓

Есть ДВА разных массива/списка для обработки?
├─ ДА → Паттерн слияния (Категория 4)
└─ НЕТ ↓

Нужно разделить/переупорядочить по условию?
├─ ДА → Паттерн разделения (Категория 5)
└─ НЕТ ↓

Указатели движутся НАВСТРЕЧУ друг другу?
├─ ДА → Встречное движение (Категория 1)
└─ НЕТ → Однонаправленное движение (Категория 2)

🚀 Примеры на собеседованиях

Сценарий 1: "Найти пару с целевой суммой в отсортированном массиве"
Мгновенное распознавание: Отсортированный массив + пара → Встречное движение

```java
// Подход Two Sum II
int left = 0, right = n - 1;
while (left < right) {
    int sum = arr[left] + arr[right];
    if (sum == target) return true;
    else if (sum < target) left++;
    else right--;
}
```

Сценарий 2: "Удалить все вхождения на месте"
Мгновенное распознавание: На месте + модификация → Однонаправленное движение

```java
int slow = 0;
for (int fast = 0; fast < n; fast++) {
    if (arr[fast] != val) {
        arr[slow++] = arr[fast];
    }
}
```

Сценарий 3: "Самая длинная подстрока с не более K уникальных символов"
Мгновенное распознавание: Подстрока + ограничение → Скользящее окно

```java
unordered_map<char, int> freq;
int left = 0, maxLen = 0;
for (int right = 0; right < n; right++) {
    freq[s[right]]++;
    while (freq.size() > k) {
        freq[s[left]]--;
        if (freq[s[left]] == 0) freq.erase(s[left]);
        left++;
    }
    maxLen = max(maxLen, right - left + 1);
}
```

💎 Профессиональные советы, которые заняли у меня 6 месяцев изучения
- Отсортированный массив = Сигнал к использованию двух указателей
- 90% задач с отсортированным массивом используют два указателя
- "На месте" = Паттерн Быстрый-Медленный
- Если говорят "O(1) память", думайте о быстром-медленном
- Подмассив/Подстрока = Скользящее окно
- "Самая длинная/короткая" + "подмассив/подстрока" = скользящее окно
- Несколько массивов = Паттерн слияния
- Обработка 2+ отсортированных массивов вместе
- Разделение/Переупорядочивание = Стиль быстрой сортировки
- Перемещение элементов по условиям

🔥 Частые ошибки, которых стоит избегать
❌ Ошибка 1: Использование двух указателей, когда нужен хэш-мап
Проблема: "Two Sum" в неотсортированном массиве
Неправильно: Два указателя | Правильно: Хэш-мап

❌ Ошибка 2: Необработка крайних случаев
```java
// Всегда проверяйте:
if (n == 0 || n == 1) return /* базовый случай */;
```

❌ Ошибка 3: Неправильное движение указателей
- Левый указатель должен двигаться только вправо
- Правый указатель должен двигаться только влево
- Не пересекайте их случайным образом

❌ Ошибка 4: Забыть проверить условие цикла
```java
// Всегда обеспечивайте допустимый диапазон
while (left < right) // не left <= right для встречного движения
while (slow < n && fast < n) // для однонаправленного движения
```

📈 Шпаргалка по сложности
Паттерн | Время | Память | Лучше всего для
---|---|---|---
Встречное движение | O(n) | O(1) | Отсортированные массивы, палиндромы
Однонаправленное движение | O(n) | O(1) | Модификации на месте
Скользящее окно | O(n) | O(k) | Подмассивы с ограничениями
Слияние | O(n+m) | O(1) | Два отсортированных массива
Разделение | O(n) | O(1) | Переупорядочивание элементов

🎯 Красные флаги на собеседованиях (Когда НЕ использовать два указателя)
🚫 Неотсортированный массив + нужны все пары → Используйте хэш-мап
🚫 Нужно найти элементы в любом порядке → Используйте хэш-сет
🚫 Обход дерева/графа → Используйте DFS/BFS
🚫 Состояние динамического программирования → Используйте массив для ДП
🚫 Нужен подсчет частот → Сначала используйте хэш-мап
