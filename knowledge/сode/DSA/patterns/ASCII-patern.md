Этот паттерн `chars[c - 'a']++` — классический прием в программировании для работы с символами английского алфавита. Давайте разберем его подробно.

## Что делает этот паттерн?

Данный код используется для подсчета частоты встречаемости символов (обычно строчных букв английского алфавита) в строке.

## Как это работает?

### 1. Преобразование символа в индекс
```cpp
c - 'a'
```
- `c` — текущий символ (например, 'b', 'c', 'd')
- `'a'` — символ 'a' с ASCII кодом 97
- Вычитание дает смещение относительно 'a':
  - `'a' - 'a' = 0`
  - `'b' - 'a' = 1`
  - `'c' - 'a' = 2`
  - ...
  - `'z' - 'a' = 25`

### 2. Инкремент счетчика
```cpp
chars[index]++;
```
Увеличивает счетчик для соответствующего символа в массиве.

## Пример использования

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "hello";
    int chars[26] = {0}; // массив для 26 букв алфавита
    
    for (char c : s) {
        if (c >= 'a' && c <= 'z') {
            chars[c - 'a']++;
        }
    }
    
    // Вывод результатов
    for (int i = 0; i < 26; i++) {
        if (chars[i] > 0) {
            cout << (char)('a' + i) << ": " << chars[i] << endl;
        }
    }
    
    return 0;
}
```

**Вывод:**
```
e: 1
h: 1
l: 2
o: 1
```

## Вариации паттерна

### Для заглавных букв:
```cpp
chars[c - 'A']++;  // 'A' = 65 в ASCII
```

### Для смешанного регистра:
```cpp
// Приведение к нижнему регистру
chars[tolower(c) - 'a']++;

// Или отдельные массивы для разных регистров
if (c >= 'a' && c <= 'z') {
    lower[c - 'a']++;
} else if (c >= 'A' && c <= 'Z') {
    upper[c - 'A']++;
}
```

### Для других диапазонов символов:
```cpp
// Для цифр '0'-'9'
digits[c - '0']++;  // '0' = 48 в ASCII

// Для расширенного набора
chars[c - 'a']++;  // работает для a-z
```

## Преимущества паттерна

1. **Эффективность** — O(1) доступ к элементам массива
2. **Простота** — минимальный код
3. **Скорость** — быстрее чем `map` или `unordered_map` для ограниченного набора символов
4. **Память** — фиксированное использование памяти (26 элементов для английского алфавита)

## Типичные применения

1. **Проверка анаграмм**
```cpp
bool isAnagram(string s, string t) {
    if (s.length() != t.length()) return false;
    
    int count[26] = {0};
    
    for (char c : s) count[c - 'a']++;
    for (char c : t) {
        if (--count[c - 'a'] < 0) return false;
    }
```

## Ограничения

- Работает только с английским алфавитом a-z
- Требует проверки диапазона символов
- Не подходит для Unicode или других кодировок
