### **Сортировка пузырьком (Bubble Sort)**  

#### **📌 Основная идея**  
Сортировка пузырьком — это простой алгоритм сортировки, который **многократно проходит по массиву**, сравнивая соседние элементы и меняя их местами, если они расположены в неправильном порядке.  

---

### **🔍 Как работает?**  
1. **Проходы по массиву**: Алгоритм делает `n-1` проходов (для массива из `n` элементов).  
2. **Сравнение пар**: На каждом шаге сравниваются соседние элементы.  
3. **Обмен местами**: Если порядок нарушен, элементы меняются.  
4. **"Всплытие"**: После каждого прохода **наибольший элемент "всплывает" в конец** массива.  

---

### **⚡ Сложность алгоритма**  
- **Лучший случай**: **O(n)** (если массив уже отсортирован + оптимизация).  
- **Средний и худший случай**: **O(n²)**.  
- **Память**: **O(1)** (сортировка на месте).  

---

### **📌 Ключевые свойства**  
✅ **Простота реализации** — легко понять и написать.  
✅ **Не требует дополнительной памяти**.  
❌ **Медленный на больших массивах** (из-за O(n²)).  
❌ **На практике почти не используется** (есть более эффективные алгоритмы).  

---

### **🚀 Оптимизации**  
1. **Уменьшение границы**  
   - После каждого прохода последний `i`-й элемент уже на месте → не проверяем его снова.  
2. **Флаг обмена (`swapped`)**  
   - Если за проход не было ни одного обмена → массив отсортирован → досрочный выход.  

---

### **🛠️ Пример работы**  
**Исходный массив**: `[5, 3, 8, 1, 2]`  
1. **Первый проход**: `[3, 5, 1, 2, 8]` (8 "всплыл").  
2. **Второй проход**: `[3, 1, 2, 5, 8]` (5 на месте).  
3. **Третий проход**: `[1, 2, 3, 5, 8]` (3 на месте).  
4. **Четвертый проход**: без изменений → завершение.  

---
### **🧑🏻‍💻 Где применяется?**  
- **Обучение** (для понимания основ сортировки).  
- **Маленькие/почти отсортированные массивы**.  
- **Системы с ограниченными ресурсами** (из-за простоты).  
```java
public class BubbleSort {
  public static int[] sort(int[] toSort) {
    boolean swapped;
    for (int i = 0; i < toSort.length - 1; i++) {
      swapped = false;
      for (int j = 0; j < toSort.length - 1; j++) {
        if (toSort[j + 1] < toSort[j]) {
          int buff = toSort[j];
          toSort[j] = toSort[j + 1];
          toSort[j + 1] = buff;
          swapped = true;
        }
      }
      if (!swapped) {
        break;
      }
    }
    return toSort;
  }
}
```
--
**Итог**: Хорош для обучения, но не для реальных задач с большими данными. 🎓
