### 🚀 **Горячие клавиши в UNIX/Linux: удобная командная строка**  

Для новичков, привыкших к Windows, терминал UNIX может показаться неудобным — например, `Ctrl+C` и `Ctrl+V` работают иначе, а клавиши `Home`/`End` могут не срабатывать. Но освоив несколько горячих клавиш, вы сможете работать гораздо быстрее!  

---

## 🔹 **Навигация по строке**  
| Сочетание          | Действие                          | Аналог в Windows       |  
|--------------------|-----------------------------------|------------------------|  
| **Ctrl + A**       | Курсор в **начало** строки        | `Home`                 |  
| **Ctrl + E**       | Курсор в **конец** строки         | `End`                  |  
| **Alt + B**        | На **слово назад**                | `Ctrl + ←`             |  
| **Alt + F**        | На **слово вперед**               | `Ctrl + →`             |  
| **Ctrl + B**       | На **символ назад**               | `←` (стрелка влево)    |  
| **Ctrl + F**       | На **символ вперед**              | `→` (стрелка вправо)   |  

---

## 🔹 **Редактирование текста**  
| Сочетание          | Действие                          |  
|--------------------|-----------------------------------|  
| **Ctrl + W**       | Удалить **слово слева** от курсора |  
| **Alt + D**        | Удалить **слово справа** от курсора |  
| **Ctrl + U**       | Удалить **от курсора до начала строки** |  
| **Ctrl + K**       | Удалить **от курсора до конца строки** |  
| **Ctrl + H**       | Удалить **символ слева** (`Backspace`) |  
| **Ctrl + D**       | Удалить **символ справа** (`Delete`) |  
| **Alt + L**        | Перевести слово в **нижний регистр** |  
| **Alt + U**        | Перевести слово в **верхний регистр** |  
| **Alt + C**        | Сделать **первую букву заглавной** |  

---

## 🔹 **Полезные комбинации**  
| Сочетание               | Действие                          |  
|-------------------------|-----------------------------------|  
| **Ctrl + Alt + T**      | Открыть **новый терминал**       |  
| **Tab** (дважды)        | **Автодополнение** команды       |  
| **Ctrl + L**            | **Очистить экран** (аналог `clear`) |  
| **Ctrl + P**            | Прокрутить **историю вверх** (`↑`) |  
| **Ctrl + N**            | Прокрутить **историю вниз** (`↓`) |  
| **Ctrl + Insert**       | **Копировать** (в некоторых терминалах) |  
| **Shift + Insert**      | **Вставить**                      |  
| **Ctrl + C**            | **Прервать** процесс             |  

---

### ⚠️ **Важно!**  
- В некоторых UNIX-системах вместо **Ctrl** используется **Esc** (но нажимать её нужно отдельно, а не вместе с другой клавишей).  
- Если комбинация не работает, попробуйте:  
  - Нажать **Esc**, отпустить, затем нажать нужную клавишу (например, `Esc` + `B` вместо `Alt + B`).

✅ Удобно перемещаться по истории.
