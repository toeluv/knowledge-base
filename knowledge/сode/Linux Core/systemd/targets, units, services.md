# Linux Юниты, Сервисы и Таргеты

В systemd (современной системе инициализации в Linux) используются следующие основные понятия:

## Юниты (Units)

Юниты - это базовые объекты systemd, которые представляют системные ресурсы. Основные типы юнитов:

1. **Сервисы (service)** - Демоны, службы, программы
2. **Таргеты (target)** - Группы юнитов (аналог runlevels в SysVinit)
3. **Сокеты (socket)** - Активация по запросу через сокет
4. **Устройства (device)** - Аппаратные устройства
5. **Точки монтирования (mount)** - Файловые системы
6. **Автомонтирования (automount)** - Автоматическое монтирование
7. **Таймеры (timer)** - Активация по времени (аналог cron)
8. **Пути (path)** - Активация по изменению файлов

## Сервисы

Сервисы - это юниты, которые управляют демонами и приложениями. Примеры команд:

```bash
# Управление сервисами
systemctl start service_name    # Запустить сервис
systemctl stop service_name     # Остановить сервис
systemctl restart service_name  # Перезапустить сервис
systemctl reload service_name   # Перезагрузить конфигурацию
systemctl status service_name   # Показать статус

# Включение/отключение автозапуска
systemctl enable service_name   # Включить автозапуск
systemctl disable service_name  # Отключить автозапуск

# Просмотр списка
systemctl list-units --type=service  # Активные сервисы
systemctl list-unit-files --type=service  # Все доступные сервисы
```

## Таргеты

Таргеты - это группы юнитов, которые выполняются вместе. Аналогичны уровням выполнения (runlevels) в SysVinit.

Основные таргеты:
- `multi-user.target` - Многопользовательский режим без графики
- `graphical.target` - Графический режим
- `rescue.target` - Режим восстановления
- `emergency.target` - Аварийный режим
- `reboot.target`, `poweroff.target` - Перезагрузка и выключение

Команды для работы с таргетами:
```bash
systemctl isolate multi-user.target  # Переключиться на таргет
systemctl get-default               # Показать текущий таргет по умолчанию
systemctl set-default graphical.target  # Установить таргет по умолчанию
```

## Файлы конфигурации

Юниты конфигурируются через файлы с расширением `.service`, `.target` и т.д., которые находятся в:
- `/usr/lib/systemd/system/` - Системные юниты (устанавливаются пакетами)
- `/etc/systemd/system/` - Локальные юниты и переопределения

После изменения конфигурации нужно выполнить:
```bash
systemctl daemon-reload
```

Это основные концепции работы с systemd в Linux. Система предоставляет мощные возможности для управления сервисами и зависимостями между ними.
