## **Папки Linux: структура файловой системы (FHS)**

Файловая система Linux организована по стандарту **Filesystem Hierarchy Standard (FHS)**, который определяет назначение каждой папки. Вот основные директории и их функции:

---

## **1. Корневая папка (`/`)**
Главная точка монтирования, содержащая все остальные папки.  
**Важные подкаталоги:**  
- `/bin` – основные исполняемые файлы (команды вроде `ls`, `cat`).  
- `/sbin` – системные утилиты для администрирования (`fdisk`, `iptables`).  
- `/boot` – файлы загрузчика (GRUB, ядро `vmlinuz`, `initramfs`).  
- `/dev` – файлы устройств (`/dev/sda`, `/dev/tty`, `/dev/null`).  
- `/etc` – конфигурационные файлы системы и программ.  
- `/home` – домашние папки пользователей.  
- `/root` – домашняя папка суперпользователя.  

---

## **2. Системные папки**
| Папка       | Назначение |
|-------------|------------|
| `/lib`      | Библиотеки для `/bin` и `/sbin` (аналог DLL в Windows). |
| `/lib64`    | 64-битные библиотеки (в x86_64 системах). |
| `/opt`      | Дополнительное ПО (например, `/opt/google/chrome`). |
| `/proc`     | Виртуальная файловая система с данными о процессах и ядре. |
| `/sys`      | Информация о устройствах и ядре (часть `sysfs`). |
| `/usr`      | Вторичная иерархия для ПО (бинарники, библиотеки, документация). |
| `/var`      | Изменяемые данные (логи, кеши, базы данных). |

---

## **3. Пользовательские данные**
- `/home/<user>` – личные файлы, настройки и документы пользователей.  
- `/root` – домашняя папка администратора (не путать с `/`!).  

---

## **4. Временные файлы**
| Папка       | Описание |
|-------------|----------|
| `/tmp`      | Временные файлы (очищаются при перезагрузке). |
| `/var/tmp`  | Временные файлы, сохраняемые между перезагрузками. |
| `/run`      | PID-файлы, сокеты (хранятся в RAM, см. предыдущий разбор). |
| `/dev/shm`  | Shared memory (аналог tmpfs). |

---

## **5. Логи и данные сервисов**
- `/var/log` – системные логи (`syslog`, `auth.log`, `nginx/`).  
- `/var/cache` – кеш программ (apt, браузеров).  
- `/var/spool` – очереди задач (почта, cron, принтеры).  
- `/var/lib` – базы данных (MySQL, Docker, dpkg).  

---

## **6. Специальные файловые системы**
- `/proc` – информация о процессах (например, `/proc/cpuinfo`).  
- `/sys` – параметры ядра и устройств.  
- `/mnt` – временное монтирование дисков (вручную).  
- `/media` – автоматически монтируемые устройства (USB, CD-ROM).  

---

## **7. `/usr` – вторичная иерархия**
Содержит большинство программ и библиотек:  
- `/usr/bin` – основные пользовательские команды.  
- `/usr/sbin` – системные утилиты для администрирования.  
- `/usr/lib` – библиотеки для `/usr/bin` и `/usr/sbin`.  
- `/usr/local` – ПО, установленное вручную (вне пакетного менеджера).  
- `/usr/share` – архитектурно-независимые данные (документация, иконки).  

---

## **8. Пример дерева каталогов**
```bash
/
├── bin      # Основные команды
├── boot     # Загрузчик
├── dev      # Устройства
├── etc      # Конфиги
├── home     # Домашние папки
├── lib      # Библиотеки
├── mnt      # Временное монтирование
├── opt      # Доп. ПО (Chrome, JetBrains)
├── proc     # Процессы и ядро
├── root     # Домашняя папка root
├── run      # PID-файлы и сокеты (в RAM)
├── sbin     # Системные утилиты
├── tmp      # Временные файлы
├── usr      # Пользовательские программы
└── var      # Логи, кеши, базы данных
```

---

## **9. Как запомнить структуру?**
- **Системные настройки** → `/etc`.  
- **Логи** → `/var/log`.  
- **Загрузка** → `/boot`.  
- **Библиотеки** → `/lib`, `/usr/lib`.  
- **Временные файлы** → `/tmp`, `/run`.  
- **Пользовательские данные** → `/home`, `/root`.  

---

## **10. Важные команды для навигации**
```bash
ls /          # Просмотр корневой файловой системы
tree -L 1 /   # Дерево каталогов (если установлен tree)
df -h         # Свободное место на дисках
mount         # Список смонтированных файловых систем
```

---

## **Вывод**
- Структура Linux логична, но требует изучения.  
- **FHS** стандартизирует расположение файлов для совместимости между дистрибутивами.  
- Критически важные папки: `/etc`, `/var`, `/bin`, `/usr`.  
- Временные данные хранятся в `/tmp`, `/run`, `/dev/shm`.
