# Условные выражения и подстановка команд в Bash

## 1. Условные выражения (test, [ ], [[ ]])

### Команда test и эквивалент [ ]
```bash
test условие
# или
[ условие ]
```

Примеры:
```bash
[ -f file.txt ]  # Проверка, что file.txt - обычный файл
[ -d dir ]       # Проверка, что dir - директория
[ -z "$var" ]    # Проверка, что переменная пустая
[ "$a" -eq "$b" ] # Проверка на равенство чисел
```

### Двойные квадратные скобки [[ ]]
```bash
[[ условие ]]
```
Преимущества:
- Поддержка расширенных возможностей
- Не требуется экранирование переменных
- Поддержка операторов `&&`, `||`, `!` внутри

Примеры:
```bash
[[ $var == "value" ]]  # Сравнение строк
[[ $num -gt 10 ]]      # Числовое сравнение
[[ -e file && -r file ]] # Комбинированные условия
```

### Операторы сравнения
- **Строки**:
  `==`, `!=`, `=~` (регулярные выражения)
- **Числа**:
  `-eq`, `-ne`, `-lt`, `-le`, `-gt`, `-ge`
- **Файлы**:
  `-e` (существует), `-f` (обычный файл), `-d` (директория),
  `-r` (доступен для чтения), `-w` (доступен для записи),
  `-x` (исполняемый), `-s` (не пустой)

## 2. Подстановка команд

### Обратные кавычки `` `команда` ``
```bash
result=`command`
```

### Современный синтаксис $(команда)
```bash
result=$(command)
```

Примеры:
```bash
today=$(date +%F)
files=$(ls)
count=$(wc -l < file.txt)
```

### Вложенные подстановки
```bash
result=$(echo "Today is $(date +%A)")
```

### Подстановка в условных выражениях
```bash
if [[ $(whoami) == "root" ]]; then
  echo "You are root"
fi
```

### Особенности
1. Подстановка выполняется в дочерней оболочке
2. Удаляются завершающие переводы строк
3. Можно использовать для аргументов команд:
   ```bash
   grep "pattern" $(find . -name "*.txt")
   ```

## 3. Примеры комбинирования

```bash
# Проверка, что пользователь существует в системе
if grep -q "^$user:" /etc/passwd; then
  echo "User exists"
fi

# Проверка свободного места
if [[ $(df -h / | awk 'NR==2 {print $5}' | tr -d '%') -gt 90 ]]; then
  echo "Disk space critically low"
fi
```
