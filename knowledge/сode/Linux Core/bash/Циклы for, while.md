### Циклы `for` и `while` в Bash  

#### 1. Цикл `for`  
**Синтаксис:**  
```bash
for переменная in список_значений; do
    команды
done
```  

**Примеры:**  
- Простой перебор значений:  
  ```bash
  for i in 1 2 3 4 5; do
      echo "Число: $i"
  done
  ```  

- Перебор файлов в директории:  
  ```bash
  for file in *.txt; do
      echo "Файл: $file"
  done
  ```  

- Цикл с использованием диапазона (`{начало..конец..шаг}`):  
  ```bash
  for num in {1..10..2}; do
      echo "Нечётное число: $num"
  done
  ```  

- C-подобный синтаксис (Bash 4+):  
  ```bash
  for ((i = 0; i < 5; i++)); do
      echo "Итерация: $i"
  done
  ```  

---  

#### 2. Цикл `while`  
**Синтаксис:**  
```bash
while условие; do
    команды
done
```  

**Примеры:**  
- Простой счётчик:  
  ```bash
  counter=1
  while [ $counter -le 5 ]; do
      echo "Счётчик: $counter"
      ((counter++))
  done
  ```  

- Чтение файла построчно:  
  ```bash
  while read line; do
      echo "Строка: $line"
  done < файл.txt
  ```  

- Бесконечный цикл (выход через `Ctrl+C` или `break`):  
  ```bash
  while true; do
      echo "Нажмите Ctrl+C для выхода"
      sleep 1
  done
  ```  

---  

#### 3. Управление циклами  
- `break` — прервать цикл.  
- `continue` — перейти к следующей итерации.  

**Пример:**  
```bash
for i in {1..10}; do
    if [ $i -eq 5 ]; then
        break  # Выйти из цикла при i=5
    fi
    echo "$i"
done
```  

---  

#### 4. Вложенные циклы  
```bash
for i in {1..3}; do
    for j in A B; do
        echo "$i$j"
    done
done
```  

---  

#### 5. Особенности  
- В `while` условие проверяется **перед** каждой итерацией.  
- `until` — цикл выполняется, пока условие **ложно** (анти-`while`).  
- В `for` можно использовать подстановки (например, `*.txt`).  

---  

**Важно:**  
- Для арифметических операций в условиях используйте `(( ))` (например, `while ((i < 10))`).  
- Для сравнения строк/чисел в `[ ]` используйте `-eq`, `-lt` и т. д.  

Практикуйтесь на разных примерах, чтобы освоить циклы в Bash! 🚀
