# Условные конструкции `if`, `elif`, `else` в Bash

## Базовый синтаксис

```bash
if [ условие1 ]; then
    # код, если условие1 истинно
elif [ условие2 ]; then
    # код, если условие2 истинно
else
    # код, если все условия ложны
fi
```

## Основные особенности

1. **Обязательные элементы**:
   - `if` начинают конструкцию
   - `then` на той же строке после `;` или на новой строке
   - `fi` завершает блок

2. **Проверка условий**:
   - Можно использовать `test` или `[ ]` для простых условий
   - Рекомендуется `[[ ]]` для расширенных возможностей

## Примеры использования

### Простое условие
```bash
if [ -f "file.txt" ]; then
    echo "Файл существует"
fi
```

### Полная конструкция с elif и else
```bash
if [ "$x" -gt 10 ]; then
    echo "x больше 10"
elif [ "$x" -eq 10 ]; then
    echo "x равно 10"
else
    echo "x меньше 10"
fi
```

### Проверка строк
```bash
if [[ "$name" == "admin" ]]; then
    echo "Доступ разрешен"
elif [[ "$name" == "guest" ]]; then
    echo "Ограниченный доступ"
else
    echo "Доступ запрещен"
fi
```

### Несколько условий
```bash
if [[ -f "$file" && -r "$file" ]]; then
    echo "Файл существует и доступен для чтения"
fi
```

## Важные нюансы

1. **Пробелы**:
   - Обязательны вокруг операторов в `[ ]`
   - Не нужны в `[[ ]]` для строковых операторов

2. **Сравнение чисел и строк**:
   ```bash
   # Для чисел
   if [ "$a" -eq "$b" ]; then ...
   
   # Для строк
   if [[ "$str1" == "$str2" ]]; then ...
   ```

3. **Альтернативная запись**:
   Можно писать `then` на новой строке без `;`:
   ```bash
   if [ условие ]
   then
       # код
   fi
   ```

## Практические примеры

### Проверка пользователя
```bash
if [[ "$(whoami)" != "root" ]]; then
    echo "Запустите скрипт от root!"
    exit 1
fi
```

### Обработка аргументов
```bash
if [ $# -eq 0 ]; then
    echo "Не указаны аргументы"
elif [ $# -gt 3 ]; then
    echo "Слишком много аргументов"
else
    echo "Аргументы: $@"
fi
```

### Проверка сервиса
```bash
if systemctl is-active --quiet nginx; then
    echo "Nginx работает"
else
    echo "Nginx не запущен"
fi
```
