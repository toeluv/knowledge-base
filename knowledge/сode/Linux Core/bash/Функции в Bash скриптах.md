## Функции в Bash-скриптах
В Bash-скриптах **функции** позволяют группировать команды для многократного использования, улучшая читаемость и структуру кода.  

---

## **1. Объявление функций**
### Синтаксис №1 (классический):
```bash
function_name() {
    # Тело функции
    команды
}
```
### Синтаксис №2 (альтернативный, редко используется):
```bash
function function_name {
    # Тело функции
    команды
}
```
> 🔹 Разницы между ними почти нет, но первый вариант предпочтительнее (POSIX-совместим).  

---

## **2. Простой пример**
```bash
#!/bin/bash

# Объявляем функцию
say_hello() {
    echo "Привет, $1!"  # $1 — первый аргумент функции
}

# Вызываем функцию с аргументом
say_hello "Мир"  # Выведет: Привет, Мир!
```
**Вывод:**
```
Привет, Мир!
```

---

## **3. Возвращение значений**
Bash-функции не возвращают значения как в других языках, но могут:
- **Возвращать статус выхода** (0 — успех, 1+ — ошибка) через `return`.
- **Выводить данные** в stdout (через `echo`), которые можно перехватить.

### Пример с `return` (статус):
```bash
is_even() {
    if (( $1 % 2 == 0 )); then
        return 0  # Успех (чётное)
    else
        return 1  # Ошибка (нечётное)
    fi
}

is_even 4
echo "Статус для 4: $?"  # 0 (чётное)

is_even 3
echo "Статус для 3: $?"  # 1 (нечётное)
```

### Пример с выводом в переменную (`echo` + подстановка):
```bash
get_sum() {
    local sum=$(( $1 + $2 ))
    echo "$sum"  # Функция "возвращает" sum через echo
}

result=$(get_sum 5 3)  # Перехватываем вывод
echo "5 + 3 = $result"  # 5 + 3 = 8
```

## **4. Локальные переменные**
По умолчанию переменные в функциях **глобальные**. Чтобы сделать их локальными, используйте `local`:
```bash
func() {
    local var="Я видна только внутри функции"
    global_var="А я глобальная"
}

func
echo "$var"        # Пусто (var локальная)
echo "$global_var"  # Выведет "А я глобальная"
```

---

## **5. Аргументы функции**
Аргументы передаются так же, как аргументы скрипта:
- `$1`, `$2`, ... — позиционные аргументы.
- `$@` — все аргументы.
- `$#` — количество аргументов.

### Пример:
```bash
greet() {
    echo "Имя: $1, Фамилия: $2"
}

greet "Иван" "Петров"  # Имя: Иван, Фамилия: Петров
```

---

## **6. Рекурсивные функции**
Bash поддерживает рекурсию, но без оптимизации хвостовых вызовов.  

### Пример: Факториал
```bash
factorial() {
    if (( $1 <= 1 )); then
        echo 1
    else
        local prev=$(( $1 - 1 ))
        local result=$(factorial "$prev")
        echo $(( $1 * result ))
    fi
}

echo "Факториал 5: $(factorial 5)"  # 120
```

---

## **7. Лучшие практики**
1. **Используйте `local`** для переменных, чтобы избежать побочных эффектов.
2. **Возвращайте статусы** через `return` для проверки успешности.
3. **Документируйте функции** в начале скрипта:
   ```bash
   # Функция: say_hello
   # Описание: Выводит приветствие
   # Аргументы:
   #   $1 — имя для приветствия
   say_hello() { ... }
   ```
4. **Избегайте рекурсии** в Bash — она медленная и может привести к переполнению стека.

---

## **8. Пример готового скрипта**
```bash
#!/bin/bash

# Функция: log
# Описание: Логирует сообщение с датой
log() {
    local message="$1"
    echo "[$(date)] $message"
}

# Функция: add
# Описание: Складывает два числа
add() {
    echo $(($1 + $2))
}

log "Скрипт запущен"
result=$(add 10 20)
log "Результат сложения: $result"
```

**Вывод:**
```
[Вт мая 10 15:00:00 MSK 2024] Скрипт запущен
[Вт мая 10 15:00:00 MSK 2024] Результат сложения: 30
```

---

## **Итог**
- Функции в Bash помогают **структурировать код**.
- Используйте `return` для статусов, `echo` для данных.
- **Локальные переменные (`local`)** — залог безопасности.
- Рекурсия возможна, но не рекомендуется для сложных задач.
