### **Brace Expansion (Фигурное расширение) в Bash**

**Brace Expansion** — это мощный механизм в Bash для генерации строк или последовательностей. Он работает **до** выполнения других подстановок (вроде переменных или подстановки команд).  

---

## **1. Основной синтаксис**
```bash
{элемент1,элемент2,элемент3}
```
- Расширяется в отдельные строки: `элемент1`, `элемент2`, `элемент3`.
- **Запятые** разделяют элементы, **пробелы не допускаются** внутри фигурных скобок.

### **Примеры:**
```bash
echo file.{txt,log}       # file.txt file.log
cp script.sh{,.bak}       # Копирует script.sh в script.sh.bak
mkdir -p /dir/{a,b,c}     # Создаёт /dir/a, /dir/b, /dir/c
```

---

## **2. Генерация последовательностей**
```bash
{старт..конец..шаг}
```
- Работает с числами и буквами (латиница).
- `шаг` опционален (по умолчанию 1 или -1).

### **Примеры:**
```bash
echo {1..5}          # 1 2 3 4 5
echo {5..1}          # 5 4 3 2 1
echo {a..d}          # a b c d
echo {01..10..2}     # 01 03 05 07 09
```

---

## **3. Комбинирование расширений**
Можно комбинировать с другими подстановками:
```bash
echo {A,B}_{1,2}     # A_1 A_2 B_1 B_2
```

---

## **4. Вложенные расширения**
Bash не поддерживает вложенные `{}`, но можно использовать `eval` (осторожно!):
```bash
eval echo {{A,B},{1,2}}  # A B 1 2
```

---

## **5. Практическое применение**
### **Создание резервных копий**
```bash
cp file.txt{,.bak}    # file.txt → file.txt.bak
```

### **Массовое переименование**
```bash
mv image.{jpg,png}    # image.jpg → image.png
```

### **Генерация списка файлов**
```bash
touch report_{2020..2023}.txt
```

---

## **6. Важные нюансы**
1. **Пробелы внутри `{}`**  
   Запятые должны быть **без пробелов**:
   ```bash
   {a, b}  # Ошибка (создаст строки "a" и " b")
   {a,b}   # Правильно
   ```

2. **Экранирование**  
   Если нужны буквальные `{`, `}`, экранируйте их:
   ```bash
   echo \{a,b\}    # Выведет {a,b}, а не a b
   ```

3. **Отличие от подстановки переменных**  
   Brace Expansion выполняется **раньше**, чем подстановка переменных (`$var`).

---

## **7. Примеры для задач администрирования**
### **Создание структуры каталогов**
```bash
mkdir -p /opt/{bin,logs,config/{nginx,apache}}
```

### **Пакетная установка программ**
```bash
sudo apt install {python3,pip}-{dev,venv}
```

### **Быстрое тестирование команд**
```bash
for cmd in {start,stop,restart}; do
    sudo systemctl $cmd nginx
done
```

---

## **Итог**
Brace Expansion — это удобный инструмент для:
- Генерации последовательностей (`{1..10}`).
- Массовых операций с файлами (`cp file{,.bak}`).
- Создания сложных комбинаций (`{A,B}_{1,2}`).

**Запомните:**  
- Запятые без пробелов: `{a,b}`, а не `{a, b}`.  
- Работает только в **Bash** (не в минимальных shell вроде `sh`).  
- Используйте `eval` для вложенных конструкций (но осторожно!).
