## echo $

Команда `echo $?` в Unix/Linux-системах выводит **код завершения последней выполненой команды**.  

### Как это работает:
- `$?` — это специальная переменная, которая хранит **exit-статус** (код возврата) предыдущей команды.  
- `echo $?` просто печатает этот код.  

### Значение кодов:
- **0** — успешное выполнение (без ошибок).  
- **1 и выше** — ошибка (каждая программа может иметь свои коды ошибок).  

### Пример:
```sh
ls /существующий_каталог  # допустим, команда выполняется успешно
echo $?                   # выведет 0

ls /несуществующий_каталог  # ошибка (каталог не найден)
echo $?                     # выведет не 0 (например, 2)
```

### Зачем это нужно?  
- Проверять успешность выполнения скриптов.  
- Обрабатывать ошибки в сценариях оболочки (shell-скриптах).
