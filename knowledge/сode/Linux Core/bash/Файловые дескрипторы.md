### **Файловые дескрипторы и перенаправление потоков в Bash**  

В Linux и Bash все вводы и выводы (I/O) работают через **файловые дескрипторы** (file descriptors, fd). Это числовые идентификаторы, которые система использует для доступа к открытым файлам, устройствам, сокетам и каналам.  

#### **Стандартные файловые дескрипторы**  
- **`0` — stdin** (стандартный ввод, клавиатура)  
- **`1` — stdout** (стандартный вывод, терминал)  
- **`2` — stderr** (стандартный вывод ошибок, терминал)  

Дополнительные дескрипторы (`3`, `4`, ...) можно создавать вручную.  

---

## **1. Базовое перенаправление (`>`, `>>`, `<`)**  

### **Перенаправление вывода (`>`, `>>`)**  
- **`>`** — перезаписать файл (или создать, если его нет)  
  ```bash
  echo "Hello" > file.txt  # stdout в file.txt
  ls /nonexistent 2> errors.log  # stderr в errors.log
  ```
- **`>>`** — добавить в конец файла  
  ```bash
  echo "World" >> file.txt  # дописать в file.txt
  ```

### **Перенаправление ввода (`<`)**  
- **`<`** — читать из файла (вместо клавиатуры)  
  ```bash
  grep "pattern" < input.txt  # искать в input.txt
  ```

---

## **2. Комбинированное перенаправление (`&>`, `2>&1`)**  

### **Перенаправление stdout и stderr**  
- **`&>`** или **`>&`** — записать **оба** потока в файл (Bash ≥4)  
  ```bash
  command &> output.log  # stdout + stderr в output.log
  ```
- **`2>&1`** — перенаправить stderr в stdout  
  ```bash
  command > output.log 2>&1  # stdout в файл, stderr туда же
  ```
- **`1>&2`** — перенаправить stdout в stderr  
  ```bash
  echo "Error message" 1>&2  # вывести в stderr
  ```

### **Раздельное перенаправление stdout и stderr**  
```bash
command > output.log 2> error.log  # stdout → output.log, stderr → error.log
```

---

## **3. Дополнительные дескрипторы (`exec`, `{var}>`, `<>`)**  

### **Создание своих дескрипторов (`exec`)**  
```bash
exec 3> custom.log  # открыть fd 3 для записи в custom.log
echo "Test" >&3     # записать в fd 3
exec 3>&-           # закрыть fd 3
```

### **Чтение и запись в один файл (`<>`)**  
```bash
exec 4<>file.txt  # открыть file.txt на чтение и запись в fd 4
read line <&4     # прочитать строку
echo "New line" >&4  # записать строку
exec 4>&-         # закрыть
```

### **Перенаправление в переменную (`< <()`)**  
```bash
output=$(command)       # захватить stdout
errors=$(command 2>&1)  # захватить stderr + stdout
```

---

## **4. Игнорирование вывода (`/dev/null`)**  
```bash
command > /dev/null    # игнорировать stdout
command 2> /dev/null   # игнорировать stderr
command &> /dev/null   # игнорировать всё
```

---

## **5. Here-document и Here-string**  

### **`<<` (Here-document)** — многострочный ввод  
```bash
cat << EOF
Line 1
Line 2
EOF
```

### **`<<<` (Here-string)** — передача строки  
```bash
grep "hello" <<< "hello world"
```

---

## **6. Временное перенаправление в блоке (`{}`)**  
```bash
{
    echo "Normal output"
    exec 3>&1  # сохранить stdout в fd 3
    exec 1> output.log  # перенаправить stdout в файл
    echo "This goes to output.log"
    exec 1>&3  # восстановить stdout
    echo "Back to terminal"
}
```

---

## **Итоговая таблица**  

| Синтаксис          | Описание                                      |
|--------------------|-----------------------------------------------|
| `> file`           | Перезаписать stdout в файл                    |
| `>> file`          | Дописать stdout в файл                        |
| `2> file`          | Перезаписать stderr в файл                    |
| `&> file`          | Перезаписать stdout + stderr в файл           |
| `2>&1`             | Перенаправить stderr в stdout                 |
| `1>&2`             | Перенаправить stdout в stderr                 |
| `command1 | command2` | stdout command1 → stdin command2              |
| `< file`           | Читать stdin из файла                         |
| `<< EOF`           | Многострочный ввод (Here-doc)                 |
| `<<< "text"`       | Передать строку (Here-string)                 |
| `exec 3> file`     | Создать fd 3 для записи в файл                |
| `>&3`              | Записать в fd 3                               |
| `3>&-`             | Закрыть fd 3                                  |

---

### **Примеры использования**  

#### **1. Логирование stdout и stderr в разные файлы**  
```bash
./script.sh > output.log 2> error.log
```

#### **2. Игнорировать ошибки**  
```bash
rm /nonexistent 2> /dev/null
```

#### **3. Запись в лог + вывод в терминал (`tee`)**  
```bash
echo "Hello" | tee -a logfile.txt
```

#### **4. Временное подавление вывода**  
```bash
(
    echo "Visible"
    exec 2> /dev/null  # игнорировать stderr
    ls /nonexistent    # ошибка не выводится
    exec 2>&1          # восстановить stderr
    echo "Visible again"
)
```
