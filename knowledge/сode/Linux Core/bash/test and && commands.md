## `test` - Команда для проверки условий в Bash (с `&&` (успех) и `||` (неуспех))

Команда `test` (также `[ ]`) оценивает условия и возвращает код завершения: 0 (истина/успех) или 1 (ложь/неудача). Этот конспект фокусируется на связывании `test` с командами, используя `&&` и `||` для выполнения действий в зависимости от успеха или неудачи теста.

**1. Синтаксис:**

*   `test выражение`
*   `[ выражение ]` (Важно: пробелы внутри скобок!)

**2. Типы проверок:**

Команда `test` (и её эквивалент `[ ]`) в Bash используется для проверки условий. Вот основные ключи (опции), сгруппированные по типам проверок:

---

#### Проверки файлов и директорий
| Ключ          | Проверяет                              | Пример (`test` / `[ ]`)         |
|---------------|----------------------------------------|----------------------------------|
| `-e`          | Файл существует                        | `test -e file` / `[ -e file ]`   |
| `-f`          | Это обычный файл (не директория)       | `[ -f file ]`                    |
| `-d`          | Это директория                         | `[ -d dir ]`                     |
| `-s`          | Файл не пустой (размер > 0)            | `[ -s file ]`                    |
| `-r`          | Файл доступен для чтения               | `[ -r file ]`                    |
| `-w`          | Файл доступен для записи               | `[ -w file ]`                    |
| `-x`          | Файл исполняемый или директория доступна для входа | `[ -x file ]`       |
| `-L`          | Это символическая ссылка               | `[ -L link ]`                    |
| `-nt`         | Файл новее (по времени модификации)    | `[ file1 -nt file2 ]`            |
| `-ot`         | Файл старше                            | `[ file1 -ot file2 ]`            |

---

#### Сравнение строк
| Ключ          | Проверяет                              | Пример                          |
|---------------|----------------------------------------|----------------------------------|
| `-z`          | Строка пустая                          | `[ -z "$var" ]`                 |
| `-n`          | Строка не пустая                       | `[ -n "$var" ]`                 |
| `=` / `==`    | Строки равны                           | `[ "$a" = "$b" ]`               |
| `!=`          | Строки не равны                        | `[ "$a" != "$b" ]`              |

---

#### Сравнение чисел
| Ключ          | Проверяет                              | Пример                          |
|---------------|----------------------------------------|----------------------------------|
| `-eq`         | Равно (`==`)                           | `[ "$a" -eq "$b" ]`             |
| `-ne`         | Не равно (`!=`)                        | `[ "$a" -ne "$b" ]`             |
| `-gt`         | Больше (`>`)                           | `[ "$a" -gt "$b" ]`             |
| `-ge`         | Больше или равно (`>=`)                | `[ "$a" -ge "$b" ]`             |
| `-lt`         | Меньше (`<`)                           | `[ "$a" -lt "$b" ]`             |
| `-le`         | Меньше или равно (`<=`)                | `[ "$a" -le "$b" ]`             |

---

#### Логические операторы
| Ключ          | Действие                               | Пример                          |
|---------------|----------------------------------------|----------------------------------|
| `!`           | Отрицание                              | `[ ! -f file ]`                 |
| `-a`          | Логическое И (`AND`)                   | `[ "$a" -eq 1 -a "$b" -eq 2 ]`  |
| `-o`          | Логическое ИЛИ (`OR`)                  | `[ "$a" -eq 1 -o "$b" -eq 2 ]`  |

> Примечание: В современных скриптах лучше использовать `&&` и `||` вместо `-a`/`-o` (например, `[[ $a -eq 1 && $b -eq 2 ]]`).
---


**3. Логические операторы `&&` (успех) и `||` (неудача) - Цепочки команд:**

*   **`&&` (AND - Успех):** Выполняет следующую команду *только если* предыдущая команда (включая `test`) завершилась *успешно* (код завершения 0).  Думайте об этом как "сделать это *только если* предыдущее сработало".
*   **`||` (OR - Неудача):** Выполняет следующую команду *только если* предыдущая команда (включая `test`) завершилась *неудачно* (код завершения не равен 0). Думайте об этом как "сделать это *только если* предыдущее не сработало".

**4. Ключевое понятие: Код завершения**

Каждая команда в Bash возвращает код завершения.  0 означает успех, любое другое значение - неудачу.  `test` не исключение. Код завершения `test` определяет, будет ли выполняться следующая команда в цепочке, связанной с помощью `&&` или `||`.

**5. Примеры использования `&&` и `||` с `test` и `[ ]`:**

*   **`[ ] && команда`:** Команда выполняется, если условие внутри `[ ]` истинно.

    ```bash
    [ -f myfile.txt ] && echo "Файл существует!"
    # Если файл myfile.txt существует, будет выведено "Файл существует!"
    ```

*   **`[ ] || команда`:** Команда выполняется, если условие внутри `[ ]` ложно.

    ```bash
    [ -f myfile.txt ] || echo "Файл не существует!"
    # Если файл myfile.txt не существует, будет выведено "Файл не существует!"
    ```

*   **Комбинирование `&&` и `||`:** Позволяет строить более сложные цепочки.  Важно понимать порядок выполнения.  Команды выполняются слева направо.

    ```bash
    [ -f myfile.txt ] && echo "Файл есть" && ls -l myfile.txt || echo "Ошибка: файла нет"
    # 1. Если файл существует, выводит "Файл есть"
    # 2. Если предыдущая команда (echo) и [ -f myfile.txt ] были успешными, то выполняет ls -l myfile.txt
    # 3. Если что-то пошло не так (файла нет или ls завершился с ошибкой), выводит "Ошибка: файла нет"
    ```

*   **Примеры с переменными:**

    ```bash
    [ -z "$MYVAR" ] && echo "Переменная MYVAR пуста" || echo "Переменная MYVAR не пуста"

    [ "$NUM" -gt 10 ] && echo "Число больше 10" || echo "Число не больше 10"
    ```

**6. Использование с `[[ ]]`:**

Использование `&&` и `||` с `[[ ]]` не меняет логику, но делает код более чистым и безопасным.  Помните, что внутри `[[ ]]` не нужно экранировать многие специальные символы, и можно использовать шаблоны и регулярные выражения.

```bash
[[ -f myfile.txt ]] && echo "Файл существует" || echo "Файла нет"  # Работает точно так же, как с [ ]
```

**7. Примеры практического использования:**

*   **Создание резервной копии файла только если он существует:**

    ```bash
    [ -f important.txt ] && cp important.txt important.txt.bak
    ```

*   **Выполнение команды только если предыдущая команда завершилась успешно:**

    ```bash
    make && ./myprogram  # Запускает myprogram только если make завершился без ошибок
    ```

*   **Проверка и создание директории, если ее нет:**

    ```bash
    [ ! -d mydir ] && mkdir mydir
    ```

*   **Обработка ошибок:**

    ```bash
    ./long_running_process || echo "Ошибка при выполнении long_running_process! Проверьте логи." > error.log
    ```

**8. Продвинутые примеры:**

```bash
# Проверка наличия файла, затем чтение первых 10 строк, иначе вывод сообщения
[ -f mydata.txt ] && head -n 10 mydata.txt || echo "Файл mydata.txt не найден."

# Компиляция и запуск программы, если компиляция прошла успешно, иначе вывод сообщения об ошибке
gcc myprogram.c -o myprogram && ./myprogram || echo "Ошибка компиляции!"

# Создание каталога, если он не существует, и переход в него, если создание прошло успешно
[ ! -d mynewdir ] && mkdir mynewdir && cd mynewdir || echo "Не удалось создать или перейти в каталог mynewdir."
```

**9. Важные моменты:**

*   `&&` и `||` работают на основе *кода завершения* предыдущей команды, а не на основе *вывода* команды.
*   `0` - успех, любое другое значение - неудача.
*   Используйте `[[ ]]` для более безопасного и читаемого кода, особенно при работе со строками и шаблонами.
*   `&&` и `||` выполняются слева направо.
*   Кавычки вокруг переменных по-прежнему важны для предотвращения проблем.

**10. Заключение:**

Совместное использование `test` (или `[ ]`/`[[ ]]`) с логическими операторами `&&` и `||` – это мощный способ создания условных цепочек команд в Bash.  Это позволяет выполнять определенные действия только при выполнении определенных условий или обрабатывать ошибки, возникающие в процессе выполнения скрипта.  Понимание этих концепций необходимо для написания эффективных и надежных Bash скриптов.
