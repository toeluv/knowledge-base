## Bash: Основы (bashrc, аргументы функций)

### 1. `bashrc` - Конфигурационный файл для Bash

*   **Что такое `bashrc`?**
    *   Это файл конфигурации для интерактивной оболочки Bash.
    *   Выполняется каждый раз при запуске новой сессии Bash (например, при открытии терминала).
    *   Позволяет настроить поведение оболочки и определить пользовательские настройки.

*   **Расположение:**
    *   Обычно находится в домашней директории пользователя: `~/.bashrc` (точка в начале скрывает файл).

*   **Основные возможности и применения:**
    *   **Настройка переменных окружения:**
        *   `export PATH="$PATH:/путь/к/вашей/команде"` - добавление пути к исполняемым файлам.
        *   `export EDITOR=vim` - настройка редактора по умолчанию.
        *   `export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64` - установка переменных для Java.
    *   **Определение псевдонимов (aliases):**
        *   `alias ls='ls -lha'` - создание короткого имени для часто используемой команды с опциями.
        *   `alias cd='cd -P'` - добавление функциональности.
    *   **Настройка приглашения командной строки (prompt):**
        *   `PS1="..."` - установка формата приглашения (например, отображение текущей директории, имени пользователя, времени).
    *   **Определение функций:**
        *   `function my_function { ... }` - определение пользовательских функций (см. ниже).
    *   **Загрузка других скриптов:**
        *   `source ~/.bash_profile` или `. ~/.bash_profile` - загрузка других конфигурационных файлов.

*   **Пример `.bashrc`:**

```bash
# Настройка переменных окружения
export PATH="$PATH:/usr/local/bin:/opt/my-tools"
export EDITOR=nano

# Определение псевдонимов
alias la='ls -la'
alias grep='grep --color=auto'

# Настройка приглашения командной строки
PS1="\[\e[32m\]\u@\h \W \[\e[34m\]\$ \[\e[0m\]"

# Определение функции
my_hello() {
  echo "Hello, $1!" # $1 - первый аргумент функции
}
```

*   **Применение изменений:**
    *   После внесения изменений в `.bashrc` необходимо перезапустить терминал или выполнить команду:
        *   `source ~/.bashrc`  (или  `. ~/.bashrc`)  - для применения изменений в текущей сессии.

### 2. Аргументы функций в Bash

*   **Объявление функции:**
    ```bash
    function my_function {
      # Тело функции
    }
    # или
    my_function() {
      # Тело функции
    }
    ```

*   **Передача аргументов:**
    *   Аргументы передаются в функцию через пробелы после имени функции.
    *   Внутри функции аргументы доступны через специальные переменные:
        *   `$1` - первый аргумент
        *   `$2` - второй аргумент
        *   `$3` - третий аргумент
        *   и так далее...
        *   `$0` - имя функции
        *   `$@` - все аргументы (в виде отдельных строк)
        *   `$*` - все аргументы (в виде одной строки, разделенной пробелами)
        *   `$#` - количество аргументов

*   **Пример функции с аргументами:**

```bash
my_print() {
  echo "Первый аргумент: $1"
  echo "Второй аргумент: $2"
  echo "Все аргументы: $@"
  echo "Количество аргументов: $#"
}

# Вызов функции
my_print "Привет" "Мир"
# Output:
# Первый аргумент: Привет
# Второй аргумент: Мир
# Все аргументы: Привет Мир
# Количество аргументов: 2
```

*   **Обработка ошибок:**
    *   Функции могут возвращать код завершения, используя `return`.
    *   Код завершения `0` означает успешное выполнение, другие значения - ошибки.
    *   Проверить код завершения можно с помощью `$?`:
        ```bash
        my_function() {
          if [ $1 -eq 0 ]; then
            return 0 # Успех
          else
            echo "Ошибка!"
            return 1 # Ошибка
          fi
        }

        my_function 1
        echo "Код завершения: $?" # Output: 1
        ```

*   **Пример использования `$@` и `$*`:**

```bash
print_args() {
  echo "Аргументы через \$@ (цикл):"
  for arg in "$@"; do  #  Используем кавычки для сохранения пробелов в аргументах
    echo "  -$arg-"
  done

  echo "Аргументы через \$* (как одна строка):"
  echo "  -$*-"
}

print_args "аргумент 1" "аргумент 2 с пробелами"  "аргумент3"
```

*   **Результат вызова вышеприведенной функции:**

```
Аргументы через $@ (цикл):
  -аргумент 1-
  -аргумент 2 с пробелами-
  -аргумент3-
Аргументы через $* (как одна строка):
  -аргумент 1 аргумент 2 с пробелами аргумент3-
```

**В заключение:**

Понимание `bashrc` и аргументов функций является фундаментом для настройки и автоматизации в Bash.  Это позволяет упростить ежедневную работу, повысить продуктивность и создавать более сложные скрипты. Регулярное использование и практика - ключ к овладению этими концепциями.
