## Когда ставить `;` в Bash?
`;` разделяет команды, **игнорируя их успешность** (в отличие от `&&` и `||`).

### **Где нужно `;`?**
#### **(1) Разделение команд в одной строке**
```bash
echo "Привет"; ls; pwd  # Выполнит все 3 команды подряд
```

#### **(2) В `case` перед `)`**
```bash
case $var in
  start) echo "Запуск..." ;;  # Обязательно ;;
  stop)  echo "Остановка" ;;
esac
```

#### **(3) В `for`/`while` в одной строке**
```bash
for i in {1..3}; do echo $i; done
while true; do echo "Цикл"; sleep 1; done
```

### **Где `;` НЕ нужна?**
- Если команды на разных строках:
  ```bash
  echo "Привет"  # ; не нужна
  ls
  ```
- В двойных скобках `[[ ]]` (там работают `&&`, `||` без `;`):
  ```bash
  [[ -f file.txt && -r file.txt ]]  # Правильно
  [[ -f file.txt; -r file.txt ]]    # Ошибка!
  ```

---

## **3. Разница между `;`, `&&`, `||`**
| Оператор | Действие | Пример |
|----------|----------|--------|
| `;`  | Выполняет команды **последовательно** | `cmd1; cmd2` → выполнятся обе |
| `&&` | Выполняет `cmd2` **только если `cmd1` успешна** | `mkdir dir && cd dir` |
| `||` | Выполняет `cmd2` **только если `cmd1` провалилась** | `ping host || echo "Ошибка"` |

---

## **Итог:**
- **Подстановка команд** — `$(...)` для вставки вывода.
- **`;`** — разделитель команд (не зависит от успеха/ошибки).
- **`&&`/`||`** — управление выполнением в зависимости от результата.

Пример без `if`:
```bash
[[ -f file.txt ]] && echo "Файл есть" || echo "Файла нет"
```
