## Перенаправление вввода и вывода в циклах

В этой конструкции:

```bash
while read line; do
    echo "Строка: $line"
done < файл.txt
```

происходит следующее:

1. `while read line` - начинает цикл while, где на каждой итерации команда `read` читает одну строку из входного потока и сохраняет её в переменную `line`

2. `do ... done` - тело цикла, которое выполняется для каждой прочитанной строки

3. `< файл.txt` - перенаправление ввода. Весь цикл while получает входные данные из указанного файла (в данном случае "файл.txt")

Таким образом, этот код:
- Открывает файл "файл.txt"
- Построчно читает его содержимое
- Для каждой строки выполняет команды в теле цикла (в данном случае просто выводит строку с префиксом "Строка: ")
- Автоматически завершается, когда достигается конец файла

Важные особенности:
- Строки читаются последовательно, по одной за итерацию
- Пустые строки также обрабатываются
- Если файл не существует, цикл не выполнится ни разу
- Перенаправление `<` делается для всего цикла while, а не только для команды read

Это идиоматический способ построчной обработки файлов в bash.

## Перенаправление вывода в цикле while

К предыдущему конспекту добавим информацию о перенаправлении вывода:

### 1. Перенаправление вывода всего цикла в файл

```bash
while read line; do
    echo "Строка: $line"
done < файл.txt > результат.txt
```

Здесь:
- `< файл.txt` - входные данные берутся из этого файла
- `> результат.txt` - весь вывод цикла перенаправляется в этот файл (перезаписывается, если существует)

### 2. Добавление вывода цикла в конец файла

```bash
while read line; do
    echo "Строка: $line"
done < файл.txt >> результат.txt
```

`>>` означает добавление в конец файла вместо перезаписи

### 3. Перенаправление вывода внутри тела цикла

```bash
while read line; do
    echo "Строка: $line" >> лог.txt
    grep "$line" /var/log/syslog > "архивы/${line}.log"
done < файл.txt
```

Здесь:
- Каждое сообщение "Строка..." добавляется в лог.txt
- Для каждой строки создается отдельный файл с результатами grep

### 4. Перенаправление и stderr, и stdout

```bash
while read line; do
    команда_которая_может_дать_ошибку "$line"
done < вход.txt > вывод.log 2> ошибки.log
```

Или объединить stderr и stdout в один поток:

```bash
while read line; do
    команда "$line"
done < вход.txt > вывод_и_ошибки.log 2>&1
```

### 5. Перенаправление в другой процесс (pipeline)

```bash
while read line; do
    обработка "$line"
done < вход.txt | grep "шаблон" | sort > результат.txt
```

### Важные замечания:

1. Перенаправление всего цикла (`done > файл`) эффективнее, чем перенаправление каждой команды внутри цикла

2. При использовании `>` внутри цикла файл будет открываться и закрываться на каждой итерации, что может снижать производительность

3. Для записи в несколько файлов внутри цикла используйте `exec` с дескрипторами:

```bash
exec 3>файл1.txt
exec 4>файл2.txt

while read line; do
    echo "$line" >&3
    echo "${line^^}" >&4
done < вход.txt

exec 3>&-
exec 4>&-
```

Этот пример открывает два файла для записи до начала цикла и использует дескрипторы 3 и 4 для записи.
