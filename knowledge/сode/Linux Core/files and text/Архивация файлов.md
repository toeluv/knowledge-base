# Архиваторы в Linux: Сжатие и Архивация

Этот конспект посвящен архиваторам в Linux, акцентируя внимание на тех, что предназначены для работы с несколькими файлами, а затем переходя к утилитам, сжимающим отдельные файлы.

**dl;dr: Основные архиваторы Linux: `tar` и `zip`**

# tar (tarball): Для архивации (объединения файлов и каталогов в один файл).  Часто используется в комбинации с утилитами сжатия.

# Примеры:
```bash
tar -cf archive.tar file1.txt file2.txt directory1  # Создать архив archive.tar (-c создать, -f имя)
tar -xzf archive.tar.gz  # Извлечь из архива archive.tar.gz (-x извлечь, -z gzip)
tar -cjf archive.tar.bz2 file1.txt directory1  # Создать архив и сжать bzip2 (-j bzip2)
tar -xzf archive.tar.gz -C /tmp/extract  # Извлечь в указанный каталог /tmp/extract (-C каталог)
tar -tf archive.tar  # Посмотреть содержимое архива (-t list)
tar -czf archive.tar.gz --exclude=*.log directory1  # Сжать и исключить файлы .log (--exclude)
```

# zip: Для создания ZIP-архивов (включает архивацию и сжатие).  Совместим с Windows.

# Примеры:
```bash
zip archive.zip file1.txt file2.txt  # Создать zip-архив archive.zip
zip -r archive.zip directory1  # Создать zip-архив рекурсивно (-r рекурсивно)
zip -u archive.zip file3.txt  # Добавить/обновить файл (-u update)
zip -d archive.zip file2.txt  # Удалить файл (-d delete)
```

## 1. `tar` - Архивация (создание архивных файлов) и сочетание с утилитами сжатия

*   **Описание:**  Утилита для создания, извлечения и модификации архивных файлов.  Основное назначение - объединение нескольких файлов и каталогов в один архив.  `tar` сама по себе не сжимает данные; для сжатия используется в сочетании с утилитами сжатия ( `gzip`, `bzip2`, `xz`).
*   **Синтаксис:** `tar [OPTIONS] [file]`
*   **Основные опции:**
    *   `-c` или `--create`: Создание архива.
    *   `-x` или `--extract`: Извлечение файлов из архива.
    *   `-f archive_file`: Указание имени архивного файла (обязательно для большинства операций).  `archive_file` - путь к архиву.
    *   `-v` или `--verbose`: Подробный вывод (отображение файлов, обрабатываемых `tar`).
    *   `-t` или `--list`:  Вывод содержимого архива (список файлов).
    *   `-z` или `--gzip`:  Сжатие/распаковка с помощью `gzip` (создает архивы `.tar.gz` или `.tgz`).
    *   `-j` или `--bzip2`:  Сжатие/распаковка с помощью `bzip2` (создает архивы `.tar.bz2` или `.tbz2`).
    *   `-J` или `--xz`: Сжатие/распаковка с помощью `xz` (создает архивы `.tar.xz` или `.txz`).
    *   `-C directory`: Извлечение файлов в указанный каталог.
    *   `-p` или `--preserve-permissions`: Сохранение прав доступа к файлам при извлечении.
    *   `-u` или `--update`: Добавление в архив только тех файлов, которые новее, чем файлы в архиве.
    *   `-A` или `--concatenate`:  Добавление архивных файлов к существующему архиву.
    *   `--exclude=pattern`: Исключение файлов, соответствующих шаблону, из архива.
*   **Примеры:**
    *   **Создание архива (без сжатия):**
        ```bash
        tar -cf archive.tar file1.txt file2.txt directory1
        ```
        Создает архив `archive.tar`, содержащий `file1.txt`, `file2.txt` и `directory1` (и все его содержимое).
    *   **Создание архива и сжатие с помощью gzip:**
        ```bash
        tar -czf archive.tar.gz file1.txt file2.txt directory1
        ```
        Создает сжатый архив `archive.tar.gz`.  `-c` - создать архив, `-z` - использовать gzip, `-f archive.tar.gz` - имя архива.
    *   **Создание архива и сжатие с помощью bzip2:**
        ```bash
        tar -cjf archive.tar.bz2 file1.txt file2.txt directory1
        ```
        Создает сжатый архив `archive.tar.bz2`.  `-j` - использовать bzip2.
    *   **Создание архива и сжатие с помощью xz:**
        ```bash
        tar -cJf archive.tar.xz file1.txt file2.txt directory1
        ```
        Создает сжатый архив `archive.tar.xz`.  `-J` - использовать xz.
    *   **Извлечение файлов из архива (без сжатия):**
        ```bash
        tar -xf archive.tar
        ```
        Извлекает файлы из `archive.tar` в текущий каталог.
    *   **Извлечение файлов из архива, сжатого с помощью gzip:**
        ```bash
        tar -xzf archive.tar.gz
        ```
        Извлекает файлы из `archive.tar.gz` в текущий каталог.  `-x` - извлечь, `-z` - использовать gzip.
    *   **Извлечение файлов из архива в определенный каталог:**
        ```bash
        tar -xzf archive.tar.gz -C /tmp/extract
        ```
        Извлекает файлы из `archive.tar.gz` в каталог `/tmp/extract`.  `-C /tmp/extract` - извлечь в указанный каталог.
    *   **Просмотр содержимого архива:**
        ```bash
        tar -tf archive.tar.gz
        ```
        Выводит список файлов, содержащихся в `archive.tar.gz`.  `-t` - просмотреть (list).
    *   **Исключение файлов из архива:**
        ```bash
        tar -czf archive.tar.gz --exclude=*.log --exclude=temp_directory file1.txt directory1
        ```
        Создает сжатый архив, исключая все файлы с расширением `.log` и каталог `temp_directory`.
    *   **Обновление архива (добавление новых файлов):**
        ```bash
        tar -uf archive.tar file3.txt
        ```
        Добавляет в архив `archive.tar` файл `file3.txt`, если он существует и новее, чем в архиве.
    *   **Объединение архивов:**
        ```bash
        tar -Af archive_main.tar archive_add.tar
        ```
        Добавляет содержимое архива `archive_add.tar` к архиву `archive_main.tar`.

## 2. `zip` - Архивация (ZIP-архивы)

*   **Описание:** Утилита для создания и управления ZIP-архивами.  Создает архивы с расширением `.zip`.  В отличие от `tar`, сама выполняет и архивацию, и сжатие.
*   **Синтаксис:** `zip [OPTIONS] archive_name file1 file2 ...`
*   **Основные опции:**
    *   `-r`: Рекурсивная архивация (включая подкаталоги).
    *   `-d`: Удаление файлов из архива.
    *   `-u`: Обновление архива (добавление или обновление файлов).
    *   `-9`: Максимальный уровень сжатия.
    *   `-x`: Исключение файлов из архива.
*   **Примеры:**
    *   `zip archive.zip file1.txt file2.txt`:  Создать zip-архив `archive.zip`, содержащий `file1.txt` и `file2.txt`.
    *   `zip -r archive.zip directory1`:  Создать zip-архив `archive.zip`, содержащий `directory1` и все его содержимое.
    *   `zip -r -9 archive.zip directory1`: Создать zip-архив с максимальным сжатием.
    *   `zip -d archive.zip file2.txt`: Удалить `file2.txt` из архива `archive.zip`.
    *   `zip -u archive.zip file3.txt`: Добавить или обновить `file3.txt` в `archive.zip`.
    *   `zip -x "*.log" -r archive.zip .`: Заархивировать все файлы и папки, исключая `.log` файлы
*   **Недостатки:**  Некоторые продвинутые функции `tar` (например, сохранение особых прав доступа) могут быть недоступны в `zip`.

## 3. `unzip` - Распаковка ZIP-архивов

*   **Описание:** Утилита для распаковки ZIP-архивов.
*   **Синтаксис:** `unzip [OPTIONS] archive.zip`
*   **Основные опции:**
    *   `-d directory`: Извлечение файлов в указанный каталог.
    *   `-l`:  Список содержимого архива.
    *   `-x pattern`:  Исключение файлов, соответствующих шаблону, из извлечения.
*   **Примеры:**
    *   `unzip archive.zip`:  Извлечь файлы из `archive.zip` в текущий каталог.
    *   `unzip archive.zip -d /tmp/extract`:  Извлечь файлы в каталог `/tmp/extract`.
    *   `unzip -l archive.zip`:  Вывести список файлов в архиве `archive.zip`.
    *   `unzip archive.zip -x "*.log"`:  Извлечь все файлы из архива `archive.zip`, за исключением файлов с расширением `.log`.

## 4. Утилиты для сжатия отдельных файлов:

Эти утилиты в основном предназначены для сжатия отдельных файлов.  Они не могут работать непосредственно с несколькими файлами или каталогами, но их можно использовать совместно с `tar`.

### 4.1. `gzip` - Сжатие файлов (одиночных)

*   **Описание:** Утилита для сжатия отдельных файлов с использованием алгоритма DEFLATE. Создает файлы с расширением `.gz`.  Не умеет архивировать несколько файлов в один архив; предназначена для сжатия одиночных файлов.
*   **Синтаксис:** `gzip [OPTIONS] file`
*   **Основные опции:**
    *   `-d` или `--decompress`: Распаковка (декомпрессия) файла.
    *   `-c` или `--stdout`: Вывод сжатого результата в стандартный вывод (stdout).
    *   `-v` или `--verbose`: Подробный вывод (отображение информации о процессе сжатия/распаковки).
    *   `-N` или `--name`: Сохранение исходного имени файла и даты/времени в сжатом файле.
    *   `-<number>`: Уровень сжатия (1 - быстрый, 9 - максимальный, 6 - по умолчанию).
*   **Примеры:**
    *   `gzip file.txt`: Сжать `file.txt`, создав `file.txt.gz` и удалив исходный файл.
    *   `gzip -d file.txt.gz`: Распаковать `file.txt.gz`, создав `file.txt` и удалив архив.
    *   `gzip -c file.txt > file.txt.gz`: Сжать `file.txt` и сохранить сжатый вывод в `file.txt.gz`, оставив исходный файл.
    *   `gzip -v -9 file.txt`: Сжать `file.txt` с максимальным уровнем сжатия и отображением подробной информации.
    *   `cat file.txt | gzip > file.txt.gz` - сжать файл с использованием cat.
*   **Недостатки:** Не архивирует несколько файлов; только сжимает один.

### 4.2. `gunzip` - Распаковка файлов `.gz`

*   **Описание:** Утилита для распаковки файлов, сжатых с помощью `gzip`.
*   **Синтаксис:** `gunzip [OPTIONS] file.gz`
*   **Основные опции:** (Аналогичны `-d` и другим опциям `gzip`)
    *   `-c`: Вывод распакованного содержимого в стандартный вывод (stdout).
    *   `-v`: Подробный вывод.
*   **Примеры:**
    *   `gunzip file.txt.gz`: Распаковать `file.txt.gz`, создав `file.txt` (или перезаписав его, если он уже существует) и удалив архив.
    *   `gunzip -c file.txt.gz > file.txt`:  Распаковать файл в stdout и перенаправить результат в `file.txt`, сохранив архив.
*   `gzip` и `gunzip` часто используются в сочетании с другими утилитами через перенаправление (`|`).

### 4.3. `bzip2` - Сжатие файлов (с более высокой степенью, чем gzip)

*   **Описание:** Утилита для сжатия файлов с использованием алгоритма Burrows-Wheeler Transform.  Обеспечивает более высокую степень сжатия, чем `gzip`, но медленнее. Создает файлы с расширением `.bz2`.  Как и `gzip`, предназначена для сжатия одного файла.
*   **Синтаксис:** `bzip2 [OPTIONS] file`
*   **Основные опции:**
    *   `-d` или `--decompress`: Распаковка.
    *   `-c` или `--stdout`: Вывод сжатого результата в stdout.
    *   `-v` или `--verbose`: Подробный вывод.
    *   `-z`: Сжатие.
    *   `-k` или `--keep`: Сохранить исходный файл (не удалять его после сжатия/распаковки).
    *   `-1` - `-9`: Уровень сжатия (1 - быстрый, 9 - максимальный).
*   **Примеры:**
    *   `bzip2 file.txt`: Сжать `file.txt`, создав `file.txt.bz2` и удалив исходный файл.
    *   `bzip2 -d file.txt.bz2`: Распаковать `file.txt.bz2`, создав `file.txt` и удалив архив.
    *   `bzip2 -c file.txt > file.txt.bz2`: Сжать файл `file.txt`, сохранив сжатый вывод в файл `file.txt.bz2`, не удаляя исходный файл.
    *   `bzip2 -k file.txt`: Сжать файл и сохранить исходник.
*   **Недостатки:** Так же, как и `gzip`, не предназначена для архивирования нескольких файлов.

### 4.4. `bunzip2` - Распаковка файлов `.bz2`

*   **Описание:** Утилита для распаковки файлов, сжатых с помощью `bzip2`.
*   **Синтаксис:** `bunzip2 [OPTIONS] file.bz2`
*   **Примеры:**
    *   `bunzip2 file.txt.bz2`: Распаковать `file.txt.bz2`.
    *   `bunzip2 -c file.txt.bz2 > file.txt`:  Распаковать и перенаправить вывод.

### 4.5. `xz` - Сжатие файлов (с лучшей степенью сжатия, чем bzip2)

*   **Описание:** Утилита для сжатия файлов с использованием алгоритма LZMA/LZMA2.  Обеспечивает еще более высокую степень сжатия, чем `bzip2` и `gzip`, но медленнее. Создает файлы с расширением `.xz`.  Как и `gzip` и `bzip2`, предназначена для сжатия одного файла.
*   **Синтаксис:** `xz [OPTIONS] file`
*   **Основные опции:**
    *   `-d` или `--decompress`: Распаковка.
    *   `-c` или `--stdout`: Вывод сжатого результата в stdout.
    *   `-v` или `--verbose`: Подробный вывод.
    *   `-k` или `--keep`: Сохранить исходный файл.
    *   `-z`: Сжатие.
    *   `-0` - `-9`: Уровень сжатия (0 - быстрый, 9 - максимальный).
*   **Примеры:**
    *   `xz file.txt`: Сжать `file.txt`.
    *   `xz -d file.txt.xz`: Распаковать `file.txt.xz`.
*   **Недостатки:** Не предназначена для архивирования нескольких файлов.

### 4.6. `unxz` - Распаковка файлов `.xz`

*   **Описание:** Утилита для распаковки файлов, сжатых с помощью `xz`.
*   **Синтаксис:** `unxz [OPTIONS] file.xz`
*   **Примеры:**
    *   `unxz file.txt.xz`: Распаковать `file.txt.xz`.

| Утилита   | Расширение      | Сжатие/Архивация           | Распаковка             | Особенности                                    |
| :-------- | :--------------- | :-------------------------- | :--------------------- | :--------------------------------------------- |
| `tar`     | `.tar`, `.tar.gz`, `.tar.bz2`, `.tar.xz`, `.tgz`, `.tbz2`, `.txz` | Архивация (без/с gzip/bzip2/xz) | `tar` (с опциями)     | Мощная архивация, объединение файлов и каталогов.  Не выполняет сжатие без опций `-z`, `-j`, `-J`. |
| `zip`     | `.zip`          | Архивация и сжатие (ZIP)   | `unzip`                |  Популярный формат, кроссплатформенная совместимость. |
| `gzip`    | `.gz`           | Сжатие (одиночных файлов)   | `gunzip`               | Быстрое сжатие                                 |
| `bzip2`   | `.bz2`          | Сжатие (одиночных файлов)   | `bunzip2`              | Более высокая степень сжатия, чем `gzip`      |
| `xz`      | `.xz`           | Сжатие (одиночных файлов)   | `unxz`                 | Наиболее высокая степень сжатия, медленнее   |

**Важные моменты:**

*   Выбор архиватора зависит от требуемой степени сжатия, скорости и совместимости.
*   Для большинства задач архивации (резервное копирование, распространение файлов) комбинация `tar` и утилиты сжатия ( `gzip`, `bzip2`, `xz`) является наиболее универсальным решением.
*   `zip` удобен для работы с ZIP-архивами, особенно при обмене файлами с пользователями Windows.
*   Всегда проверяйте результат архивации/распаковки.
*   Помните об экранировании специальных символов при работе с именами файлов.
