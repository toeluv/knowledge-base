# Групповые символы (Globbing) в Linux

Групповые символы, или "globbing", - это специальные символы, которые используются в командной строке Linux (и других Unix-подобных системах) для подстановки имен файлов, соответствующих определенному шаблону.  Это позволяет выполнять операции сразу над несколькими файлами, не перечисляя их имена вручную.  Globbing выполняется оболочкой (shell) перед тем, как команда будет запущена.

## Основные групповые символы:

1.  **`*` (Звездочка):**

    *   Соответствует любому количеству символов (включая отсутствие символов).
    *   **Примеры:**
        *   `ls *.txt`:  Выводит список всех файлов с расширением `.txt`.
        *   `rm image*.jpg`:  Удаляет все файлы, начинающиеся с "image" и имеющие расширение `.jpg`.
        *   `cp backup* /destination`:  Копирует все файлы, начинающиеся с "backup", в каталог `/destination`.
        *   `*.txt`: соответствует "file.txt", "my_file.txt", "a.b.c.txt", "" (если globstar включен и директория пуста, что обычно нежелательно)
        *   `*`: соответствует любому файлу и каталогу в текущей директории.
2.  **`?` (Вопросительный знак):**

    *   Соответствует ровно одному любому символу.
    *   **Примеры:**
        *   `ls file?.txt`:  Выводит список файлов, имена которых начинаются с "file", затем идет ровно один любой символ, и расширение `.txt` (например, `file1.txt`, `filea.txt`).
        *   `rm data??.log`: Удаляет файлы с именем data, за которым следуют два любых символа и расширение .log (data01.log, dataAB.log).
3.  **`[]` (Квадратные скобки):**

    *   Соответствует одному символу, входящему в указанный набор или диапазон символов.
    *   **Примеры:**
        *   `ls file[123].txt`:  Выводит список файлов с именами `file1.txt`, `file2.txt` или `file3.txt`.
        *   `ls data[a-z].log`:  Выводит список файлов, начинающихся с `data`, за которыми следует одна строчная буква, и имеющих расширение `.log` (например, `dataa.log`, `datab.log`).
        *   `ls image[0-9][0-9].jpg`:  Выводит список файлов, начинающихся с `image`, за которыми следуют две цифры, и имеющих расширение `.jpg` (например, `image01.jpg`, `image99.jpg`).
        *   `ls file[!abc].txt`: Выводит список файлов, имена которых начинаются с "file", затем следует ровно один символ, *не* являющийся a, b или c, и расширение `.txt`. Символ `!` внутри скобок означает "отрицание" или "исключение". Эквивалентно `file[^abc].txt`.
        *  `ls file[[:digit:]].txt`: Выводит список файлов, имена которых начинаются с "file", затем следует ровно одна цифра, и расширение `.txt`. `[:digit:]` является предопределенным классом символов (цифры). Другие классы: `[:alpha:]` (буквы), `[:upper:]` (прописные буквы), `[:lower:]` (строчные буквы), `[:alnum:]` (буквы и цифры), `[:space:]` (пробельные символы).
4.  **`{}` (Фигурные скобки):**

    *   Позволяет генерировать несколько вариантов имен файлов.
    *   **Примеры:**
        *   `cp file.{txt,bak} /destination`:  Копирует `file.txt` и `file.bak` в каталог `/destination`.  Эквивалентно `cp file.txt file.bak /destination`.
        *   `mkdir project_{src,bin,doc}`:  Создает три каталога: `project_src`, `project_bin` и `project_doc`.
        *   `touch file{1..5}.txt`: Создает файлы `file1.txt`, `file2.txt`, `file3.txt`, `file4.txt`, `file5.txt`.
        *   `rm image_{001..010..2}.jpg`: удаляет файлы `image_001.jpg`, `image_003.jpg`, `image_005.jpg`, `image_007.jpg`, `image_009.jpg`

## Особенности и важные замечания:

*   **Чувствительность к регистру:**  Globbing обычно чувствителен к регистру (зависит от настроек системы).  Например, `*.txt` не будет соответствовать `*.TXT`.
*   **Скрытые файлы:**  Групповые символы не соответствуют файлам, начинающимся с точки (`.`), если точка не указана явно. Например, `ls *` не покажет `.hidden_file`, но `ls .*` покажет.
*   **Безопасность:**  Будьте осторожны при использовании групповых символов с командами, которые могут изменять файлы (например, `rm`).  Всегда проверяйте, какие файлы будут затронуты, прежде чем выполнять команду.
*   **Экранирование:**  Если вам нужно использовать групповой символ как обычный символ (а не для подстановки имен файлов), его нужно экранировать с помощью обратного слеша (`\`). Например, `ls file\*.txt` будет искать файл с именем `file*.txt`.
*   **`globstar` (Опция bash):**

    *   Если включена опция `globstar` в bash (с помощью команды `shopt -s globstar`), двойная звездочка `**` соответствует файлам и каталогам рекурсивно, то есть во всех подкаталогах.
    *   **Пример:**
        *   `ls **/*.txt`:  Выводит список всех файлов с расширением `.txt` во всех подкаталогах текущего каталога.
    *   Проверка состояния опции: `shopt globstar`.
    *   Включение/выключение опции: `shopt -s globstar` / `shopt -u globstar`.  Обычно эта опция не включена по умолчанию.

## Примеры использования:

*   **Переименование файлов:**
    ```bash
    for file in *.jpg; do
      new_name=$(echo "$file" | tr ' ' '_')
      mv "$file" "$new_name"
    done
    ```
    Этот скрипт переименовывает все файлы с расширением `.jpg`, заменяя пробелы в именах файлов на символы подчеркивания.
*   **Поиск файлов по дате изменения:**
    ```bash
    find . -name "*.txt" -mtime -7
    ```
    Этот скрипт находит все файлы с расширением `.txt`, измененные в течение последних 7 дней.

Групповые символы - это мощный инструмент для работы с файлами в командной строке Linux. Понимание и умелое использование этих символов значительно упрощает и ускоряет выполнение многих задач.
