## Работа с текстом

### Пример регулярных выражений:
`ls -a` → вывод: sda, sd0, sd1
`ls -a sd[abcd]` → вывод: sda (только соответствующие шаблону)

### `grep` - поиск текста

`grep [опции] шаблон файл`

Опции:
- `-i` - игнорировать регистр
- `-v` - инвертировать совпадения
- `-r` - рекурсивный поиск
- `-n` - показывать номера строк
- `-l` - показывать только имена файлов

Примеры:
`grep "error" log.txt`
`grep -r "function" /path/to/code/`
`grep -i "warning" system.log`

---
### `tail` - вывод конца файла

`tail [опции] файл`

Опции:
- `-n N` - показать последние N строк
- `-f` - следить за изменениями файла
- `-F` - как `-f`, но переоткрывает файл при ротации

Примеры:
`tail -n 20 access.log`
`tail -f /var/log/syslog`
`tail -F growing_file.log`

---

### `head` - вывод начала файла

`head [опции] файл`

Опции:
- `-n N` - показать первые N строк
- `-c N` - показать первые N байт

Примеры:
`head -n 5 data.csv`
`head -c 100 binary.file`
`head /etc/passwd`

---

### `cat` - объединение и вывод файлов

`cat [опции] файл1 файл2...`

Опции:
- `-n` - нумеровать строки
- `-b` - нумеровать непустые строки
- `-s` - сжимать пустые строки

Примеры:
`cat file.txt`
`cat file1.txt file2.txt > combined.txt`
`cat -n script.py`

---

### `less` - просмотр файлов с прокруткой

`less [опции] файл`

Опции:
- `-N` - показывать номера строк
- `-S` - обрезать длинные строки
- `-i` - игнорировать регистр при поиске

Примеры:
`less large_file.log`
`less -N config.conf`
`dmesg | less`

---

### `more` - постраничный просмотр

`more [опции] файл`

Опции:
- `-d` - показывать подсказки
- `-N` - отображать N строк на странице

Примеры:
`more long_text.txt`
`ls -la | more`
`more -10 /etc/services`

---

### `tee` - вывод в файл и на экран

`tee [опции] файл`

Опции:
- `-a` - дописывать в файл (не перезаписывать)
- `-i` - игнорировать прерывания

Примеры:
`echo "test" | tee output.txt`
`dmesg | tee -a system.log`
`sudo make install | tee build.log`

### `cut` - Выделение секций из каждой строки файла

*   **Описание:** Вырезает определенные секции (поля или символы) из каждой строки входного файла.
*   **Синтаксис:** `cut [OPTIONS] file`
*   **Примеры:**
    *   `cut -d ':' -f 1 /etc/passwd`: Вырезать первое поле (имя пользователя) из файла `/etc/passwd`, используя `:` в качестве разделителя.
    *   `cut -c 1-10 file.txt`: Вырезать символы с 1 по 10 из каждой строки файла `file.txt`.
    *   `cut -c -5 file.txt`: Вырезать символы с начала строки до 5.
    *   `cut -c 5- file.txt`: Вырезать символы с 5 до конца строки.
    *   `cut -f 2,4 -d ',' data.csv`:  Вырезать 2-е и 4-е поля, разделитель запятая.

### `expand` - Преобразование табуляций в пробелы

*   **Описание:**  Преобразует символы табуляции в пробелы.
*   **Синтаксис:** `expand [OPTIONS] file`
*   **Примеры:**
    *   `expand file.txt`:  Преобразовать табуляции в пробелы (по умолчанию, длина табуляции 8 пробелов).
    *   `expand -t 4 file.txt`:  Преобразовать табуляции в 4 пробела.
    *   `expand -i file.txt`: Преобразовать только начальные табуляции в каждой строке.

### `fmt` - Простое форматирование текста

*   **Описание:**  Переформатирует текст для выравнивания строк по заданной ширине.
*   **Синтаксис:** `fmt [OPTIONS] file`
*   **Примеры:**
    *   `fmt file.txt`:  Переформатировать текст в файле `file.txt` (ширина строки по умолчанию 75 символов).
    *   `fmt -w 60 file.txt`:  Переформатировать текст в файле `file.txt` с шириной строки 60 символов.
    *   `fmt -s file.txt`:  Разделять строки только на пробелах, а не обрезать слова.

### `join` - Объединение строк двух файлов на основе общего поля

*   **Описание:** Объединяет строки двух файлов на основе общего поля (по умолчанию, первое поле).
*   **Синтаксис:** `join [OPTIONS] file1 file2`
*   **Примеры:**
    *   `join file1.txt file2.txt`: Объединить файлы `file1.txt` и `file2.txt` по первому общему полю.
    *   `join -1 2 -2 1 file1.txt file2.txt`:  Использовать второе поле из `file1.txt` и первое поле из `file2.txt` для объединения. `-1 2` означает "использовать 2-е поле из первого файла", `-2 1` означает "использовать 1-е поле из второго файла".
    *   `join -t ',' file1.csv file2.csv`:  Использовать запятую в качестве разделителя полей.
    *   `join -a 1 file1.txt file2.txt`:  Показать все строки из `file1.txt`, даже если нет соответствия во `file2.txt`.
    *   `join -a 2 file1.txt file2.txt`:  Показать все строки из `file2.txt`, даже если нет соответствия во `file1.txt`.

### `nl` - Нумерация строк файла

*   **Описание:** Нумерует строки файла.
*   **Синтаксис:** `nl [OPTIONS] file`
*   **Примеры:**
    *   `nl file.txt`: Нумерация всех строк файла `file.txt`.
    *   `nl -b a file.txt`: Нумерация всех строк (включая пустые).
    *   `nl -b t file.txt`: Нумерация только непустых строк.
    *   `nl -n ln file.txt`: Выравнивание номеров строк по левому краю.
    *   `nl -s ": " file.txt`: Использовать ": " в качестве разделителя между номером строки и текстом.

### `od` - Вывод содержимого файла в различных форматах

*   **Описание:**  Выводит содержимое файла в восьмеричном, шестнадцатеричном, десятичном или другом формате.
*   **Синтаксис:** `od [OPTIONS] file`
*   **Примеры:**
    *   `od -x file.txt`: Вывод в шестнадцатеричном формате.
    *   `od -o file.txt`: Вывод в восьмеричном формате.
    *   `od -c file.txt`: Вывод символов ASCII.
    *   `od -A x -t x1 file.txt`: Шестнадцатеричный дамп с адресами. `-A x` добавляет смещения в шестнадцатеричном виде. `-t x1` выводит каждый байт как один символ в шестнадцатеричном виде.

### `paste` - Объединение строк нескольких файлов в одну строку

*   **Описание:** Объединяет строки нескольких файлов в одну строку, разделяя их табуляцией (по умолчанию).
*   **Синтаксис:** `paste [OPTIONS] file1 file2 ...`
*   **Примеры:**
    *   `paste file1.txt file2.txt`: Объединить строки из `file1.txt` и `file2.txt`.
    *   `paste -d ',' file1.csv file2.csv`:  Использовать запятую в качестве разделителя.
    *   `paste -s file1.txt`:  Объединить все строки `file1.txt` в одну строку (последовательно).

### `pr` - Форматирование файлов для печати

*   **Описание:** Форматирует файлы для печати, добавляя заголовки, номера страниц и другие элементы.
*   **Синтаксис:** `pr [OPTIONS] file`
*   **Примеры:**
    *   `pr file.txt`: Форматировать файл `file.txt` для печати.
    *   `pr -n file.txt`:  Нумеровать строки.
    *   `pr -h "Отчет" file.txt`:  Установить заголовок страницы в "Отчет".
    *   `pr -l 50 file.txt`: Установить длину страницы в 50 строк.
    *   `pr -2 file.txt`: Вывод в две колонки.

### `sed` - Потоковый редактор текста

*   **Описание:** Мощный потоковый редактор текста.  Применяет операции к каждой строке входного потока.
*   **Синтаксис:** `sed [OPTIONS] 'command' file`
*   **Примеры:**
    *   `sed 's/old/new/g' file.txt`: Заменить все вхождения "old" на "new" в каждой строке файла `file.txt` (g - global).
    *   `sed 's/^/# /' file.txt`: Добавить "# " в начало каждой строки (комментирование). `^` - начало строки.
    *   `sed '/pattern/d' file.txt`: Удалить все строки, содержащие "pattern".
    *   `sed -n '2,5p' file.txt`: Вывести строки с 2 по 5. `-n` подавляет автоматический вывод, `p` печатает выбранные строки.
    *   `sed -i 's/old/new/g' file.txt`: Изменить файл `file.txt` на месте (inplace edit). **Будьте осторожны с этой опцией!**
    *   `sed 's/[0-9]//g' file.txt`: Удалить все цифры из каждой строки.
    *   `sed 's/ *$//' file.txt`:  Удалить пробелы в конце каждой строки.

### `sort` - Сортировка строк файла

*   **Описание:**  Сортирует строки файла.
*   **Синтаксис:** `sort [OPTIONS] file`
*   **Примеры:**
    *   `sort file.txt`: Сортировка строк в файле `file.txt` по алфавиту.
    *   `sort -n file.txt`: Сортировка строк, содержащих числа, в числовом порядке.
    *   `sort -r file.txt`: Сортировка в обратном порядке.
    *   `sort -k 2 file.txt`: Сортировка по второму полю (по умолчанию разделитель - пробел).
    *   `sort -t ':' -k 3n file.txt`: Сортировка по третьему полю, используя `:` в качестве разделителя, в числовом порядке.
    *   `sort -u file.txt`:  Вывод только уникальных строк (удаление дубликатов).

### `split` - Разделение файла на несколько частей

*   **Описание:** Разделяет файл на несколько частей.
*   **Синтаксис:** `split [OPTIONS] file [prefix]`
*   **Примеры:**
    *   `split file.txt`: Разделить файл `file.txt` на части по 1000 строк каждая, с префиксом `x` (xaa, xab, xac, ...).
    *   `split -l 200 file.txt part_`: Разделить файл `file.txt` на части по 200 строк каждая, с префиксом `part_` (part_aa, part_ab, part_ac, ...).
    *   `split -b 1M file.txt part_`: Разделить файл `file.txt` на части по 1MB каждая.
    *   `split -d -l 100 file.txt part_`: Использовать числовые суффиксы (part_00, part_01, part_02, ...).

### `tr` - Трансляция или удаление символов

*   **Описание:** Транслирует или удаляет символы.
*   **Синтаксис:** `tr [OPTIONS] set1 [set2]`
*   **Примеры:**
    *   `tr 'a-z' 'A-Z' < file.txt`:  Преобразовать все строчные буквы в прописные. Важно использовать перенаправление ввода `<`.
    *   `tr -d '0-9' < file.txt`: Удалить все цифры из файла.
    *   `tr -s ' ' < file.txt`: Сжать повторяющиеся пробелы в один.
    *   `tr '\n' ' ' < file.txt`: Заменить все переводы строк на пробелы.
    *   `tr -c 'a-zA-Z0-9' '\n' < file.txt`: Заменить все символы, кроме букв и цифр, на перевод строки. `-c` - инвертировать множество set1.

### `unexpand` - Преобразование пробелов в табуляции

*   **Описание:** Преобразует пробелы в табуляции.
*   **Синтаксис:** `unexpand [OPTIONS] file`
*   **Примеры:**
    *   `unexpand file.txt`: Преобразовать пробелы в табуляции (по умолчанию, каждая группа из 8 пробелов заменяется на табуляцию).
    *   `unexpand -t 4 file.txt`: Преобразовать пробелы в табуляции, заменяя каждую группу из 4 пробелов.
    *   `unexpand -a file.txt`: Преобразовать все последовательности пробелов (а не только начальные) в табуляцию.

### `uniq` - Удаление повторяющихся строк

*   **Описание:**  Удаляет повторяющиеся смежные строки из отсортированного файла.
*   **Синтаксис:** `uniq [OPTIONS] file`
*   **Примеры:**
    *   `uniq file.txt`: Удалить повторяющиеся смежные строки из `file.txt`. **Важно: файл должен быть отсортирован!**  Обычно используется в сочетании с `sort`:  `sort file.txt | uniq`.
    *   `uniq -c file.txt`:  Показать количество повторений каждой строки.
    *   `uniq -d file.txt`:  Вывести только повторяющиеся строки.
    *   `uniq -u file.txt`:  Вывести только уникальные строки.
    *   `uniq -i file.txt`: Сравнивать строки без учета регистра.

### `wc` - Подсчет слов, строк и байтов

*   **Описание:**  Подсчитывает количество строк, слов и байтов в файле.
*   **Синтаксис:** `wc [OPTIONS] file`
*   **Примеры:**
    *   `wc file.txt`:  Подсчитать строки, слова и байты в `file.txt`.
    *   `wc -l file.txt`: Подсчитать количество строк.
    *   `wc -w file.txt`: Подсчитать количество слов.
    *   `wc -c file.txt`: Подсчитать количество байтов.
    *   `wc -m file.txt`: Подсчитать количество символов.
    *   `wc -L file.txt`:  Определить длину самой длинной строки.

### `awk` - Обработка текста по шаблонам

*   **Описание:**  Мощный инструмент для обработки текста, основанный на шаблонах.  `awk` сканирует файл построчно, сопоставляет каждую строку с заданными шаблонами и выполняет соответствующие действия.  Каждая строка разделяется на поля, к которым можно обращаться по номеру (`$1`, `$2`, ...).

*   **Синтаксис:** `awk [OPTIONS] 'pattern { action }' file`

*   **Основные концепции:**
    *   `pattern`: Шаблон, которому должна соответствовать строка для выполнения действия.  Если шаблон не указан, действие выполняется для каждой строки.
    *   `action`: Код, который выполняется, если строка соответствует шаблону.  `action` заключается в фигурные скобки `{}`.  Если действие не указано, по умолчанию выполняется `print`.
    *   `$0`:  Вся строка.
    *   `$1`, `$2`, `$3`, ...:  Поля строки, разделенные пробелами (по умолчанию).  Разделитель полей можно изменить с помощью опции `-F`.
    *   `BEGIN`: Специальный шаблон, который выполняется *перед* обработкой первой строки.  Используется для инициализации переменных, печати заголовков и т.д.
    *   `END`: Специальный шаблон, который выполняется *после* обработки последней строки.  Используется для печати итоговых результатов, выполнения заключительных действий и т.д.

*   **Опции:**
    *   `-F separator`: Указать разделитель полей (вместо пробела).  Например, `-F: ` для разделителя `:`.
    *   `-v variable=value`:  Инициализировать переменную `awk`.
    *   `-f scriptfile`:  Читать программу `awk` из файла `scriptfile`.

*   **Примеры:**
    *   `awk '{print $1}' file.txt`: Вывести первое поле каждой строки.
    *   `awk '{print $1, $3}' file.txt`: Вывести первое и третье поля каждой строки, разделенные пробелом.
    *   `awk -F':' '{print $1}' /etc/passwd`: Вывести имя пользователя из файла `/etc/passwd` (разделитель - `:`)
    *   `awk '/pattern/ {print}' file.txt`: Вывести строки, содержащие "pattern".  Эквивалентно `grep "pattern" file.txt`.
    *   `awk '$1 == "value" {print}' file.txt`: Вывести строки, где первое поле равно "value".
    *   `awk '$2 > 10 {print $1, $2}' file.txt`:  Вывести первое и второе поля строк, где второе поле больше 10.
    *   `awk 'BEGIN {print "Начало"}; {print $0}; END {print "Конец"}' file.txt`:  Вывести "Начало" перед обработкой, каждую строку, и "Конец" после обработки.
    *   `awk '{sum += $1} END {print "Сумма:", sum}' file.txt`:  Вычислить сумму первого поля всех строк и вывести результат.
    *   `awk -v threshold=10 '$1 > threshold {print $0}' file.txt`:  Использовать переменную `threshold` для сравнения первого поля.
    *   `awk 'NF > 3 {print NR, $0}' file.txt`: Вывести номер строки (`NR`) и строку (`$0`) для строк, содержащих более 3 полей (`NF`).
    *   `awk '{count[$1]++} END {for (word in count) print word, count[word]}' file.txt`: Подсчитать количество вхождений каждого слова в первом поле и вывести результат.

*   **Встроенные переменные:**

    *   `FS`: Разделитель полей ввода (по умолчанию - пробел).  Можно изменить с помощью `-F`.
    *   `OFS`: Разделитель полей вывода (по умолчанию - пробел).
    *   `RS`: Разделитель записей ввода (по умолчанию - перевод строки).
    *   `ORS`: Разделитель записей вывода (по умолчанию - перевод строки).
    *   `NF`: Количество полей в текущей записи (строке).
    *   `NR`: Номер текущей записи (строки).
    *   `FILENAME`: Имя текущего входного файла.
