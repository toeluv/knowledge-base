`file filename.txt` - отобразить тип файла

### `find` - поиск файлов

`find path [expression]` - поиск файлов, удовлетворяющих заданным критериям.  `path` - путь к каталогу для поиска (по умолчанию - текущий каталог `.`).  `expression` - критерии поиска.  Если `path` не указан, поиск выполняется в текущей директории.

Основные опции и примеры выражений:

- `-name "pattern"` - поиск по имени файла (с учетом регистра, если не указано иное).  Использует globbing, но работает рекурсивно.
    *   `find . -name "my_file.txt"` - найти файл с именем `my_file.txt` в текущем каталоге и его подкаталогах.
    *   `find /tmp -name "*.log"` - найти все файлы с расширением `.log` в каталоге `/tmp` и его подкаталогах.
- `-iname "pattern"` - поиск по имени файла без учета регистра.
    *   `find . -iname "my_FILE.TXT"` - найти файл, независимо от регистра букв.
- `-type type` - поиск по типу файла:
    *   `f` - обычный файл.
    *   `d` - каталог.
    *   `l` - символьная ссылка.
    *   `s` - сокет.
    *   `p` - именованный канал (FIFO).
    *   `b` - блочное устройство.
    *   `c` - символьное устройство.
    *   `find / -type f -name "*.conf"` - найти все файлы конфигурации (с расширением `.conf`).
    *   `find /var/log -type d` - найти все каталоги в `/var/log`.
- `-size [+|-]N[cwbkMG]` - поиск по размеру файла:
    *   `N` - размер в блоках (512 байт по умолчанию).
    *   `c` - байты.
    *   `w` - двухбайтные слова.
    *   `b` - блоки (512 байт).
    *   `k` - килобайты.
    *   `M` - мегабайты.
    *   `G` - гигабайты.
    *   `-`: меньше указанного размера.
    *   `+`: больше указанного размера.
    *   `find . -size +100k` - найти файлы размером больше 100 КБ.
    *   `find . -size -1M` - найти файлы размером меньше 1 МБ.
    *   `find . -size 2M` - найти файлы размером ровно 2 МБ.
- `-atime [+|-]N`, `-mtime [+|-]N`, `-ctime [+|-]N` - поиск по времени доступа, модификации и изменения метаданных (ctime), соответственно:
    *   `N` - ровно N дней назад.
    *   `-N` - менее N дней назад.
    *   `+N` - более N дней назад.
    *   `find . -atime -7` - найти файлы, к которым обращались менее 7 дней назад.
    *   `find . -mtime +30` - найти файлы, измененные более 30 дней назад.
    *   `find . -ctime 0` - найти файлы, метаданные которых были изменены сегодня.
    *   `find . -mmin -60` - найти файлы, измененные менее 60 минут назад.
- `-user username` - поиск по владельцу файла.
    *   `find /home -user john` - найти файлы, принадлежащие пользователю `john`.
- `-group groupname` - поиск по группе владельца файла.
    *   `find / -group users` - найти файлы, принадлежащие группе `users`.
- `-perm mode` - поиск по правам доступа к файлу (в восьмеричном или символьном формате).
    *   `find . -perm 755` - найти файлы с правами доступа 755.
    *   `find . -perm -u+w` - найти файлы, владельцу которых предоставлено право на запись (при этом остальные права могут быть любыми).
    *   `find . -perm +777` - найти файлы, у которых хотя бы один пользователь имеет право на чтение, запись или выполнение.
- `-print` - вывод найденных файлов (по умолчанию).
    *   `find . -name "*.txt" -print` - вывод найденных файлов.
- `-print0` - вывод найденных файлов, разделенных null-символами (для использования с другими командами, которые ожидают null-разделенные входные данные).
    *   `find . -name "*.txt" -print0 | xargs -0 rm` - удаление найденных файлов.
- `-exec command {} \;` -  выполнение команды над найденными файлами. `{}` - заменяется на имя найденного файла. `\;` - экранированный символ для завершения команды.
    *   `find . -name "*.txt" -exec ls -l {} \;` - вывести подробную информацию о найденных файлах.
    *   `find . -name "*.log" -exec grep "error" {} \;` - найти строки, содержащие "error", в файлах `.log`.
    *   `find . -name "*.bak" -exec rm {} \;` - удалить все файлы с расширением .bak.
- `-ok command {} \;` -  аналогично `-exec`, но запрашивает подтверждение перед выполнением команды.
    *   `find . -name "*.bak" -ok rm {} \;` - удаляет файлы с расширением .bak с подтверждением.
-  `-path "pattern"` - поиск по пути к файлу (полный путь). Позволяет искать файлы, путь к которым соответствует шаблону.  Удобно, когда нужно исключить часть пути.
    *   `find /var/log -path "*/log/syslog*"` - найти файлы, путь к которым содержит `/log/syslog`.
- `-regex "pattern"` -  Поиск по имени файла с использованием регулярных выражений (похоже на `grep`).  Работает с полным путем к файлу.
    *   `find /var/log -regex ".*/[0-9]{4}-[0-9]{2}-[0-9]{2}_.*\.log"` - найти файлы логов, соответствующие определенному шаблону имени файла.

Логические операторы:

- `-a` или `-and` - логическое "И" (по умолчанию).
- `-o` или `-or` - логическое "ИЛИ".
- `!` или `-not` - логическое "НЕ".

Примеры комбинирования:

- `find . -name "*.txt" -and -mtime +30`  - найти файлы `.txt`, измененные более 30 дней назад.
- `find . -name "*.log" -or -name "*.txt"` - найти файлы с расширением `.log` *или* `.txt`.
- `find . ! -name "*.txt"` - найти все файлы, *кроме* файлов с расширением `.txt`.
- `find /tmp -type f ! -user root` - найти все файлы в /tmp, которые принадлежат не пользователю root.

### `touch` - создание файлов

`touch newfile.txt` - создание пустого файла

Опции:

- `-r` - копирование метаданных (времени) из другого файла
`touch -r old.txt new.txt`

- `-t` - ручная установка времени (формат [[CC]YY]MMDDhhmm[.ss])
`touch -t 202310151830.00 file.txt`

---

### `mkdir` - создание директорий

`mkdir dirname`

Опции:

- `-p` - создание всей иерархии директорий
`mkdir -p /path/to/new/dir`

- `-m` - установка прав при создании
`mkdir -m 755 dirname`

---

### `rm` - удаление файлов и директорий

`rm file.txt`

Опции:

- `-r` - рекурсивное удаление (для директорий)

- `-f` - принудительное удаление без подтверждения

- `-i` - интерактивный режим

Пример:
`rm -rf dirname/` - удаление директории со всем содержимым

---

### `cp` - копирование

`cp source dest`

Опции:

- `-r` - рекурсивное копирование

- `-u` - копирование только новых/измененных файлов

- `-p` - сохранение атрибутов

Примеры:
`cp file1.txt file2.txt`
`cp folder1/ folder2/ -r`
`cp folder1/* folder2/`

---

### `mv` - перемещение/переименование

`mv source dest`

Примеры:
`mv old.txt new.txt` - переименование
`mv file.txt dir/` - перемещение
`mv dir1/ dir2/` - перемещение директории

### `ls` - список файлов

`ls [options] [path]`

Основные опции:
`-l` — вывод подробной информации о содержимом каталога в виде списка;
`-a (—all) `— вывод информации о всех имеющихся объектах явных и скрытых;
`-A (—allmost-all)` — вывод информации о всех имеющихся явных и скрытых объектах (за исключением объектов «.» и «..»);
`-d (—directory)` — вывод информации о директории без вывода его содержимого;
`-F` — к объектам являющимся каталогами добавит в конце символ слеш «/», к объектам являющимися исполняемыми файлами добавляется «*», к объектам являющимися символьными ссылками — «@»;
`-r (—reverse)` — данные ключи меняют сортировку на обратную;
`-i` — отображение номера индексных дескрипторов объектов;
`-S` — сортировка объектов по размеру от большого к меньшему;
`-Sr` — сортировка объектов по размеру от меньшего;
`-t` — сортировка объектов по времени модификации файлов;
`-R (—recursive)` — вывод информации об имеющихся объектах в том числе и объектах во вложенных каталогах.
`-h` - человеко-читаемые размеры

### `xargs` - построение и выполнение команд из стандартного ввода

`xargs [options] [command]` - Читает аргументы из стандартного ввода (stdin), разбивает их на части и передает как аргументы указанной команде (`command`). Если команда не указана, используется `echo`.  Полезен для обхода ограничений на длину аргументов в командной строке.

Опции:

- `-n max-args` -  Максимальное количество аргументов, передаваемых каждой команде.
- `-I replace-str` - Замена `replace-str` на каждый аргумент из стандартного ввода.  Удобно, когда аргумент нужно вставить в середину команды.
- `-d delimiter` - Использовать `delimiter` в качестве разделителя аргументов вместо пробелов.
- `-0` - Аргументы разделены null-символами.  Безопасный способ обработки имен файлов, содержащих пробелы и другие специальные символы. Используется в сочетании с `find -print0`.
- `-L max-lines` - Максимальное количество непустых строк, читаемых из стандартного ввода для каждой команды.

Примеры:

`ls *.txt | xargs rm` - Удаляет все файлы с расширением `.txt` (передает имена файлов команде `rm`).

`find . -name "*.log" -print0 | xargs -0 grep "error"` - Ищет строки, содержащие "error", во всех файлах с расширением `.log` в текущем каталоге и его подкаталогах. `-print0` и `-0` обеспечивают корректную обработку имен файлов с пробелами.

`ls | xargs -n 2 mkdir` - Создает каталоги попарно (из списка файлов, полученного от `ls`).  `ls` выводит имена файлов/каталогов, а `xargs -n 2` передает `mkdir` по 2 имени за раз.

`echo "file1 file2 file3" | xargs -I {} cp {} /tmp` - Копирует файлы `file1`, `file2` и `file3` в каталог `/tmp`.  `-I {}` заменяет `{}` на каждый аргумент.

`echo "a,b,c" | xargs -d ',' echo` - Выводит аргументы, разделенные запятыми.

`cat list_of_files.txt | xargs -L 1 wc -l` - Считает количество строк в каждом файле, перечисленном в `list_of_files.txt` (по одному файлу на строку).

### Полезные комбинации

- Создать несколько файлов:
`touch file{1..5}.txt`

- Копировать с прогрессом:
`rsync -ah --progress source dest`

- Найти и удалить:
`find . -name "*.tmp" -exec rm {} \;`

- Алиасы:
`la` — обычно алиас для `ls -a` (показать скрытые файлы)

`l` — часто алиас для `ls -la` или `ls -l` (подробный вывод + скрытые файлы)

По умолчанию вызов команды ls выводит содержимое текущего каталога, для того, чтобы узнать содержимое другого каталога, то нужно передать путь до этого каталога в качестве аргумента. Путь может быть задан как относительный, так и абсолютный (полный), как в примере ниже.

`$ ls -la /etc/xml`
