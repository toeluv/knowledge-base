### **No-op (No Operation) и другие полезные фишки в Linux/UNIX**  

В Linux и UNIX-подобных системах есть множество маленьких, но мощных трюков, которые делают работу в терминале удобнее. Один из них — команда `:` (no-op), а также другие хитрости, которые помогут в скриптинге и повседневной работе.  

---

## **1. `:` (No-op — "ничего не делай")**  
Команда `:` (двоеточие) — это встроенная команда shell, которая **ничего не делает** и всегда возвращает `0` (успех).  
```bash
: docker run nginx
```

---

## **2. `$_` — последний аргумент предыдущей команды**  
Переменная `$_` содержит **последний аргумент** предыдущей команды.  

### **Пример:**  
```bash
mkdir -p /tmp/new_folder
cd $_  # перейдёт в /tmp/new_folder
```

---

## **3. `!!` — повтор последней команды**  
Если забыли `sudo`, можно быстро повторить команду с правами root:  
```bash
apt update  # Ошибка: недостаточно прав
sudo !!     # Выполнит "sudo apt update"
```

---

## **4. `!$` — последний аргумент предыдущей команды (аналог `$_`)**  
```bash
cat /var/log/syslog
vim !$  # откроет /var/log/syslog в vim
```
---

## **5. `<(команда)` — подстановка вывода команды как файла**  
```bash
diff <(ls /dir1) <(ls /dir2)  # сравнить списки файлов
```

## **6. `mktemp` — создание временных файлов/директорий**  
```bash
temp_file=$(mktemp)       # /tmp/tmp.XYZ123
temp_dir=$(mktemp -d)     # /tmp/tmp.ABC456
echo "Временный файл: $temp_file"
```

---

## **Вывод**  
Эти фишки делают работу в терминале **быстрее и удобнее**:  
✅ `:` и `true`/`false` — полезны в скриптах.  
✅ `!!`, `!$`, `$_` — экономят время.  
✅ `{1..10}`, `<(cmd)` — упрощают сложные операции.
