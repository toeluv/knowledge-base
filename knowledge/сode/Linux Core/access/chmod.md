
### Отображение

`drwxr--r-w` - отображение при `ls` . Структура:
1.  `d` или `-` - папка/файл
2. `rwx` - Read, Write, Execute - для владельца
3. `r--` - Read для группы
4. `r-w` - Read, Write для остальных.
### Примечание для папок:
- -- `х` для папки разрешает чтение мета-данных (inode) файлов - размер файла, права доступа, времена доступа, номер inode и т.д. А так же, разрешает "войти" в эту папку
- --`r`  разрешает чтение списка файлов и каталогов из этой папки, но не их метаданных
- -- `w` разрешает добавление и удаление файлов из папки (даже тех, которые вам не принадлежат)
- -- Для папок `x` - проход в папку и сквозь
- Если есть права на файлы внутри папки, то они выполнятся. Пример `r` на файл, но не на директорию, позволяет читать файл, но `ls -l directory` будет ошибкой

## chmod
### В простом виде
Работает для всех трех категорий:
```bash
$ chmod +r file.txt # добавление
$ chmod +w file.txt
$ chmod +x file.txt

$ chmod -r file.txt # удаление
$ chmod -w file.txt
$ chmod -x file.txt

$ chmod =r file.txt # перезапись
$ chmod =w file.txt
$ chmod =x file.txt 
```

Если нужно для конкретных категорий, то необходимо использовать `ugo` - User, Group, Other.

```bash
$ chmod go-wx file.txt # удаление прав на запись и выполнение у группы и других
```
### В виде цифр:
`r = 4`, `w = 2`, `x = 1`. Тогда:
- `rwx = 7`
 - `rw-=  6`
- `r-x = 5`
- `r-- = 4`
- `-wx = 3`
 - `-w- = 2`
- `--x = 1` 
- `--- = 0`
Пример:

```bash
$ chmod 765 text.txt
```

- Чтение, запись, выполнение для владельца
- Чтение, запись для группы
- Чтение, выполнение для всех
