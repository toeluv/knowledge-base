# umask в Linux

`umask` (user file-creation mode mask) - это команда и настройка в Linux (и других Unix-подобных системах), определяющая **права доступа по умолчанию** для новых файлов и каталогов, создаваемых пользователем. `umask` работает путем *маскирования* (отнимания) битов от стандартных прав доступа.

**Как это работает:**

1.  **Стандартные права:**
    *   Файлы: `666` (rw-rw-rw-) - Чтение и запись для всех.
    *   Каталоги: `777` (rwxrwxrwx) - Чтение, запись и выполнение для всех.

2.  **Значение `umask`:** `umask` задается в восьмеричной системе (base 8). Каждый разряд соответствует правам для владельца, группы и остальных.

3.  **Применение:** Система вычитает значение `umask` из стандартных прав, чтобы получить права доступа по умолчанию для нового файла или каталога.

**Примеры:**

| umask | Результат (Файлы) | Результат (Каталоги) | Объяснение                                                                                                   |
|-------|--------------------|-----------------------|-------------------------------------------------------------------------------------------------------------|
| `000` | `rw-rw-rw-` (666) | `rwxrwxrwx` (777)   | Без маскирования. Все получают полный доступ.                                                              |
| `022` | `rw-r--r--` (644) | `rwxr-xr-x` (755)   | Запретить запись для группы и остальных.                                                                  |
| `077` | `rw-------` (600) | `rwx------` (700)   | Запретить все права для группы и остальных.                                                                |
| `002` | `rw-rw-r--` (664) | `rwxrwxr-x` (775)   | Запретить запись для "остальных".                                                                         |

**Как использовать:**

*   **Просмотр текущего `umask`:** `umask` (без аргументов)
*   **Установка `umask` (временная):** `umask 022` (изменится только для текущей сессии)
*   **Установка `umask` (постоянная):** Изменить в файлах:
    *   `/etc/profile` (для всех пользователей при входе через login shell)
    *   `/etc/bash.bashrc` (для всех пользователей, использующих bash)
    *   `~/.bashrc` или `~/.profile` (для конкретного пользователя)
    *   Добавьте строку `umask 022` (или желаемое значение) в один из этих файлов.

**Важно:**

*   `umask` **только** устанавливает права доступа **по умолчанию**. Права доступа можно изменить после создания файла/каталога с помощью `chmod`.
*   `umask` применяется в восьмеричной системе.
*   Изменения в `/etc/profile` и `/etc/bash.bashrc` требуют перезапуска системы или нового входа в систему. Изменения в `~/.bashrc` требуют открытия нового терминала или выполнения `source ~/.bashrc`.
*   Значение `umask` может зависеть от дистрибутива Linux.

**Полезные значения:**

*   `022`: Хороший компромисс между безопасностью и удобством.
*   `077`: Очень строгие права доступа, подходят для чувствительных данных.
*   `002`: Общая практика, ограничивающая запись для "остальных".

**Пример сценария:**

1.  Вы хотите, чтобы новые файлы были доступны только для чтения группе и остальным, а каталоги были доступны для выполнения, но не для записи.
2.  Используйте `umask 022`.
3.  Новые файлы будут созданы с правами `rw-r--r--` (644).
4.  Новые каталоги будут созданы с правами `rwxr-xr-x` (755).
