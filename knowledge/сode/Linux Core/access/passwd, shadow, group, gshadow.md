
### Основное

*   **Описание:**  Файлы `/etc/passwd` и `/etc/shadow` содержат информацию об учетных записях пользователей в Linux-системах.
*   **Важность:**  Критически важны для аутентификации и безопасности системы. Некорректная конфигурация может привести к проблемам с доступом или компрометации учетных записей.

### /etc/group

*   **Расположение:** `/etc/group`
*   **Описание:** Содержит базовую информацию о каждой группе пользователей. Доступен для чтения *всем* пользователям системы (но запись - только root).
*   **Формат строки (разделитель - `:`)**:
    `имя_группы:пароль:GID:список_пользователей`
    *   **имя_группы:** Имя группы пользователей.
    *   **пароль:**  Практически не используется в современных системах. Обычно содержит "x" или "\*". Информация об аутентификации групп (если она используется) хранится в `/etc/gshadow`.
    *   **GID (Group ID):** Уникальный числовой идентификатор группы. Должен быть уникальным в системе.
        *   0: root group
        *   1-999: System groups (usually)
        *   1000+: User-defined groups (usually)
    *   **список_пользователей:** Список имен пользователей, являющихся членами данной группы (через запятую, без пробелов). Эти пользователи, в дополнение к своим личным правам, получают права доступа, связанные с этой группой.
*   **Пример:**
    `developers:x:1002:john,jane,peter`
    `root:x:0:`

### /etc/gshadow

*   **Расположение:** `/etc/gshadow`
*   **Описание:** Содержит защищенную информацию, связанную с группами, такую как захешированные пароли групп (если используются) и администраторов группы. Доступен для чтения *только root*.
*   **Формат строки (разделитель - `:`)**:
    `имя_группы:пароль:администраторы:список_пользователей`
    *   **имя_группы:** Имя группы (должно совпадать с полем имени группы в `/etc/group`).
    *   **пароль:** Захешированный пароль группы. Если пароль не установлен, это поле обычно пустое. Групповые пароли используются редко.
    *   **администраторы:** Список имен пользователей, являющихся администраторами группы (через запятую, без пробелов). Администраторы могут управлять членством в группе.
    *   **список_пользователей:** Список имен пользователей, являющихся членами группы (через запятую, без пробелов). Дублирует информацию из `/etc/group`, но может быть более полной (включать пользователей, добавленных администраторами группы).
*   **Пример:**
    `developers::admin1,admin2:john,jane,peter`
### /etc/passwd

*   **Расположение:** `/etc/passwd`
*   **Описание:**  Содержит базовую информацию о каждой учетной записи пользователя.  Доступен для чтения *всем* пользователям системы (но запись - только root).
*   **Формат строки (разделитель - `:`)**:
    `имя_пользователя:пароль:UID:GID:комментарий:домашний_каталог:оболочка`
    *   **имя_пользователя:** Имя учетной записи пользователя (логин).
    *   **пароль:**  Исторически - захешированный пароль.  В современных системах заменен на "x" или "\*", что указывает на то, что захешированный пароль хранится в `/etc/shadow`.
    *   **UID (User ID):**  Уникальный числовой идентификатор пользователя.
        *   0: root
        *   1-999: Системные учетные записи (обычно)
        *   1000+: Пользовательские учетные записи (обычно)
    *   **GID (Group ID):**  Числовой идентификатор группы, к которой принадлежит пользователь.
    *   **комментарий:**  Необязательное текстовое поле, обычно содержит информацию о пользователе (ФИО, телефон и т.д.).
    *   **домашний_каталог:**  Путь к домашнему каталогу пользователя.
    *   **оболочка:**  Путь к командной оболочке, используемой пользователем (например, `/bin/bash`, `/bin/sh`, `/bin/false`).  `/bin/false` означает, что пользователю запрещен интерактивный вход в систему.
*   **Пример:**
    `john:x:1001:1001:John Doe:/home/john:/bin/bash`
    `root:x:0:0:root:/root:/bin/bash`

### /etc/shadow

*   **Расположение:** `/etc/shadow`
*   **Описание:**  Содержит захешированные пароли пользователей и другую информацию, связанную с безопасностью учетных записей. Доступен для чтения *только root*.
*   **Формат строки (разделитель - `:`)**:
    `имя_пользователя:пароль:последнее_изменение:мин_возраст:макс_возраст:предупреждение:неактивность:срок_действия:флаг`
    *   **имя_пользователя:** Имя учетной записи пользователя (должно совпадать с полем имени пользователя в `/etc/passwd`).
    *   **пароль:**  Захешированный пароль пользователя.  Может быть представлен различными алгоритмами (например, SHA-512).  `!` или `*` означают, что учетная запись заблокирована и не может быть использована для входа в систему.
    *   **последнее_изменение:** Количество дней с 1 января 1970 года (Unix epoch) до даты последнего изменения пароля.
    *   **мин_возраст:**  Минимальное количество дней, которое должно пройти, прежде чем пользователь сможет изменить свой пароль.
    *   **макс_возраст:**  Максимальное количество дней, в течение которых пароль действителен.  После этого срока пользователь должен изменить пароль.
    *   **предупреждение:**  Количество дней до истечения срока действия пароля, когда пользователь начинает получать предупреждения о необходимости его смены.
    *   **неактивность:** Количество дней после истечения срока действия пароля, в течение которых учетная запись останется активной.  После этого срока учетная запись будет заблокирована.
    *   **срок_действия:**  Количество дней с 1 января 1970 года до даты истечения срока действия учетной записи.  После этой даты учетная запись будет заблокирована.
    *   **флаг:**  Зарезервированное поле.
*   **Пример:**
    `john:$6$SALT$HASHED_PASSWORD:19284:0:90:7:30::`
    `root:$6$ANOTHERSALT$ANOTHERHASHED_PASSWORD:19284:0:99999:7:::`

### Безопасность

*   **Защита `/etc/shadow`:**  Крайне важно защищать `/etc/shadow` от несанкционированного доступа, так как он содержит захешированные пароли.
*   **PAM (Pluggable Authentication Modules):**  Система PAM используется для аутентификации пользователей.  Она позволяет гибко настраивать различные методы аутентификации.
*   **Рекомендации:**
    *   Регулярно меняйте пароли.
    *   Используйте сложные пароли.
    *   Включите блокировку учетных записей после нескольких неудачных попыток входа.
    *   Регулярно проверяйте файлы `/etc/passwd` и `/etc/shadow` на наличие подозрительных изменений.
    *   Используйте инструменты для аудита безопасности системы.

### Инструменты для работы с файлами passwd, shadow, group, gshadow

*   `useradd`, `userdel`, `usermod`:  Утилиты для добавления, удаления и изменения учетных записей пользователей.
*   `passwd`:  Утилита для изменения паролей пользователей.
*   `chage`: Утилита для изменения параметров старения паролей (мин_возраст, макс_возраст и т.д.).
*   `getent`: Утилита для получения записей из различных баз данных (включая passwd и shadow).
*   `groupadd`: Добавляет новую группу.
*   `groupdel`: Удаляет группу.
*   `groupmod`: Изменяет параметры группы.
*   `gpasswd`: Управляет членами и администраторами группы.
*   `groups`: Выводит список групп, к которым принадлежит пользователь.
*   `id`:  Выводит UID, GID и список групп пользователя.

### Альтернативы

*   **LDAP:**  Централизованная служба каталогов, используемая для хранения информации о пользователях и группах.
*   **Active Directory:**  Служба каталогов, разработанная Microsoft.

### Заключение

Понимание структуры и назначения файлов `/etc/passwd` и `/etc/shadow` необходимо для обеспечения безопасности и корректного управления учетными записями пользователей в Linux-системах.  Необходимо соблюдать осторожность при изменении этих файлов и использовать соответствующие инструменты для управления учетными записями.
