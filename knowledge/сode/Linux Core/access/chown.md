## Команда chown: Изменение владельца и группы файлов

**Синтаксис:**

```bash
chown [ОПЦИИ] пользователь[:группа] файл(ы)
```
Описание:

chown изменяет владельца и группу файлов. Требует привилегий суперпользователя (root) или владение файлом и членство в целевой группе (для изменения только группы).

Основные Опции:

`-c, --changes`: Показывать информацию только о файлах, владельцы которых были изменены.
`-f, --silent, --quiet`: Не выводить сообщения об ошибках.
`-v`, --verbose: Выводить подробную информацию о каждой обработанной файле.
`-R, --recursive`: Рекурсивно изменять владельца и группу каталогов и их содержимого.
`--from=текущий_пользователь[:текущая_группа]`: Изменять владельца/группу только файлов, принадлежащих указанному пользователю/группе. Можно использовать без целевого пользователя/группы.
`--no-preserve-root`: Не обрабатывать ‘/’ особым образом (отключает защиту от рекурсивного изменения владельца корневого каталога). Опасно!
`--preserve-root`: Не работает рекурсивно в корневом каталоге. Это поведение по умолчанию.
`--reference`=ФАЙЛ: Использовать владельца и группу указанного ФАЙЛА для целевых файлов.
`-h, --no-dereference`: Изменять владельца и группу символической ссылки, а не файла, на который она указывает (если система это поддерживает). Используется в сочетании с -R.
`-H`: Если указана опция -R, то при обработке символической ссылки, указывающей на каталог, следует его пройти.
`-L`: Если указана опция -R, то следует проходить каждую символическую ссылку, указывающую на каталог.
`--dereference`: Всегда изменять владельца файла, на который указывает символическая ссылка.
`--help`: Вывести справку и выйти.
`--version`: Вывести информацию о версии и выйти.
Аргументы:

пользователь: Имя пользователя или UID.
группа: Имя группы или GID.
файл(ы): Список файлов или каталогов, владельца и группу которых нужно изменить.
Примеры:
```bash
chown user file.txt: # Изменить владельца file.txt на пользователя user.
chown user:group file.txt: # Изменить владельца file.txt на пользователя user и группу на group.
chown :group file.txt: # Изменить только группу file.txt на group.
chown -R user:group directory: # Рекурсивно изменить владельца и группу каталога directory и всего его содержимого на пользователя user и группу group.
chown --from=olduser newuser file.txt: # Изменить владельца file.txt на newuser только если текущий владелец olduser.
chown --reference=otherfile file.txt: # Сделать владельца и группу file.txt такими же, как у otherfile.
