
#### ✨ TL;DR:

```bash
sudo useradd ini -m
sudo usermod ini -aG sudo
sudo passwd
```

### Основные команды

*   **`useradd`**: Добавление новой учетной записи пользователя.
    *   **Синтаксис:** `useradd [опции] имя_пользователя`
    *   **Основные опции:**
        *   `-m`: Создать домашний каталог пользователя.
        *   `-d` *каталог*: Указать домашний каталог пользователя.
        *   `-k` *каталог*: Добавить доступные файлы из папки.
        *   `-g` *группа*: Указать первичную группу пользователя (по GID или имени).
        *   `-G` *список_групп*: Указать список вторичных групп пользователя (через запятую, без пробелов).
        *   `-s` *оболочка*: Указать командную оболочку пользователя (например, `/bin/bash`, `/bin/false`).
        *   `-c` *комментарий*: Добавить комментарий к учетной записи пользователя.
        *   `-u` *UID*: Указать User ID (обычно не требуется, система выберет автоматически).
    *   **Пример:**
        `useradd -m -d /home/newuser -g users -G audio,video -s /bin/bash -c "New User" newuser`

*   **`userdel`**: Удаление учетной записи пользователя.
    *   **Синтаксис:** `userdel [опции] имя_пользователя`
    *   **Основные опции:**
        *   `-r`: Удалить домашний каталог пользователя и его почтовый ящик.
    *   **Пример:**
        `userdel -r olduser`

*   **`usermod`**: Изменение параметров учетной записи пользователя.
    *   **Синтаксис:** `usermod [опции] имя_пользователя`
    *   **Основные опции (похожи на `useradd`):**
        *   `-d` *каталог*: Изменить домашний каталог пользователя. (С опцией `-m` перемещает содержимое)
        *   `-g` *группа*: Изменить первичную группу пользователя.
        *   `-G` *список_групп*: Изменить список вторичных групп пользователя. (`-a` для добавления к существующим группам).
        *   `-s` *оболочка*: Изменить командную оболочку пользователя.
        *   `-c` *комментарий*: Изменить комментарий к учетной записи пользователя.
        *   `-l` *новое_имя*: Изменить имя пользователя.
        *   `-u` *UID*: Изменить User ID.
        *   `-L`: Заблокировать учетную запись пользователя (добавляет `!` в `/etc/shadow`).
        *   `-U`: Разблокировать учетную запись пользователя (удаляет `!` из `/etc/shadow`).
    *   **Пример:**
        `usermod -g developers -G audio,video,www newuser`
        `usermod -L lockeduser`

*   **`passwd`**: Изменение пароля пользователя.
    *   **Синтаксис:** `passwd [имя_пользователя]`
    *   **Работа:**
        *   Если запущена без аргументов, запрашивает смену пароля текущего пользователя.
        *   Если запущена от имени root, позволяет изменить пароль любого пользователя.
        *   Запрашивает старый пароль (если меняет пароль текущий пользователь) и новый пароль (дважды для подтверждения).
    *   **Пример:**
        `passwd john`  (от root)
        `passwd` (от пользователя john)

*   **`chage`**: Управление политикой старения паролей.
    *   **Синтаксис:** `chage [опции] имя_пользователя`
    *   **Основные опции:**
        *   `-d` *дата*: Установить дату последнего изменения пароля (в формате YYYY-MM-DD).
        *   `-m` *минимальный_возраст*: Установить минимальный возраст пароля (в днях).
        *   `-M` *максимальный_возраст*: Установить максимальный возраст пароля (в днях).
        *   `-W` *предупреждение*: Установить количество дней до истечения срока действия пароля, когда пользователь начинает получать предупреждения.
        *   `-I` *неактивность*: Установить количество дней неактивности после истечения срока действия пароля, после которого учетная запись блокируется.
        *   `-E` *срок_действия*: Установить дату истечения срока действия учетной записи (в формате YYYY-MM-DD).
        *   `-l`: Вывести текущую политику старения пароля для пользователя.
    *   **Пример:**
        `chage -m 7 -M 90 -W 7 john` (минимальный возраст 7 дней, максимальный 90 дней, предупреждение за 7 дней)

*   **`groupadd`**: Добавление новой группы.
    *   **Синтаксис:** `groupadd [опции] имя_группы`
    *   **Основные опции:**
        *   `-g` *GID*: Указать Group ID (обычно не требуется, система выберет автоматически).
        *   `-r`: Создать системную группу (GID < 1000).
    *   **Пример:**
        `groupadd developers`
*   **`groupdel`**: Удаление группы.
    *   **Синтаксис:** `groupdel имя_группы`
    *   **Внимание:** Нельзя удалить первичную группу пользователя, пока пользователь не будет переведен в другую группу.
    *   **Пример:**
        `groupdel oldgroup`
*   **`groupmod`**: Изменение параметров группы.
    *   **Синтаксис:** `groupmod [опции] имя_группы`
    *   **Основные опции:**
        *   `-g` *GID*: Изменить Group ID.
        *   `-n` *новое_имя*: Изменить имя группы.
    *   **Пример:**
        `groupmod -n newdevelopers developers`
*   **`gpasswd`**: Управление членами и администраторами группы.
    *   **Синтаксис:** `gpasswd [опции] имя_группы`
    *   **Основные опции:**
        *   `-a` *имя_пользователя*: Добавить пользователя в группу.
        *   `-d` *имя_пользователя*: Удалить пользователя из группы.
        *   `-A` *список_администраторов*: Установить список администраторов группы (через запятую, без пробелов).
        *   `-r`: Удалить пароль группы.
    *   **Пример:**
        `gpasswd -a john developers`
        `gpasswd -d jane developers`
        `gpasswd -A admin1,admin2 developers`
*   **`groups`**: Вывод списка групп, к которым принадлежит пользователь.
    *   **Синтаксис:** `groups [имя_пользователя]`
    *   **Работа:**
        *   Если запущена без аргументов, выводит список групп, к которым принадлежит текущий пользователь.
        *   Если указано имя пользователя, выводит список групп, к которым принадлежит этот пользователь.
    *   **Пример:**
        `groups`
        `groups john`
*   **`id`**: Вывод идентификационной информации о пользователе.
    *   **Синтаксис:** `id [опции] [имя_пользователя]`
    *   **Работа:**
        *   Если запущена без аргументов, выводит информацию о текущем пользователе.
        *   Если указано имя пользователя, выводит информацию об этом пользователе.
    *   **Выводимая информация:**
        *   `uid`: User ID
        *   `gid`: Group ID (первичная группа)
        *   `groups`: Список GID вторичных групп.

### Примеры совместного использования

*   Создать нового пользователя `testuser` с домашним каталогом, первичной группой `users`, оболочкой `/bin/bash` и добавить его в группы `audio` и `video`:
    ```bash
    useradd -m -g users -G audio,video -s /bin/bash testuser
    passwd testuser  # Задать пароль для testuser
    ```

*   Изменить домашний каталог пользователя `john` на `/data/john` и перенести содержимое старого каталога:
    ```bash
    usermod -m -d /data/john john
    ```

*   Заблокировать учетную запись пользователя `disableduser`:
    ```bash
    usermod -L disableduser
    ```

*   Удалить пользователя `olduser` вместе с его домашним каталогом:
    ```bash
    userdel -r olduser
    ```
