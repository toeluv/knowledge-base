### Права доступа в Linux

Базовые права доступа в Linux:

*   **Чтение (r):** Просмотр содержимого файла или списка файлов в каталоге.
*   **Запись (w):** Изменение содержимого файла или добавление/удаление файлов в каталоге.
*   **Выполнение (x):** Запуск файла как программы (для исполняемых файлов) или переход в каталог (для каталогов).

Каждая категория (владелец, группа, остальные) имеет свой набор прав.

### Setuid (SUID)

**Описание:**
Бит SUID устанавливается на исполняемый файл и позволяет ему запускаться с правами владельца файла, а не пользователя, который его запускает.

**Синтаксис:**

*   **Символьный:** `chmod u+s <имя_файла>`
*   **Числовой:** `chmod 4<права_доступа> <имя_файла>` (например, `chmod 4755 <имя_файла>`)

**Отображение (ls -l):**

*   `s` в позиции прав на выполнение для владельца.
*   `S` (заглавная) - если SUID установлен, но у владельца нет прав на выполнение.  В этом случае SUID не действует.

**Пример:**

Программа смены пароля (`/usr/bin/passwd`) может использовать SUID, чтобы временно получить доступ к файлу `/etc/shadow` (который хранит хеши паролей) для смены пароля пользователя.
При монтировании Floppy привода, который работает от root все пользователи могут выполнять операции
**Безопасность:**

*   Может создать серьезные уязвимости, если программа содержит ошибки, так как позволяет запускать код с привилегиями владельца (часто root).
*   Важно тщательно проверять код и применять лучшие практики безопасной разработки.

**Альтернативы:**

*   Capabilities
*   `sudo`

### Setgid (SGID)

**Описание:**

Бит SGID имеет два разных эффекта:

1.  **Для исполняемых файлов:**  Аналогично SUID, но программа запускается с правами группы-владельца файла.
2.  **Для каталогов:** Все новые файлы, созданные в каталоге с установленным SGID, будут принадлежать группе-владельцу каталога, а не группе пользователя, который создал файл.

**Синтаксис:**

*   **Символьный:** `chmod g+s <имя_файла>` (или `<имя_каталога>`)
*   **Числовой:** `chmod 2<права_доступа> <имя_файла>` (например, `chmod 2755 <имя_файла>`)

**Отображение (ls -l):**

*   `s` в позиции прав на выполнение для группы.
*   `S` (заглавная) - если SGID установлен, но у группы нет прав на выполнение (для исполняемых файлов).  SGID не действует.

**Пример:**

Директория обмена файлами, где все файлы должны принадлежать одной группе, чтобы участники группы могли совместно работать над файлами.

**Безопасность:**

*   Менее опасен, чем SUID, но также требует внимания к безопасности.
*   Важно контролировать членство в группах.

### Sticky Bit

**Описание:**

Устанавливается только на каталогах.  Означает, что только владелец файла, владелец каталога или пользователь root могут удалять или переименовывать файлы в этом каталоге.
Нужно когда несколько программ пишут в папку, но не могут удалять файлы других программ.
**Синтаксис:**

*   **Символьный:** `chmod +t <имя_каталога>`
*   **Числовой:** `chmod 1<права_доступа> <имя_каталога>` (например, `chmod 1777 <имя_каталога>`)

**Отображение (ls -l):**

*   `t` в позиции прав на выполнение для "остальных" пользователей.
*   `T` (заглавная) - если sticky bit установлен, но у "остальных" нет прав на выполнение. Sticky Bit все равно действует (только владелец файла, владелец каталога или root может удалить/переименовать).

**Пример:**

Каталог `/tmp`, который предназначен для хранения временных файлов, доступных всем пользователям. Sticky bit гарантирует, что пользователи могут удалять только свои собственные файлы из `/tmp`.

**Безопасность:**

*   Помогает предотвратить случайное или злонамеренное удаление файлов другими пользователями в общих каталогах.

### Числовое представление прав доступа

Для понимания числовых прав доступа, нужно знать, что каждая привилегия имеет свое числовое значение:

*   Чтение (r) = 4
*   Запись (w) = 2
*   Выполнение (x) = 1

Для каждой категории (владелец, группа, остальные) складываются значения необходимых привилегий.  Дополнительно:

*   SUID = 4000 (или `4` в первой позиции)
*   SGID = 2000 (или `2` в первой позиции)
*   Sticky Bit = 1000 (или `1` в первой позиции)

**Пример:**

`chmod 755 <имя_файла>`:
*   7 (владелец): 4 (чтение) + 2 (запись) + 1 (выполнение) = rwx
*   5 (группа): 4 (чтение) + 0 (нет записи) + 1 (выполнение) = r-x
*   5 (остальные): 4 (чтение) + 0 (нет записи) + 1 (выполнение) = r-x

`chmod 4755 <имя_файла>`: SUID установлен + права rwxr-xr-x
