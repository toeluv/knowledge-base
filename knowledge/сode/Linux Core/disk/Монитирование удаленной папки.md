# Монтирование удаленной папки в Linux

Существует несколько способов монтирования удаленных папок в Linux:

## 1. Использование SSHFS (SSH Filesystem)

SSHFS позволяет монтировать удаленную файловую систему через SSH.

```bash
# Установка sshfs (для Ubuntu/Debian)
sudo apt install sshfs

# Создание точки монтирования
mkdir ~/remote_folder

# Монтирование
sshfs username@remote_host:/remote/path ~/remote_folder

# Размонтирование
fusermount -u ~/remote_folder
```

## 2. Использование NFS (Network File System)

Серверная часть (на удаленном сервере):
```bash
sudo apt install nfs-kernel-server
sudo nano /etc/exports
# Добавить строку: /remote/path client_ip(rw,sync,no_subtree_check)
sudo exportfs -a
sudo systemctl restart nfs-kernel-server
```

Клиентская часть:
```bash
sudo apt install nfs-common
mkdir ~/remote_folder
sudo mount -t nfs remote_host:/remote/path ~/remote_folder
```

## 3. Использование Samba/CIFS (для Windows-совместимых общих папок)

```bash
sudo apt install cifs-utils
mkdir ~/remote_folder
sudo mount -t cifs //remote_host/sharename ~/remote_folder -o username=user,password=pass,uid=local_user,gid=local_group
```

## 4. Автоматическое монтирование при загрузке

Для автоматического монтирования добавьте запись в `/etc/fstab`:

Для SSHFS:
```
username@remote_host:/remote/path /local/mountpoint fuse.sshfs defaults,allow_other,IdentityFile=/path/to/id_rsa 0 0
```

Для NFS:
```
remote_host:/remote/path /local/mountpoint nfs defaults 0 0
```

Для CIFS:
```
//remote_host/sharename /local/mountpoint cifs credentials=/path/to/credentials.file,uid=local_user,gid=local_group 0 0
```

## Примечания

1. Убедитесь, что у вас есть соответствующие разрешения на доступ к удаленной папке
2. Для SSHFS должен быть настроен SSH-доступ без пароля (по ключам) для автоматического монтирования
3. Будьте осторожны с правами доступа при монтировании
