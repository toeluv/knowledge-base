
## Основные понятия
- `/etc/fstab` - файл конфигурации, содержащий информацию о статически монтируемых файловых системах
- `/dev` - директория, содержащая файлы устройств (бинарные интерфейсы к оборудованию)
## Просмотр смонтированных систем
```bash
$ mount  # список всех смонтированных ФС
$ df -h  # информация о свободном месте
$ lsblk  # информация о блочных устройствах
```
## Основные команды монтирования

### Монтирование устройств

```bash
mount /dev/sda1 /home/user
```

Где:

-   `/dev/sda1`  - устройство или раздел для монтирования
    
-   `/home/user`  - точка монтирования (путь в файловой системе)
    

### Полезные флаги mount

-   `-t`  - указание типа файловой системы (ext4, ntfs, exfat и др.)
    
-   `-o`  - опции монтирования (например,  `ro`  для только чтения)
    
-   `-a`  - монтирование всех файловых систем из /etc/fstab
    

### Размонтирование

```bash
umount /home/user  # или
umount /dev/sda1
```
## Автоматическое монтирование

Для автоматического монтирования при загрузке добавить запись в `/etc/fstab`:

`/dev/sdb1  /mnt/usb_disk  exfat  defaults  0  0`

*   `<device>`: Устройство (UUID или `/dev/sdXN`). **Рекомендуется UUID** (получить через `blkid`).
*   `<mount_point>`: Каталог монтирования (должен существовать).
*   `<filesystem_type>`: Тип файловой системы (`ext4`, `xfs`, `exfat`, `ntfs`, `swap` и т.д.).
*   `<mount_options>`: Опции монтирования (`defaults`, `noatime`, `ro`, `rw`, `user`, `uid=`, `gid=`, `umask=` и т.д.).  `defaults` - стандартный набор.
*   `<dump>`: Использовать для резервного копирования (`0` - не использовать).
*   `<fsck>`: Порядок проверки при загрузке (`0` - не проверять, `1` - корневая ФС, `2` - остальные).

**Пример:**
```text
/dev/sdb1  /mnt/usb_disk  exfat  defaults  0  0
UUID=”a1b2c3d4-e5f6-7890-1234-567890abcdef” /mnt/data ext4 defaults,noatime 0 2
```
## Работа с внешними накопителями

### Рекомендуемые файловые системы

-   Для флешек и внешних дисков рекомендуется exFAT (поддержка больших файлов и хорошая кроссплатформенность)
    

### Процесс монтирования USB-диска

```bash
$ mkdir /mnt/usb_disk  # создание точки монтирования
$ mount /dev/sdb1 /mnt/usb_disk  # монтирование
```
## Особенности монтирования

-   При монтировании содержимое точки монтирования становится недоступным до размонтирования
    
-   После монтирования путь к файлам изменяется (например, файл  `/home/user/file.txt`  на разделе sda1 будет доступен как  `/mnt/sda1_mount/home/user/file.txt`)
    
-   Для безопасного извлечения USB-устройств обязательно использовать umount перед физическим отключением
    
## Советы

-   Всегда проверяйте устройство перед монтированием (fdisk -l или lsblk)
    
-   Для NTFS-разделов может потребоваться пакет ntfs-3g
    
-   При проблемах с правами используйте опции uid и gid в mount
