## Создание и форматирование разделов жестких дисков в Linux

**TL;DR**

```bash
$ mount  # список всех смонтированных ФС
$ df -h  # информация о свободном месте
$ lsblk  # информация о блочных устройствах
$ blkid /dev/sdXN # посмотреть UUID
```

*   **Посмотреть диски и разделы:**
    *   `lsblk`: Список всех блочных устройств (дисков) и их разделов, с точками монтирования.
    *   `sudo fdisk -l`: Отображает таблицу разделов диска (удобно для MBR).  Замените `/dev/sda` на нужное устройство.
    *   `sudo parted -l`: Более подробная информация о разделах, в том числе и GPT (включает файловую систему, метку).
*   **Посмотреть точки монтирования и статус разделов:**
    *   `df -h`: Показать использование дискового пространства, включая смонтированные разделы и их точки монтирования.
    *   `mount`: Показать все смонтированные файловые системы.
*   **Посмотреть информацию о файловой системе:**
    *   `sudo blkid /dev/sdXN`:  Показать UUID, тип файловой системы, метку раздела. (Замените `sdXN` на номер раздела, например, `sda1`).
    *   `sudo wipefs /dev/sdXN`: Показать информацию о файловой системе, таблице разделов. (Замените `sdXN` на номер раздела, например, `sda1`).

*   **Создать раздел (пример для GPT, с `gdisk`):**
    1.  `sudo gdisk /dev/sdX` (замените `/dev/sdX` на диск)
    2.  `o` (создать новую таблицу GPT)
    3.  `n` (создать новый раздел)
    4.  Укажите номер раздела, начальный и конечный секторы (или размер).
    5.  `w` (записать изменения).

*   **Отформатировать раздел:** Используется команда `mkfs` (make filesystem) для создания файловой системы на разделе.  Синтаксис: `sudo mkfs.<тип_файловой_системы> /dev/sdXN` или `sudo mkfs -t xfs -f /dev/sdb`
    *   `sudo mkfs.<filesystem> /dev/sdXN`
    *   Примеры:
        *   `sudo mkfs -f ext4 /dev/sda1`  (Создание ext4 файловой системы)
        *   `sudo mkfs -f xfs /dev/sda2`  (Создание XFS файловой системы)
        *   `sudo mkfs -f btrfs /dev/sdb1` (Создание Btrfs файловой системы)
        *   `sudo mkfs -f vfat /dev/sdc1` (Создание FAT32 файловой системы, для USB накопителей, например)
        *   `sudo mkswap /dev/sda3` (для swap)

    *   **Опции mkfs:**  Многие `mkfs` команды имеют опции, позволяющие настроить параметры файловой системы. Например:
        *   `mkfs.ext4 -L "Метка_тома" /dev/sda1` (Установка метки тома)
        *   `mkfs.ext4 -m 1 /dev/sda1` (Установка резервированного процента блоков для root)
        *   `mkfs.xfs -f /dev/sdb1` (Принудительное форматирование, если раздел уже содержит файловую систему)

*   **Примонтировать раздел:**
    1.  `sudo mkdir /mnt/имя_точки_монтирования` (Создать папку для монтирования, например, `/mnt/mydisk`)
    2.  `sudo mount /dev/sdXN /mnt/имя_точки_монтирования` (Примонтировать раздел)

*   **Автоматическое монтирование при загрузке (из `/etc/fstab`):**
    1.  Получить UUID раздела:  `sudo blkid /dev/sdXN`
    2.  Отредактировать `/etc/fstab`:  `sudo nano /etc/fstab`
    3.  Добавить строку (замените UUID, точку монтирования и тип файловой системы):
       ```
       UUID="a1b2c3d4-e5f6-7890-1234-567890abcdef" /mnt/имя_точки_монтирования ext4 defaults 0 2
       #  1                                     2        3      4         5 6
       # 1: UUID раздела.
       # 2: Точка монтирования.
       # 3: Тип файловой системы.
       # 4: Опции монтирования.
       # 5: Dump flag (используется для резервного копирования; 0 - не использовать).
       # 6: fsck order (порядок проверки файловой системы при загрузке; 0 - не проверять).
       ```

        *   **Опции монтирования (defaults):**
            *   `defaults`:  Стандартный набор опций (rw, suid, dev, exec, auto, nouser, async).
            *   `noatime`:  Не обновлять время последнего доступа к файлам (улучшает производительность).
            *   `nodiratime`: Не обновлять время последнего доступа к каталогам.
            *   `ro`:  Монтировать в режиме "только чтение".
            *   `rw`: Монтировать в режиме "чтение-запись".
            *   `user`:  Позволяет обычному пользователю монтировать файловую систему.
            *   `noauto`:  Не монтировать автоматически при загрузке.
    4.  Проверить: `sudo mount -a` (чтобы применить изменения).

*   **Важно:** Всегда используйте `lsblk` или `sudo parted -l` для определения правильных имен дисков и разделов! Никогда не работайте с дисками, о которых вы ничего не знаете, и всегда делайте резервное копирование данных.

**I. Основные понятия:**

*   **Раздел (Partition):** Логически отделенная область на физическом диске.
*   **Файловая система (File system):** Структура, определяющая, как данные хранятся и управляются на разделе.
*   **Точка монтирования (Mount point):** Каталог в файловой системе, куда монтируется раздел, делая его доступным.
*   **Device Name (Имя устройства):** Идентификатор физического диска (например, `/dev/sda`, `/dev/nvme0n1`).
*   **Partition Number (Номер раздела):** Идентификатор раздела на диске (например, `/dev/sda1`, `/dev/nvme0n1p2`).
*   **Superuser (Root):** Права, необходимые для выполнения операций с дисками.

**II. Инструменты для работы с разделами:**

*   **`fdisk`:**
    *   **Описание:** Текстовый инструмент для создания и управления разделами MBR (Legacy).
    *   **Применение:** Работа со старыми системами, дисками с MBR разметкой.
    *   **Важно:** На дисках с GPT лучше использовать `gdisk`.
*   **`gdisk`:**
    *   **Описание:** Текстовый инструмент для создания и управления разделами GPT.
    *   **Применение:** Работа с современными системами, дисками с GPT разметкой.
*   **`parted`:**
    *   **Описание:** Более мощный текстовый инструмент, поддерживающий как MBR, так и GPT. Позволяет изменять размер разделов, перемещать их и выполнять другие операции.
    *   **Применение:** Работа с разделами, когда требуется гибкость и сложные операции.
*   **`lsblk`:**
    *   **Описание:** Утилита для вывода информации о блочных устройствах (диски, разделы).
    *   **Применение:** Просмотр структуры дисков и разделов.
*   **`blkid`:**
    *   **Описание:** Утилита для получения информации об атрибутах блочных устройств (UUID, метка файловой системы, тип).
    *   **Применение:** Получение уникальных идентификаторов для монтирования разделов.
*   **wipefs**:
    *   **Описание**: Утилита для очистки сигнатур файловых систем и таблиц разделов. Полезно, когда нужно "очистить" диск от старой информации перед его переформатированием.
    *   **Применение**:  Очистка диска перед созданием новой таблицы разделов, решение проблем с монтированием из-за старых сигнатур.
    *   **Пример**: `sudo wipefs -a /dev/sdX` (очистит все сигнатуры на диске sdX).
    *   **Внимание**: Будьте осторожны с `wipefs`, так как она может удалить данные, если используется неправильно.

**III. Процесс создания и форматирования разделов (Общий):**

1.  **Определение устройства:**
    *   Используйте `lsblk` для идентификации диска, с которым будете работать (например, `/dev/sda`).
    *   **ВНИМАНИЕ:** Убедитесь, что вы выбрали правильный диск! Ошибки могут привести к потере данных.
2.  **Запуск инструмента для работы с разделами (от имени root):**
    *   `sudo fdisk /dev/sda` (для MBR)
    *   `sudo gdisk /dev/sda` (для GPT)
    *   `sudo parted /dev/sda` (для MBR/GPT)
3.  **Создание разделов:** (Примеры команд для `fdisk`/`gdisk`, `parted` немного отличается)
    *   `n` - создать новый раздел.
    *   Выбор типа раздела (primary/extended для MBR, для GPT - автоматически).
    *   Указание начального и конечного сектора (или размера раздела).
4.  **Изменение типа раздела (опционально):**
    *   `t` - изменить тип раздела (например, для swap).
5.  **Сохранение изменений:**
    *   `w` - записать изменения на диск и выйти (в `fdisk`/`gdisk`).
    *   В `parted` изменения применяются немедленно, но рекомендуется использовать `print` для проверки, а затем `quit` для выхода.
6.  **Форматирование раздела:**
    *   `sudo mkfs.<filesystem> /dev/sda<номер_раздела>`
    *   Примеры:
        *   `sudo mkfs.ext4 /dev/sda1`
        *   `sudo mkfs.xfs /dev/sda2`
        *   `sudo mkswap /dev/sda3` (для swap)
7.  **Монтирование раздела:**
    *   Создание точки монтирования: `sudo mkdir /mnt/mydisk`
    *   Монтирование раздела: `sudo mount /dev/sda1 /mnt/mydisk`
    *   Проверка монтирования: `df -h`

**VI. Пример форматирования (после создания раздела):**

```bash
sudo mkfs.ext4 /dev/sda1
```

**VII. Монтирование раздела (После форматирования):**

```bash
sudo mkdir /mnt/mydisk  # Создаем папку, в которую будет примонтирован диск
sudo mount /dev/sda1 /mnt/mydisk # Примонтировали раздел в папку mydisk
df -h # Проверяем, чтобы убедиться, что диск примонтировался
```

**VIII. Автоматическое монтирование при загрузке (Редактирование /etc/fstab):**

1.  **Получение UUID раздела:** `sudo blkid /dev/sda1`
    *   Запомните UUID, например: `UUID="a1b2c3d4-e5f6-7890-1234-567890abcdef"`
2.  **Редактирование `/etc/fstab`:** `sudo nano /etc/fstab`
3.  **Добавление строки:**
    ```
    UUID="a1b2c3d4-e5f6-7890-1234-567890abcdef" /mnt/mydisk ext4 defaults 0 2
    ```
    *   `UUID="..."`: UUID раздела.
    *   `/mnt/mydisk`: Точка монтирования.
    *   `ext4`: Тип файловой системы.
    *   `defaults`: Опции монтирования (обычно подходят).
    *   `0`: Не проверять файловую систему при загрузке.
    *   `2`: Порядок проверки (0 - не проверять).
4.  **Проверка:** `sudo mount -a` (Монтирует все разделы, указанные в `/etc/fstab`).

**IX. Типы файловых систем:**

*   `ext4`:  Стандартная и наиболее распространенная файловая система для Linux. Хороший выбор по умолчанию.
*   `XFS`:  Высокопроизводительная файловая система, хорошо подходит для больших файлов и серверов.
*   `Btrfs`:  Современная файловая система с расширенными функциями, такими как снапшоты и встроенное сжатие.
*   `FAT32`:  Совместима с большинством операционных систем, используется для USB накопителей и карт памяти.  Ограничение на размер файла (4 ГБ).
*   `NTFS`: Используется в Windows,  Linux может читать и писать на NTFS разделы (используйте пакет `ntfs-3g`).

**X. SWAP (Раздел подкачки):**

*   Создание SWAP раздела:
    *   `sudo fdisk /dev/sdX` или `sudo parted /dev/sdX`
    *   Создать раздел, как обычно (тип `Linux swap`).
*   Форматирование SWAP раздела:  `sudo mkswap /dev/sdXN`
*   Активация SWAP раздела: `sudo swapon /dev/sdXN`
*   Отключение SWAP раздела: `sudo swapoff /dev/sdXN`
*   Автоматическое включение при загрузке: Добавить в `/etc/fstab` строку:
    `UUID="ваш_uuid" none swap sw 0 0`
*   Просмотр информации о SWAP: `swapon -s` или `free -h`

**XI. Важные моменты и предостережения:**

*   **Резервное копирование:** Перед любыми операциями с дисками сделайте резервную копию важных данных!
*   **Внимательность:** Будьте предельно внимательны при выборе диска и разделов. Ошибки могут привести к потере данных.
*   **Права root:** Операции с дисками требуют прав суперпользователя (root).
*   **Корректное завершение:** Убедитесь, что все процессы записи на диск завершены перед перезагрузкой компьютера.
*   **UUID vs. /dev/sdX:** Использование UUID в `/etc/fstab` более надежно, чем использование `/dev/sdaX`, так как UUID остается постоянным даже если порядок дисков изменится.
*   **SWAP:** Для разделов SWAP используйте `sudo mkswap /dev/sdXX` и `swapon /dev/sdXX`.
*   При форматировании разделов под конкретные цели (например, сервер баз данных) изучите опции `mkfs` для выбранной файловой системы и настройте ее соответствующим образом.
