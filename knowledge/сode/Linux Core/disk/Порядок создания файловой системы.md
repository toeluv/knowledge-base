## **1. Процесс создания и монтирования файловой системы**  
Порядок действий:  

1. **Разметка диска (`fdisk /dev/sda`)**  
   - Создаются разделы `/dev/sda1` и `/dev/sda2`.  
   - Пример:  
     ```bash
     fdisk /dev/sda  # запуск утилиты разметки
     n               # создание нового раздела
     p               # primary раздел
     1               # номер раздела (например, /dev/sda1)
     ```  

2. **Создание файловой системы (`mkfs.ext4 /dev/sda2`)**  
   - На разделе `/dev/sda2` форматируется файловая система **ext4**.  
   - Пример:  
     ```bash
     mkfs.ext4 /dev/sda2  # форматирование в ext4
     ```  

3. **Монтирование раздела (`mount /dev/sda2 /home`)**  
   - Раздел `/dev/sda2` подключается к каталогу `/home`.  
   - Для автоматического монтирования при загрузке используется `/etc/fstab`.  
   - Пример записи в `fstab`:  
     ```
     /dev/sda2  /home  ext4  defaults  0  2
     ```
