## Проверка файловой системы в Linux

Эти команды позволяют получить информацию об использовании дискового пространства в Linux. `df` показывает свободное место на смонтированных файловых системах, а `du` отображает использование диска конкретными файлами и каталогами.

**1. `df` (Disk Free): Информация о свободном дисковом пространстве**

*   **Описание:** Команда `df` предоставляет информацию об общем размере, использованном пространстве, доступном пространстве и точках монтирования файловых систем.

*   **Синтаксис:** `df [опции] [файловая_система|файл]`

*   **Опции:**

    *   `-h` (human-readable): Отображает размеры в удобном для чтения формате (например, K, M, G).
    *   `-u` (или `--portability`): Отображает информацию в формате, более подходящем для скриптов. В основном влияет на вывод чисел, чтобы они не зависели от локали. В большинстве случаев лучше использовать `-h` для чтения человеком и вывод, который легко парсить (например, используя `--output` для `df` или `--block-size=1` для `du`).
    *   `-i` (inodes): Отображает информацию об использовании inodes.
    *   `-T` (type): Отображает тип файловой системы.
    *   `-a` (all): Отображает все файловые системы, включая те, у которых размер равен 0.
    *   `-x` (exclude-type=тип): Исключает файловые системы указанного типа.

*   **Примеры:**

    *   `df -h`: Отображает информацию о свободном месте на всех смонтированных файловых системах в удобочитаемом формате.  Это наиболее часто используемый вариант.
    *   `df -T`: Показывает тип файловой системы для каждого смонтированного раздела.
    *   `df -i`:  Отображает информацию об использовании inode (см. ниже).
    *   `df -h /`: Отображает информацию о корневой файловой системе.
    *   `df -h /mnt/mydisk`: Отображает информацию о файловой системе, смонтированной в `/mnt/mydisk`.
    *   `df -x tmpfs`: Исключить из вывода файловые системы типа `tmpfs`.

*   **Вывод:**

    ```
    Файловая система Размер Использовано  Доступно Использовано% Cмонтирована на
    udev             3,9G            0      3,9G            0% /dev
    tmpfs            797M         1,5M      796M            1% /run
    /dev/sda2        228G         125G       92G           58% /
    tmpfs            3,9G         138M      3,8G            4% /dev/shm
    tmpfs            5,0M         4,0K      5,0M            1% /run/lock
    tmpfs            3,9G            0      3,9G            0% /sys/fs/cgroup
    /dev/sda1        976M         140M      837M           15% /boot
    tmpfs            797M          64K      797M            1% /run/user/1000
    ```

**2. `du` (Disk Usage): Информация об использовании диска**

*   **Описание:** Команда `du` оценивает использование дискового пространства файлами и каталогами.  В отличие от `df`, которая показывает информацию о файловых системах, `du` показывает, *что* занимает место.

*   **Синтаксис:** `du [опции] [каталог|файл]`

*   **Опции:**

    *   `-h` (human-readable): Отображает размеры в удобном для чтения формате.
    *   `-s` (summarize): Отображает только общую сумму для каждого указанного аргумента (каталога или файла).  Без `-s`, `du` показывает размер для каждого подкаталога.
    *   `-c` (total):  Отображает общую сумму для всех указанных аргументов в конце вывода.
    *   `-k` (kilobytes): Отображает размеры в килобайтах. Аналогично `-m` для мегабайт и `-g` для гигабайт.
    *   `-m` (megabytes): Отображает размеры в мегабайтах.
    *   `-d` (depth=N): Ограничивает глубину рекурсивного поиска по каталогам. `du -d 1` покажет размер текущего каталога и его непосредственных подкаталогов.
    *   `-x` (one-file-system):  Не пересекать границы файловых систем.  Полезно, если вы хотите узнать использование диска только в текущей файловой системе.
    *   `--exclude='Паттерн'`:  Исключить файлы и каталоги, соответствующие указанному паттерну.

*   **Примеры:**

    *   `du -h .`: Отображает использование диска текущим каталогом и всеми его подкаталогами, в удобочитаемом формате.
    *   `du -sh .`: Отображает общий размер текущего каталога (без подкаталогов) в удобочитаемом формате.
    *   `du -sh /var/log`:  Показывает общий размер каталога `/var/log`.
    *   `du -h -d 1 .`: Отображает размер текущего каталога и его подкаталогов первого уровня.
    *   `du -shc /var/log /tmp`:  Показывает общий размер `/var/log`, `/tmp` и общую сумму.
    *   `du -sh --exclude='*.log' .`: Показывает использование диска в текущем каталоге, исключая все файлы с расширением `.log`.

*   **Вывод:**

    ```
    4,0K    ./.config/menus
    4,0K    ./.config/gtk-3.0/bookmarks
    8,0K    ./.config/gtk-3.0
    4,0K    ./.config/ibus/bus
    8,0K    ./.config/ibus
    ...
    2,1M    ./.config
    1,3M    ./Загрузки
    1,6M    .
    ```

**3. Inode (Index Node):**

*   **Описание:** Inode - это структура данных в файловой системе Linux, которая хранит метаданные о файле или каталоге.  Метаданные включают:
    *   Размер файла
    *   Права доступа (разрешения)
    *   Владелец и группа
    *   Временные метки (время создания, изменения, последнего доступа)
    *   Указатели на блоки данных, где хранится содержимое файла.
*   **Важно:** Inode *не* хранит имя файла. Имя файла хранится в каталоге, который содержит ссылку на соответствующий inode.

*   **Ограничение inodes:** Каждая файловая система имеет ограниченное количество inodes. Если на файловой системе заканчиваются inodes, даже если есть свободное дисковое пространство, вы не сможете создавать новые файлы или каталоги.

*   **Просмотр использования inodes:**
    *   `df -i`:  Показывает общее количество inodes, использованные inodes и доступные inodes для каждой файловой системы.

*   **Когда нехватка inodes может стать проблемой:**
    *   Когда на файловой системе очень много маленьких файлов (например, в кэшах веб-серверов, почтовых серверах).  Каждый файл, даже самый маленький, требует inode.

**4. Другие полезные команды:**

*   `tree`: Отображает структуру каталогов в виде дерева. (Нужно установить: `sudo apt install tree` или аналогично)  Полезно для визуализации структуры.

*   `ncdu`:  Интерактивная утилита для анализа использования диска.  Позволяет перемещаться по файловой системе и быстро определять, какие каталоги занимают больше всего места. (Нужно установить: `sudo apt install ncdu` или аналогично)

*   `find`: Очень мощная команда для поиска файлов по различным критериям, включая размер, дату изменения и т.д.  Можно использовать в сочетании с `du` для более точного анализа.

    *   Пример: Найти 10 самых больших файлов в каталоге `/var/log`:
        ```bash
        find /var/log -type f -printf '%s %p\n' | sort -nr | head -10
        ```

**Примеры использования вместе:**

1.  **Найти самые большие каталоги в `/var`:**

    ```bash
    du -h -d 1 /var | sort -hr | head -10
    ```

2.  **Проверить, достаточно ли inodes на корневой файловой системе:**

    ```bash
    df -i /
    ```

3. **Выяснить, почему заканчивается место:**

   * Сначала `df -h` чтобы увидеть, какой раздел заполнен.
   * Затем `du -hsx /* | sort -rh | head -20` чтобы увидеть, какие папки в этом разделе больше всего занимают места.

**Важно:**

*   Всегда запускайте `du` от имени пользователя, для которого вы хотите узнать использование диска.  Запуск от имени root может показать размеры файлов, к которым у обычного пользователя нет доступа.
*   Команды `df` и `du` предоставляют моментальный снимок использования диска.  Информация может измениться, пока вы анализируете вывод.
*   При использовании `du` с опцией `-s` будьте осторожны, так как сканирование больших файловых систем может занять много времени.

Понимание этих команд и концепции inodes поможет вам эффективно управлять дисковым пространством в вашей системе Linux.
