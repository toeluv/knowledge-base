## MBR vs. GPT: Схемы разделов диска

**MBR (Master Boot Record)**

*   **Что это:** Стандартная схема разделов диска, использующаяся с 1983 года. Она хранит информацию о разделах и загрузочный код в первом секторе диска (512 байт).
*   **Особенности:**
    *   **Ограничение на размер диска:** Поддерживает диски размером до 2.2 ТБ.
    *   **Ограничение на количество основных разделов:** Можно создать только 4 основных раздела. Для большего количества разделов нужно использовать один расширенный раздел, внутри которого создаются логические диски.
    *   **Загрузочный код:** Содержит код, необходимый для загрузки операционной системы.
    *   **Простота:** Относительно простая структура, но устаревшая.
*   **Применение:**
    *   Использовалась повсеместно на старых компьютерах.
    *   Все еще может использоваться на небольших дисках или для обеспечения совместимости со старыми системами.

**GPT (GUID Partition Table)**

*   **Что это:** Современная схема разделов диска, являющаяся частью стандарта UEFI. Использует таблицу разделов с GUID (Globally Unique Identifiers) для идентификации каждого раздела.
*   **Особенности:**
    *   **Поддержка больших дисков:** Поддерживает диски размером более 2.2 ТБ (теоретически до 9.4 ZB).
    *   **Большое количество разделов:** Позволяет создавать до 128 разделов (обычно).
    *   **Надежность:** Хранит несколько копий таблицы разделов для восстановления в случае повреждения.
    *   **Совместимость с UEFI:** Требуется для загрузки операционных систем в режиме UEFI.
*   **Применение:**
    *   Стандарт для современных компьютеров с UEFI.
    *   Используется для дисков большого размера и для систем, требующих больше 4 разделов.

**Сравнение MBR и GPT:**

| Характеристика         | MBR                     | GPT                     |
|-------------------------|--------------------------|--------------------------|
| Размер диска             | до 2.2 ТБ               | более 2.2 ТБ             |
| Количество разделов    | до 4 основных           | до 128                   |
| Загрузка               | BIOS                    | UEFI                     |
| Надежность             | низкая                  | высокая                  |
| Современность            | устаревшая              | современная              |
