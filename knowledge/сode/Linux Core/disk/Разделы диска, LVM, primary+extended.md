**I. Разделы диска (MBR)**

*   **Контекст:** Относится к дискам, использующим схему разделов **MBR (Master Boot Record)**.
*   **Primary Partitions (Основные разделы):**
    *   Независимые разделы.
    *   Максимум 4 основных раздела на диске.
    *   Может быть помечен как "активный" (bootable) для загрузки ОС.
    *   Прямой доступ к дисковому пространству.
*   **Extended Partition (Расширенный раздел):**
    *   Специальный тип *основного* раздела, предназначенный для обхода ограничения в 4 раздела.
    *   Только 1 расширенный раздел на диске.
    *   Не может содержать данные напрямую.
    *   Содержит логические диски.
*   **Logical Drives (Логические диски):**
    *   Разделы, созданные *внутри* расширенного раздела.
    *   Используются для хранения данных и установки ОС (но загрузка с них сложнее).
    *   Не являются основными разделами.

**Схема MBR:**

`[Primary Partition] [Primary Partition] [Primary Partition] [Extended Partition]`

`[Extended Partition] -> [Logical Drive] [Logical Drive] [Logical Drive]`

**II. LVM (Logical Volume Manager)**

*   **Назначение:** Обеспечивает гибкое управление дисковым пространством, позволяя динамически изменять размер разделов, объединять несколько дисков в один логический том и делать снапшоты.

*   **Структура LVM:**

    1.  **Physical Volumes (PVs):**
        *   Физические тома - это физические разделы (обычно), которые используются для создания LVM.
        *   Инициализируются командой `pvcreate`.
    2.  **Volume Group (VG):**
        *   Группа томов - это контейнер, объединяющий один или несколько PVs.
        *   VG действует как единый пул дискового пространства.
        *   Создается командой `vgcreate`.
    3.  **Logical Volumes (LVs):**
        *   Логические тома - это виртуальные разделы, созданные внутри VG.
        *   LVs можно форматировать и монтировать как обычные разделы.
        *   Создаются командой `lvcreate`.

*   **Преимущества LVM:**

    *   **Гибкость:** Динамическое изменение размера разделов (LVs) без потери данных.
    *   **Объединение дисков:** Создание логических томов, охватывающих несколько физических дисков.
    *   **Снапшоты:** Быстрое создание копий LVs для резервного копирования или тестирования.
    *   **Перемещение томов:** Перемещение LVs между физическими дисками (миграция данных).

*   **Основные команды LVM:**

    *   `pvcreate /dev/sdX1`: Создать PV на разделе /dev/sdX1.
    *   `vgcreate myvg /dev/sdX1 /dev/sdY1`: Создать VG с именем myvg, используя PVs /dev/sdX1 и /dev/sdY1.
    *   `lvcreate -L 10G -n mylv myvg`: Создать LV с именем mylv, размером 10GB в VG myvg.
    *   `lvresize -L +5G /dev/myvg/mylv`: Увеличить размер LV mylv на 5GB.
    *   `mkfs.ext4 /dev/myvg/mylv`: Отформатировать LV mylv в ext4.
    *   `mount /dev/myvg/mylv /mnt/mymount`: Смонтировать LV mylv в /mnt/mymount.
    *   `vgextend`: Добавить PV в VG.
    *   `vgreduce`: Удалить PV из VG.
    *   `lvremove`: Удалить LV.
    *   `vgremove`: Удалить VG.
    *   `pvremove`: Удалить PV.
    *   `pvs`, `vgs`, `lvs`: Отобразить информацию о PVs, VGs и LVs.

**III. Схема на примере (Совмещение MBR, LVM и файловой системы):**

1.  **Физический диск (/dev/sda):** MBR (или GPT, но рассматриваем MBR)
2.  **Раздел:** Один primary partition на весь диск (/dev/sda1), помечен как LVM.
    *   На GPT можно просто создать раздел и пометить его как LVM.
3.  **Physical Volume (PV):** Создается на разделе /dev/sda1.
4.  **Volume Group (VG):** Создается, используя PV.
5.  **Logical Volume (LV):** Создается внутри VG.
6.  **Файловая система:** ext4 форматируется на LV.
7.  **Точка монтирования:** LV монтируется в каталог (например, `/home`).

**Пример CLI (кратко):**

```bash
# Предполагаем, что /dev/sda1 существует (обычный primary раздел)

sudo pvcreate /dev/sda1       # Создать PV
sudo vgcreate myvg /dev/sda1     # Создать VG
sudo lvcreate -L 50G -n rootlv myvg  # Создать LV для корня
sudo lvcreate -L 20G -n homelv myvg   # Создать LV для /home

sudo mkfs.ext4 /dev/myvg/rootlv  # Форматировать LV
sudo mkfs.ext4 /dev/myvg/homelv   # Форматировать LV

# Создать папки
sudo mkdir /mnt/root
sudo mkdir /mnt/home

# Примонтировать разделы (Временно! Для проверки)
sudo mount /dev/myvg/rootlv /mnt/root
sudo mount /dev/myvg/homelv /mnt/home

# Настроить автоматическое монтирование в /etc/fstab (как описывалось ранее)
```

**IV. Важные моменты:**

*   LVM работает *поверх* физических разделов.
*   Нельзя создать LV непосредственно на физическом диске, нужно создать PV и VG.
*   Рекомендуется использовать UUID для автоматического монтирования в `/etc/fstab`.

**V. Преимущества LVM относительно обычных разделов:**

*   **Гибкость:** Динамическое изменение размеров, снапшоты.
*   **Абстракция:** Не нужно жестко привязываться к физическому диску.
*   **Объединение дисков:** Можно использовать несколько дисков как один логический том.

Этот конспект предоставляет обзор основных и расширенных разделов (MBR) и концепции LVM для гибкого управления дисковым пространством.
