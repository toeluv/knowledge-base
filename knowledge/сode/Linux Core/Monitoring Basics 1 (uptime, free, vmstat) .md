## Конспект по Мониторингу Системы Linux

Этот конспект содержит информацию о командах для мониторинга состояния системы Linux.

### `uptime` - Время работы системы

*   **Описание:** Отображает время работы системы, количество пользователей, работающих в данный момент, и среднюю загрузку за последние 1, 5 и 15 минут.
*   **Синтаксис:** `uptime`
*   **Вывод (пример):**
    ```
    14:35:23 up 1 day, 20 min,  2 users,  load average: 0.00, 0.01, 0.05
    ```
*   **Разбор вывода:**
    *   `14:35:23`: Текущее время.
    *   `up 1 day, 20 min`: Время работы системы.
    *   `2 users`: Количество пользователей, вошедших в систему.
    *   `load average: 0.00, 0.01, 0.05`: Средняя загрузка процессора за 1, 5 и 15 минут соответственно.  Значения больше 1.0 указывают на то, что процессор перегружен.

### `free` - Информация об использовании памяти

*   **Описание:** Отображает информацию об использовании оперативной памяти (RAM) и swap-пространства.
*   **Синтаксис:** `free [OPTIONS]`
*   **Опции:**
    *   `-h`:  Вывод в человекочитаемом формате (например, KB, MB, GB).
    *   `-m`: Вывод в мегабайтах.
    *   `-k`: Вывод в килобайтах (по умолчанию).
    *   `-s <interval>`: Обновление данных каждые `<interval>` секунд.
    *   `-t`:  Вывод общей информации (включая swap).
*   **Вывод (пример с `-h`):**
    ```
                  total        used        free      shared  buff/cache   available
    Mem:           15Gi       3.0Gi       7.2Gi       1.0Gi       5.2Gi       9.8Gi
    Swap:          2.0Gi          0B       2.0Gi
    ```
*   **Разбор вывода:**
    *   `total`: Общий объем памяти (RAM и swap).
    *   `used`:  Использованная память.
    *   `free`:  Свободная память.
    *   `shared`: Память, используемая несколькими процессами.
    *   `buff/cache`:  Память, используемая буферами (buffers) и кэшем (cache).  Использование этой памяти не всегда означает, что она задействована "в полную силу", так как ОС может высвобождать эту память для других нужд.
    *   `available`:  Оценка доступной памяти для новых процессов.  Учитывает `free` и часть `buff/cache`, которую можно освободить.
    *   `Swap`: Информация о swap-пространстве (если используется).

### `vmstat` -  Статистика производительности виртуальной памяти, процессора и I/O

*   **Описание:**  Предоставляет подробную статистику о производительности системы, включая информацию о виртуальной памяти, процессоре, дисковом вводе/выводе, прерываниях и переключениях контекста.
*   **Синтаксис:** `vmstat [OPTIONS] [delay] [count]`
    *   `delay`:  Интервал обновления данных в секундах (по умолчанию - нет).
    *   `count`: Количество обновлений (по умолчанию - бесконечно).
*   **Опции:**
    *   `-n`: Не отображать заголовок при каждом обновлении.
    *   `-w`: Широкий вывод (больше информации).
*   **Вывод (пример):**
    ```
    procs -----------memory---------- ---swap-- -----io---- -system-- ------cpu-----
     r  b   swpd   free   buff  cache   si   so    bi    bo   in   cs us sy id wa st
     1  0      0  774888  12400 248400    0    0     0     1   14   31  1  1 97  1  0
     0  0      0  774888  12400 248400    0    0     0     0   14   28  0  1 99  0  0
     0  0      0  774888  12400 248400    0    0     0     0   15   30  0  1 99  0  0
    ```
*   **Разбор вывода (основные колонки):**
    *   `procs`: Информация о процессах:
        *   `r`: Количество процессов, ожидающих выполнения (ready).
        *   `b`: Количество процессов, находящихся в состоянии сна (блокированы).
    *   `memory`: Информация о памяти:
        *   `swpd`:  Объем памяти, используемый swap.
        *   `free`:  Объем свободной памяти (в килобайтах).
        *   `buff`:  Объем памяти, используемый буферами.
        *   `cache`:  Объем памяти, используемый кэшем.
    *   `swap`: Информация о swap:
        *   `si`:  Количество памяти, перемещенной из swap (за секунду).
        *   `so`:  Количество памяти, перемещенной в swap (за секунду).  Большие значения `si` и `so` указывают на нехватку RAM.
    *   `io`:  Информация об I/O:
        *   `bi`:  Количество блоков, прочитанных с диска (за секунду).
        *   `bo`:  Количество блоков, записанных на диск (за секунду).  Большие значения могут указывать на проблемы с дисковой подсистемой.
    *   `system`: Информация о системе:
        *   `in`:  Количество прерываний (interrupts) за секунду.
        *   `cs`:  Количество переключений контекста (context switches) за секунду.
    *   `cpu`:  Информация о загрузке CPU:
        *   `us`:  Пользовательское время (время, затраченное на выполнение пользовательских процессов).
        *   `sy`:  Системное время (время, затраченное на выполнение системных процессов).
        *   `id`:  Время простоя (idle time).  Высокое значение указывает на неиспользование CPU.
        *   `wa`:  Время ожидания ввода-вывода (I/O wait).  Высокое значение может указывать на проблемы с диском.
        *   `st`:  Время, украденное (stolen time).  В виртуальных машинах: время, которое виртуальная машина ожидала, когда CPU физического хоста был занят другой виртуальной машиной.

### `pstree` - Отображение процессов в виде дерева

*   **Описание:** Отображает запущенные процессы в виде дерева, что позволяет визуально понять иерархию процессов (какой процесс породил какой).
*   **Синтаксис:** `pstree [OPTIONS] [PID или USER]`
    *   `PID`:  Показать дерево процессов, начиная с указанного PID (Process ID).
    *   `USER`:  Показать дерево процессов, принадлежащих указанному пользователю.  Если не указано, отображает все процессы.
*   **Опции:**
    *   `-p`: Показать PID процессов.
    *   `-u`: Показать имя пользователя, владельца процесса.
    *   `-a`: Показать аргументы командной строки.
    *   `-n`: Сортировать по PID.
    *   `-s PID`: Показать ветку дерева, ведущую к процессу с указанным PID.
*   **Вывод (пример, упрощенный):**
    ```
    systemd─┬─NetworkManager───2*[{NetworkManager}]
            ├─accounts-daemon───2*[{accounts-daemon}]
            ├─agetty───2*[{agetty}]
            ├─atd
            ├─cron
            ├─dbus-daemon
            ├─gdm3───gdm-session-wor─┬─gnome-session-b─┬─gnome-shell───2*[{gnome-shell}]
            │                     │                 │               ├─Xwayland
            │                     │                 │               └─2*[{Xwayland}]
            │                     │                 ├─2*[{gnome-session-b}]
            │                     │                 └─3*[{gdm-session-wor}]
            │                     └─3*[{gdm-session-wor}]
            ├─...
    ```
*   **Разбор вывода:**
    *   Вывод представляет собой древовидную структуру, где каждый процесс (или его нить) является узлом.
    *   `─┬` и `├─` показывают связи между процессами (родительский-дочерний).
    *   В примере видно, что `systemd` является родителем для множества других процессов.

**Использование в связке (пример):**

1.  **Диагностика проблем с производительностью:**  Использовать `uptime` для общей оценки загрузки, `free -h` для проверки нехватки памяти, `vmstat 1 5` для анализа загрузки CPU, I/O и swap.  Если `vmstat` показывает проблемы, использовать `pstree -p` для выявления "прожорливых" процессов, которые могут быть причиной проблем.

2.  **Мониторинг нагрузки:** Запустить `vmstat 5` (или `vmstat 1`) в отдельном терминале для непрерывного мониторинга.

3.  **Поиск процесса:**  Использовать `pstree -p | grep <process_name>` для нахождения процесса и его PID, а затем `pstree -s <PID>` для отображения родительских процессов.
