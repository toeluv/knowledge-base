Логи в Linux — это файлы, в которые записывается информация о работе системы, сервисов, приложений и различных событий. Они помогают администраторам диагностировать проблемы, анализировать безопасность и отслеживать активность в системе.

### **Основные каталоги с логами**
Большинство логов хранятся в `/var/log/`. Вот некоторые важные файлы и каталоги:

| Файл/Каталог       | Описание |
|-------------------|----------|
| `/var/log/syslog` | Общие системные сообщения (в Debian/Ubuntu) |
| `/var/log/messages` | Общие системные сообщения (в RHEL/CentOS) |
| `/var/log/auth.log` | Логи аутентификации и авторизации (логины, sudo) |
| `/var/log/secure` | Аналог `auth.log` в RHEL/CentOS |
| `/var/log/kern.log` | Сообщения ядра Linux |
| `/var/log/dmesg` | Логи загрузки и работы драйверов (можно также посмотреть командой `dmesg`) |
| `/var/log/boot.log` | Логи загрузки системы |
| `/var/log/cron` | Логи задач cron (запланированные задания) |
| `/var/log/maillog` | Логи почтового сервера |
| `/var/log/httpd/` | Логи веб-сервера Apache |
| `/var/log/nginx/` | Логи веб-сервера Nginx |
| `/var/log/mysql.log` | Логи СУБД MySQL/MariaDB |

### **Сервис journalctl (systemd)**
В современных дистрибутивах с `systemd` логи также хранятся в бинарном виде и управляются через `journalctl`:

```bash
journalctl -u nginx.service  # логи сервиса nginx
journalctl -f                # просмотр логов в реальном времени (аналог tail -f)
journalctl -p err -b         # ошибки с момента последней загрузки
journalctl --since "2024-05-10" --until "2024-05-11"  # логи за определённый период
```

### **Утилиты для работы с логами**
1. **`tail`** – просмотр конца файла:
   ```bash
   tail -n 20 /var/log/syslog  # последние 20 строк
   tail -f /var/log/auth.log   # следить за логами в реальном времени
   ```
2. **`grep`** – фильтрация логов:
   ```bash
   grep "error" /var/log/syslog  # поиск ошибок
   grep -i "fail" /var/log/auth.log  # поиск без учёта регистра
   ```
3. **`less` / `more`** – постраничный просмотр:
   ```bash
   less /var/log/syslog
   ```
4. **`logrotate`** – ротация логов (автоматическое сжатие и удаление старых логов).

### **Настройка логгирования**
- Конфигурация `rsyslog` (основной демон логирования) лежит в `/etc/rsyslog.conf` и `/etc/rsyslog.d/`.
- Настройки `logrotate` находятся в `/etc/logrotate.conf` и `/etc/logrotate.d/`.

### **Важно!**
- Логи могут занимать много места, их нужно чистить или настраивать ротацию.
- Некоторые приложения (например, Docker, PostgreSQL) могут хранить логи в своих каталогах.
- Для анализа больших логов можно использовать `awk`, `sed`, `ELK-стек` (Elasticsearch, Logstash, Kibana) или `Grafana Loki`.
