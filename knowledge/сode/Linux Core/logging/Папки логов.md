В Linux логи хранятся в различных папках в зависимости от типа событий и сервисов. Основные директории логирования:

### **1. Основные системные логи (`/var/log/`)**
Главная папка для большинства системных логов:
- `/var/log/syslog` – общие системные сообщения (Debian/Ubuntu)
- `/var/log/messages` – аналог syslog в RHEL/CentOS
- `/var/log/auth.log` (или `/var/log/secure`) – логи аутентификации (входы, sudo)
- `/var/log/kern.log` – сообщения ядра Linux
- `/var/log/boot.log` – логи загрузки системы
- `/var/log/dmesg` – логи драйверов и аппаратных событий (можно смотреть через `dmesg`)

---

### **2. Логи сервисов и демонов**
- `/var/log/cron` – логи планировщика задач `cron`
- `/var/log/maillog` (или `/var/log/mail.log`) – логи почтового сервера (Postfix, Sendmail)
- `/var/log/httpd/` (или `/var/log/apache2/`) – логи веб-сервера Apache
- `/var/log/nginx/` – логи Nginx
- `/var/log/mysql.log` (или `/var/log/mysqld.log`) – логи MySQL/MariaDB
- `/var/log/postgresql/` – логи PostgreSQL

---

### **3. Логи безопасности**
- `/var/log/faillog` – неудачные попытки входа (можно просмотреть через `faillog`)
- `/var/log/btmp` – неудачные попытки входа в систему (просмотр: `lastb`)
- `/var/log/wtmp` – история входов/выходов (просмотр: `last`)
- `/var/log/audit/` – логи аудита (если включен `auditd`)

---

### **4. Логи пакетного менеджера**
- `/var/log/dpkg.log` – логи установки/удаления пакетов в Debian/Ubuntu
- `/var/log/yum.log` – логи пакетного менеджера в RHEL/CentOS
- `/var/log/pacman.log` – логи Pacman (Arch Linux)

---

### **5. Логи графической среды**
- `/var/log/Xorg.0.log` – логи X-сервера (графическая подсистема)
- `~/.xsession-errors` – ошибки графической сессии пользователя (GNOME, KDE и др.)

---

### **6. Логи контейнеров и виртуализации**
- `/var/log/docker/` – логи Docker (если настроено)
- `/var/log/podman/` – логи Podman
- `/var/log/libvirt/` – логи виртуальных машин (KVM/QEMU)

---

### **7. Логи systemd (journald)**
- `/var/log/journal/` – бинарные логи `journald` (если включено постоянное хранение)
- Просмотр: `journalctl` (например, `journalctl -u nginx`)

---

### **8. Временные логи (в `/run/log/`)**
Некоторые логи хранятся в памяти (volatile) и исчезают после перезагрузки:
- `/run/log/journal/` – временные логи `journald` (если `Storage=volatile`)
- `/run/syslogd/` – временные файлы `syslog`

---

### **9. Кастомные логи приложений**
Некоторые программы создают свои логи в:
- `/opt/<app>/logs/` – например, логи проприетарного ПО
- `~/.cache/<app>/logs/` – логи пользовательских приложений

---

### **Как искать логи?**
1. **Поиск по сервису**:  
   ```bash
   ls /var/log/ | grep nginx
   ```
2. **Просмотр в реальном времени**:  
   ```bash
   tail -f /var/log/syslog
   ```
3. **Фильтрация через journalctl**:  
   ```bash
   journalctl -u mysql --since "1 hour ago"
   ```

---

### **Важно!**
- Логи могут занимать много места – следите за их ротацией (например, через `logrotate`).
- Некоторые логи требуют прав `root` для просмотра (`sudo less /var/log/secure`).
- Для анализа логов удобно использовать `grep`, `awk`, `sed` или специализированные инструменты (ELK, Grafana Loki).
