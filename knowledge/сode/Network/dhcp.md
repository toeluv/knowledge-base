### **DHCP (Dynamic Host Configuration Protocol)**  

#### **1. Что такое DHCP?**  
**DHCP** (Dynamic Host Configuration Protocol) — это сетевой протокол, который автоматически назначает IP-адреса и другие параметры сети (маску подсети, шлюз, DNS-серверы) устройствам в сети.  

- **Основная задача**: Избежать ручной настройки IP для каждого устройства.  
- **Порт**: Работает по **UDP 67 (сервер)** и **UDP 68 (клиент)**.  
- **Типы адресов**:  
  - **Динамический** (временный, выдается на lease time).  
  - **Статический** (закреплён за MAC-адресом).  

---

#### **2. Как работает DHCP?**  
Процесс получения IP-адреса (**DORA**):  

1. **Discover** (Поиск)  
   - Клиент отправляет широковещательный запрос `DHCPDISCOVER` (источник: `0.0.0.0`, назначение: `255.255.255.255`).  

2. **Offer** (Предложение)  
   - DHCP-сервер отвечает `DHCPOFFER` с предложенным IP.  

3. **Request** (Запрос)  
   - Клиент подтверждает выбор `DHCPREQUEST` (может быть несколько серверов).  

4. **Acknowledge** (Подтверждение)  
   - Сервер подтверждает выделение IP (`DHCPACK`) и отправляет параметры сети.  

*(Если сервер не отвечает, клиент использует **APIPA** — адрес вида `169.254.x.x`.)*  

---

#### **3. Основные параметры DHCP**  
- **IP-адрес** (динамический или статический).  
- **Маска подсети** (например, `255.255.255.0`).  
- **Шлюз по умолчанию** (роутер, например, `192.168.1.1`).  
- **DNS-серверы** (например, `8.8.8.8`, `1.1.1.1`).  
- **Срок аренды (lease time)** (например, 24 часа).  

---

#### **4. Типы DHCP-серверов**  
- **Роутер** (в домашних сетях).  
- **Windows Server** (для корпоративных сетей).  
- **Linux (ISC DHCP, dnsmasq)**.  

---

#### **5. Команды для работы с DHCP**  
- **Windows**:  
  ```cmd
  ipconfig /all          # Просмотр DHCP-параметров
  ipconfig /release      # Освободить IP
  ipconfig /renew        # Запросить новый IP
  ```
- **Linux**:  
  ```bash
  dhclient -r            # Освободить IP
  dhclient               # Запросить новый IP
  ```

---

#### **6. Плюсы и минусы DHCP**  
✅ **Плюсы**:  
- Автоматизация настройки сети.  
- Экономия IP-адресов (динамическое распределение).  
- Упрощение администрирования.  

❌ **Минусы**:  
- Зависимость от сервера (если DHCP "упал", клиенты не получат IP).  
- Возможны конфликты IP (если два сервера раздают одинаковые адреса).  

---

#### **7. Дополнительные механизмы**  
- **DHCP Relay** (для работы через маршрутизаторы).  
- **DHCP Snooping** (защита от атак поддельных DHCP-серверов).  

**Вывод**: DHCP критически важен для современных сетей, так как избавляет от ручного назначения IP и упрощает масштабирование.
