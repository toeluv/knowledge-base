### **VLAN (Virtual Local Area Network) и Trunk-порты**  
*Логическая сегментация сети с использованием транковых соединений*  

---

#### **1. Основные понятия**  
**VLAN (Virtual LAN)** - технология, позволяющая создавать независимые виртуальные сети в рамках одной физической инфраструктуры.  

**Trunk (транк)** - специальный тип порта на коммутаторе, который передает трафик нескольких VLAN одновременно, используя тегирование 802.1Q.  

Ключевые особенности:
- Изолирует широковещательные домены
- Позволяет логически разделять сеть без физического переподключения
- Транковые порты необходимы для связи между коммутаторами

---

#### **2. Типы VLAN**  

| Тип VLAN       | Назначение                          | Пример использования       |
|----------------|-------------------------------------|----------------------------|
| Data VLAN      | Обычный пользовательский трафик     | VLAN 10 - отдел продаж     |
| Voice VLAN     | Трафик VoIP телефонии               | VLAN 20 - IP-телефоны      |
| Management VLAN| Управление сетевым оборудованием    | VLAN 99 - доступ к свитчам |
| Native VLAN    | Принимает нетэгированный трафик     | По умолчанию VLAN 1        |

---

#### **3. Принцип работы VLAN и Trunk**  

**Access-порт:**
- Принадлежит только одной VLAN
- Не добавляет тегов VLAN к кадрам
- Используется для подключения конечных устройств

**Trunk-порт:**
- Передает трафик нескольких VLAN
- Добавляет тег 802.1Q к каждому кадру
- Используется для связи между коммутаторами

```plaintext
[Сервер]----[Коммутатор A (Trunk)]====[Коммутатор B (Trunk)]----[ПК1 (VLAN 10)]
               |                                                   |
            [ПК2 (VLAN 20)]                                     [ПК3 (VLAN 10)]
```

---

#### **4. Формат тега 802.1Q**  

Структура тегированного кадра:
```
| MAC получателя | MAC отправителя | 802.1Q Tag | Тип | Данные | FCS |
```

Состав тега VLAN (4 байта):
- **TPID** (0x8100) - идентификатор VLAN-трафика
- **PRI** (3 бита) - приоритет для QoS
- **CFI** (1 бит) - индикатор формата MAC-адреса
- **VLAN ID** (12 бит) - идентификатор VLAN (1-4094)

---

#### **5. Настройка VLAN и Trunk**  

**На Cisco-оборудовании:**
```bash
vlan 10
 name Sales
vlan 20
 name Voice

interface GigabitEthernet0/1
 switchport mode access
 switchport access vlan 10

interface GigabitEthernet0/24
 switchport mode trunk
 switchport trunk allowed vlan 10,20
```

**На Huawei:**
```bash
vlan batch 10 20

interface Ethernet0/0/1
 port link-type access
 port default vlan 10

interface Ethernet0/0/24
 port link-type trunk
 port trunk allow-pass vlan 10 20
```

---

#### **6. Преимущества и ограничения**  

✅ **Преимущества VLAN:**
- Повышение безопасности через изоляцию трафика
- Оптимизация производительности сети
- Гибкость управления сетевыми ресурсами

⚠ **Ограничения:**
- Необходимость дополнительной настройки меж-VLAN маршрутизации
- Ошибки конфигурации могут нарушить работу сети
- Ограничение в 4094 VLAN на одну сетевую инфраструктуру

---

#### **7. Практические примеры использования**  

1. **Корпоративная сеть:**
   - VLAN 10 - Финансовый отдел
   - VLAN 20 - Отдел разработки
   - VLAN 30 - Гостевой Wi-Fi

2. **Учебное заведение:**
   - VLAN 100 - Администрация
   - VLAN 200 - Преподаватели
   - VLAN 300 - Студенты

---

### **Вывод**  
VLAN с использованием Trunk-портов - мощный инструмент для построения гибких и безопасных сетевых инфраструктур. Правильная настройка VLAN и Trunk позволяет:
- Эффективно сегментировать сеть
- Оптимизировать использование полосы пропускания
- Упрощать управление сложными сетями

Для связи между разными VLAN потребуется маршрутизатор или L3-коммутатор.
