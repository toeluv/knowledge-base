### **Port Forwarding и DMZ**  

#### **1. Port Forwarding (Проброс портов)**  
**Назначение:** Перенаправление внешнего трафика с определенного порта маршрутизатора на внутренний сервер в локальной сети.  

**Применение:**  
- Доступ к веб-серверу, FTP, SSH из интернета.  
- Организация игровых серверов или VoIP.  

**Пример:**  
```
Интернет (запрос на 203.0.113.5:80) → Маршрутизатор (Port Forwarding: 203.0.113.5:80 → 192.168.1.100:80) → Внутренний сервер  
```  

**Диаграмма Port Forwarding:**  
```
[Internet] → (203.0.113.5:80) → [Router] → (192.168.1.100:80) → [Web Server]  
```  

**Как работает:**  
1. Внешний запрос приходит на публичный IP маршрутизатора.  
2. NAT (DNAT) меняет адрес назначения на внутренний IP сервера.  
3. Ответный трафик проходит обратный DNAT.  

---  

#### **2. DMZ (Demilitarized Zone – Демилитаризованная зона)**  
**Назначение:** Выделение отдельной сети для публичных серверов, изолированной от основной LAN.  

**Применение:**  
- Размещение веб-серверов, почтовых серверов, игровых хостов.  
- Повышение безопасности (минимизация риска взлома внутренней сети).  

**Реализация:**  
- **Полная DMZ (все порты открыты)** – весь входящий трафик перенаправляется на один хост (рискованно).  
- **Избирательная DMZ** – только определенные порты пробрасываются (аналог Port Forwarding, но для отдельной подсети).  

**Пример:**  
```
Интернет → Маршрутизатор → DMZ-хост (192.168.2.100)  
                          ↘ LAN (192.168.1.0/24)  
```  

**Диаграмма DMZ:**  
```
[Internet]  
     ↓  
[Router] → [DMZ Server:192.168.2.100] (публичные сервисы)  
     ↘  
[LAN Clients:192.168.1.0/24] (защищённая сеть)  
```  

---  

#### **3. Сравнение Port Forwarding и DMZ**  

| **Параметр**       | **Port Forwarding**               | **DMZ**                          |  
|--------------------|----------------------------------|----------------------------------|  
| **Гибкость**       | Точные правила для портов         | Весь трафик идёт на один хост    |  
| **Безопасность**   | Безопаснее (открыты только нужные порты) | Рискованно (все порты открыты) |  
| **Использование**  | Для отдельных сервисов (HTTP, SSH) | Для изолированных публичных серверов |  

---  

#### **4. Обратный Port Forwarding (Reverse Port Forwarding)**  
**Назначение:** Проброс порта из локальной сети наружу (например, для удалённого доступа к домашнему ПК).  

**Пример:**  
```
Локальный ПК (192.168.1.10:3389) → SSH-туннель → VPS (203.0.113.10:5000) → Интернет  
```  
**Применение:**  
- Обход NAT для удалённого доступа.  
- Организация VPN-подключений.  

---  

#### **5. Вывод**  
- **Port Forwarding** – точечный проброс портов (безопаснее).  
- **DMZ** – выделенная зона для публичных серверов (удобно, но требует защиты).  
- **Обратный проброс** – полезен для удалённого доступа без белого IP.  

**Диаграмма сравнения:**  
```
Port Forwarding: [Internet] → [Router:Port] → [Single Server]  
DMZ:           [Internet] → [Router] → [DMZ Host] (все порты)  
```
