### SNAT, DNAT и их обратные операции  

#### **1. SNAT (Source NAT)**  
**Назначение:** Подмена исходного IP-адреса пакета перед отправкой в другую сеть.  
**Применение:**  
- Маскировка внутренних IP-адресов (например, при выходе в интернет).  
- Обход ограничений маршрутизации.  

**Пример:**  
```
Локальный хост (192.168.1.10) → Маршрутизатор (SNAT: 192.168.1.10 → 203.0.113.5) → Интернет  
```  
**Диаграмма SNAT:**  
```
[Client:192.168.1.10] → (SNAT) → [Router:203.0.113.5] → Интернет  
```  

---  

#### **2. DNAT (Destination NAT)**  
**Назначение:** Подмена IP-адреса назначения для перенаправления трафика.  
**Применение:**  
- Проброс портов (Port Forwarding).  
- Балансировка нагрузки.  
- Доступ к сервисам за NAT.  

**Пример:**  
```
Интернет → Маршрутизатор (DNAT: 203.0.113.5:80 → 192.168.1.100:80) → Внутренний сервер  
```  
**Диаграмма DNAT:**  
```
Интернет → (DNAT) → [Router:203.0.113.5] → [Server:192.168.1.100]  
```  

---  

#### **3. Обратный DNAT vs. Обратный SNAT**  

| **Параметр**       | **Обратный DNAT**                     | **Обратный SNAT**                     |  
|---------------------|---------------------------------------|---------------------------------------|  
| **Суть**           | Восстановление исходного адреса назначения | Восстановление исходного адреса отправителя |  
| **Когда применяется** | Для ответных пакетов после DNAT       | Для ответных пакетов после SNAT       |  
| **Пример**         | Ответ сервера клиенту через NAT       | Ответ из интернета локальному хосту   |  

**Диаграмма ответа после DNAT (Обратный DNAT):**  
```
[Server:192.168.1.100] → (Обратный DNAT) → [Router:203.0.113.5] → Клиент в интернете  
```  

**Диаграмма ответа после SNAT (Обратный SNAT):**  
```
Интернет → (Обратный SNAT) → [Router:203.0.113.5] → [Client:192.168.1.10]  
```  

---  

#### **4. Ключевые отличия**  
- **Обратный DNAT** работает с адресом **назначения**, возвращая пакет к исходному маршруту после DNAT.  
- **Обратный SNAT** работает с адресом **источника**, возвращая пакет к отправителю после SNAT.  

**Важно:**  
- Обе операции автоматически обрабатываются NAT-устройством (если сессия сохранена в таблице состояний).  
- Для статических правил (например, проброса портов) обратный DNAT обязателен, а обратный SNAT используется для маскировки исходящего трафика.  

---  

#### **5. Визуализация**  
```
[Client] ----(SNAT)---> [NAT Router] ----> Интернет  
           <---(Обратный SNAT)---  

Интернет ----(DNAT)---> [NAT Router] ----> [Server]  
           <---(Обратный DNAT)---  
```  

**Вывод:**  
- SNAT изменяет источник, DNAT — назначение.  
- Обратные операции обеспечивают корректную маршрутизацию ответного трафика.
