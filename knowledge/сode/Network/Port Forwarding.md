## Port Forwarding
**Что такое Port Forwarding?**

Port Forwarding (проброс портов) – это настройка на роутере, которая позволяет перенаправлять входящий трафик с определенного порта на публичном IP-адресе роутера на конкретное устройство в локальной сети и на определенный порт этого устройства.

**Зачем нужен Port Forwarding?**

Port Forwarding необходим, когда тебе нужно, чтобы к определенному сервису (программе) на твоем компьютере из Интернета можно было подключаться напрямую. Это часто нужно для:

*   **Игровых серверов:**  Чтобы друзья могли подключиться к твоему игровому серверу.
*   **Веб-серверов:** Чтобы другие люди могли просматривать твой личный веб-сайт.
*   **FTP-серверов:** Чтобы можно было загружать и скачивать файлы с твоего компьютера извне.
*   **Удаленного доступа:** Чтобы можно было подключаться к своему компьютеру удаленно (например, через RDP или SSH).
*   **IP-камер:** Чтобы можно было просматривать видео с камеры из любой точки мира.

**Как работает Port Forwarding (на примере игрового сервера)?**

Предположим, ты хочешь запустить игровой сервер Minecraft на своем компьютере, у которого частный IP-адрес `192.168.1.101`. Minecraft использует порт `25565` по умолчанию.

1.  **Без Port Forwarding:**  Если друг попытается подключиться к твоему серверу, указав твой публичный IP-адрес (`203.0.113.45`), роутер получит запрос на порт `25565`. Но, поскольку роутер не знает, куда перенаправить этот запрос, он просто его отбросит.  Он не знает, какое устройство в локальной сети "слушает" этот порт.
2.  **С Port Forwarding:**  Чтобы это работало, тебе нужно настроить Port Forwarding на роутере:
    *   **Войти в настройки роутера:** Обычно это делается через веб-интерфейс, введя IP-адрес роутера (чаще всего `192.168.1.1` или `192.168.0.1`) в браузере.
    *   **Найти раздел Port Forwarding (или Virtual Server, Application, Gaming и т.д.):** Название может отличаться в зависимости от модели роутера.
    *   **Добавить правило Port Forwarding:**  Тебе нужно будет указать:
        *   **Service Name (Имя сервиса):**  Minecraft (или любое другое название, чтобы помнить, для чего это правило).
        *   **Protocol (Протокол):** TCP или UDP (Minecraft использует TCP).
        *   **External Port (Внешний порт) / Public Port:** `25565`.  Это порт, на который будут приходить запросы из Интернета.
        *   **Internal Port (Внутренний порт) / Private Port:** `25565`.  Это порт, на который работает Minecraft на твоем компьютере.  Часто внешний и внутренний порт совпадают.
        *   **Internal IP Address (Внутренний IP-адрес) / Private IP:** `192.168.1.101`.  Это IP-адрес твоего компьютера, на котором запущен Minecraft.
    *   **Сохранить настройки и перезагрузить роутер (если потребуется).**

3.  **Как это работает после настройки:**

    *   Теперь, когда друг попытается подключиться к твоему серверу, указав твой публичный IP-адрес (`203.0.113.45`) и порт `25565`, роутер увидит, что для этого порта настроено правило Port Forwarding.
    *   Роутер перенаправит запрос на твой компьютер (`192.168.1.101`) на порт `25565`.
    *   Твой игровой сервер Minecraft получит запрос и позволит другу подключиться.

**Картинка для наглядности:**

```
+-------------------------------------------------------+
|                     Интернет                           |
+-----------------------+-------------------------------+
                        |  Запрос на 203.0.113.45:25565 |
                        V
+-----------------------+-------------------------------+
| Роутер с NAT и         |  Публичный IP: 203.0.113.45    |
| Port Forwarding       |  Правило: 25565 -> 192.168.1.101:25565 |
+-----------------------+-------------------------------+
                        |  Перенаправляет на 192.168.1.101:25565
                        V
+-----------------------+
|  Локальная сеть       |
+-----------------------+
                        |
    +-------------------+
    | Компьютер         |
    | IP: 192.168.1.101 |  Minecraft Server (порт 25565)
    +-------------------+
```

**Важные моменты:**

*   **Статический IP-адрес:**  Рекомендуется, чтобы у компьютера, на который ты перенаправляешь порт, был *статический IP-адрес* в локальной сети.  Иначе, если IP-адрес компьютера изменится, Port Forwarding перестанет работать.  Статический IP-адрес можно настроить либо на самом компьютере, либо в настройках DHCP роутера (резервирование IP-адреса по MAC-адресу).
*   **Безопасность:**  Открывать порты небезопасно, если ты не уверен, что делаешь.  Открывай только те порты, которые тебе действительно нужны, и убедись, что программа, которая "слушает" этот порт, защищена (например, с помощью пароля).
*   **Двойной NAT:**  Если у тебя более одного роутера с NAT (например, роутер от провайдера и твой личный роутер), тебе, возможно, придется настроить Port Forwarding на обоих роутерах.
*   **Проверка:**  После настройки Port Forwarding проверь, работает ли он, с помощью онлайн-сервисов для проверки открытых портов.

**В итоге:**

Port Forwarding – это как указание почтовой службе (роутеру), в какую конкретно квартиру (компьютер) нужно доставить посылку (трафик) с определенным номером (портом), адресованную на общий адрес дома (публичный IP-адрес). Это необходимо, чтобы другие люди в Интернете могли напрямую подключаться к сервисам, запущенным на твоем компьютере.
